# Endpoint–PCIA–PEFA 研究执行规划

## 一、重构后的研究目标

本项目不再把 PCIA 预设为新的基础归因量，而是建立并检验下面这条递进链：

\[
\boxed{
\text{Endpoint}
\;\longrightarrow\;
\text{端口分辨 Endpoint}
\;\longrightarrow\;
\text{PCIA 一阶路径项}
\;\longrightarrow\;
\text{PEFA 形成归因}
\;\longrightarrow\;
\text{端口路由曲率与干预}
}
\]

三类对象承担不同角色：

- **Endpoint** 是既有起点：\(E_i(x)=x_i\,\partial_iF(x)\)，等同于 Gradient × Input；既有 Endpoint 工作提供局部扫描、真实 Jacobian 分解和 ViT 结构接口，不能改称为新基础归因。
- **PCIA** 是一阶路径基线：它把路径输入归因分解到真实使用端口，但其“输入坐标 × 内部单元”骨架与 conductance 已有明显重合。因此，PCIA 只保留为端口化、切面化的一阶结构对照，不单独承担“全新基础量”的主张。
- **PEFA**（Port-resolved Endpoint Formation Attribution）是待检验的新候选：它归因的不是输出差，而是最终 Endpoint 信用如何沿路径被建立、转移和抵消。潜在贡献来自新的被解释对象、端口分辨张量、Endpoint 守恒关系，以及端口路由曲率，而不是“再次使用路径积分”本身。

最终要回答三个问题：

1. PEFA 是否在数学上严格区别于 conductance、Integrated Hessians、EAP/EAP-IG 和现有 meta-attribution？
2. PEFA 是否能在真实 ViT 使用端口上精确闭合，并揭示 Endpoint 与 IG 之间的非线性形成项？
3. PEFA/路由曲率是否能预测 Endpoint 变化或内部干预效应，而不仅是生成另一组热图？

## 二、冻结的候选数学对象

设标量目标为 \(F:\mathbb R^d\to\mathbb R\)，参考输入为 \(b\)，从 \(b\) 到 \(x\) 的分段 \(C^1\) 路径为 \(\gamma\)。所有随路径变化的根变量都必须纳入 \(\gamma\)；固定根变量的路径导数为零。

### 2.1 Endpoint 与真实端口分解

参考点相对的 Endpoint 定义为

\[
E_i^b(x)=(x_i-b_i)\frac{\partial F(x)}{\partial x_i}.
\]

原始 Endpoint 是 \(b=0\) 的特例。对合法切面 \(C\) 中的真实使用端口 \(e\)，定义

\[
D_{e,i}(u)
=
\left[
J_{z_e,u}(u)^{\mathsf T}
\frac{\partial F}{\partial z_e}
\right]_i,
\qquad
Q_{e,i}^b(u)=(u_i-b_i)D_{e,i}(u).
\]

若 \(C\) 与每条有效根—目标路径恰好相交一次，则

\[
\sum_{e\in C}D_{e,i}(u)=\partial_iF(u),
\qquad
\sum_{e\in C}Q_{e,i}^b(x)=E_i^b(x).
\]

端口 ID 至少包含 producer tensor identity、consumer operator identity、input-slot identity 和 invocation index；fan-out 后的不同消费端口不得共享聚合余切。

### 2.2 PCIA：PEFA 的一阶直接项

定义端口—输入的一阶路径项

\[
A_{e,i}^{\gamma}
=
\int_0^1
\dot\gamma_i(t)D_{e,i}(\gamma(t))
\,\mathrm dt.
\]

对合法切面求和恢复 path IG；再对输入坐标求和恢复 \(F(x)-F(b)\)。该关系是必要基线和实现检查，但不能单独支撑 PCIA 的基础新颖性。

### 2.3 PEFA：最终 Endpoint 信用的形成归因

定义

\[
\boxed{
T_{e,i\leftarrow j}^{\gamma}
=
\int_0^1
\dot\gamma_j(t)
\frac{\partial Q_{e,i}^b(u)}{\partial u_j}
\bigg|_{u=\gamma(t)}
\,\mathrm dt
}
\]

其中 \(e\) 表示真实使用端口，\(i\) 表示最终形成的 Endpoint 坐标，\(j\) 表示形成该信用的输入变化来源。其基本闭合关系为

\[
\sum_jT_{e,i\leftarrow j}^{\gamma}=Q_{e,i}^b(x),
\qquad
\sum_{e\in C}\sum_jT_{e,i\leftarrow j}^{\gamma}=E_i^b(x).
\]

展开乘积导数得到

\[
T_{e,i\leftarrow j}^{\gamma}
=
\delta_{ij}A_{e,i}^{\gamma}
+R_{e,i\leftarrow j}^{\gamma},
\]

其中新的曲率运输项为

\[
R_{e,i\leftarrow j}^{\gamma}
=
\int_0^1
(\gamma_i(t)-b_i)\dot\gamma_j(t)
\frac{\partial D_{e,i}}{\partial u_j}
\bigg|_{u=\gamma(t)}
\,\mathrm dt.
\]

因此在输入层面有

\[
E_i^b(x)
=
\operatorname{IG}_i^{\gamma}(F)
+\sum_{e\in C}\sum_jR_{e,i\leftarrow j}^{\gamma},
\]

即 PEFA 将 Endpoint 与 IG 的差精确分配给“来源坐标 × 真实端口”的累计非线性形成项。

### 2.4 端口路由曲率

定义端口梯度通道的反对称曲率

\[
\Omega_{e,ij}(u)
=
\frac{\partial D_{e,j}}{\partial u_i}
-\frac{\partial D_{e,i}}{\partial u_j}.
\]

当 \(F\) 二阶光滑且 \(C\) 为合法完整切面时，Hessian 对称性给出

\[
\boxed{\sum_{e\in C}\Omega_{e,ij}(u)=0}.
\]

单端口的非零 \(\Omega_e\) 表示内部信用路由对输入变化顺序敏感；完整切面上的相消表示总模型梯度仍是保守场。该对象是结构诊断量，不自动等于因果效应。

## 三、全程硬约束

- **不倒签新颖性。** 在查新和等价性审计完成前，只称 PEFA 为“候选框架”；不得声称路径积分、二阶归因、特征对归因或边归因本身首次提出。
- **不把旧证据改名。** 既有 Endpoint 结果只证明 Endpoint/局部切面性质；既有 Path IG 或 Endpoint 结果不能重新标记为 PCIA 或 PEFA 结果。
- **真实端口优先。** 同一张量的不同消费者、输入槽和调用次数是不同边；residual bypass、Q/K/V、head 和完整 MLP 切面必须显式注册。局部 attention cut 不得冒充全局切面。
- **区分一阶与二阶自动微分。** 计算局部 PCIA 通道时，端口余切按一阶 VJP 语义固定；计算 \(\partial_jD_{e,i}\)、\(R\) 和 \(\Omega\) 时必须保留完整二阶依赖。若误用 `detach`/`stop-gradient` 截断二阶项，验证器必须失败。
- **先闭合、后聚合。** 所有恒等式先在原始 normalized RGB \([c,h,w]\) 坐标和未聚合端口上验证，再做 patch、head、层或空间展示聚合。
- **先冻结、后读结果。** 每一步在接触对应 outcome 前冻结对象、基线、路径、积分规则、精度、容差、样本、统计量、资源预算和失败类型；不得事后调节点、删样、扩大样本或放宽阈值。
- **数学成立与科学有效分开。** 闭合 PASS 只说明实现符合定义；是否带来稳定解释、预测干预或论文贡献必须单独判定。
- **阶段门禁。** 当前步骤失败时只修复或正式收缩当前步骤，不自动进入后续步骤。CPU 原型未通过前不得启动正式 GPU；成本门未通过时不得扩大生产。

## 步骤 5.1：检验 PEFA 能否定位 Endpoint–IG 差异经过的内部端口

### 5.1.1 背景、状态与边界

步骤 5 及其三个扩展方向的既有结论保持不变：

- PEFA-R 和 $\Omega$ 没有证明自己比简单基线更擅长预测普通输入遮挡、head 消融或有限闭环效应；
- 接近分类边界没有放大 $\Omega$；
- $7\times7$ 来源分辨率没有优于 $4\times4$，且来源积分仍有明显收敛问题，因此不进入 $14\times14$ 或 pixel-level；
- 原步骤 5 的终态继续是 `NOT_SUPPORTED_EMPIRICAL_VALUE`，步骤 6 不因本节自动开放。

本节是看到上述结果后提出的**独立前瞻性方向**，不能回写或改变旧结论。该方向已于 2026-09-21 按 `step5_1_protocol.md` 冻结并执行完毕，最终 reporting-only root 为 `step5_1_r7_20260921`。执行只使用 discovery 开发图和预注册 calibration `split_order=8..15`；未访问 evaluation split，也未启动步骤 6。r1、r3 和 r4 的基础设施失败均保留为不可变证据，后续修复分别在新 root 中执行；r7 只修复跨阶段资源血缘，不改变任何实验结果。

本节不再试图证明“PEFA 能找到删掉后最影响分类的区域或 head”。新的问题是：

> Endpoint 和 IG 对同一输入坐标给出不同信用时，PEFA 能否指出这笔差异在指定合法切面上主要由哪些真实端口承载、增强或抵消？当我们在已知位置加入或削弱非线性时，PEFA 能否比 Endpoint、PCIA、梯度范数和激活范数更准确地定位变化位置？

这里的“位置”只表示冻结计算图中的 consumer use-port、input slot、invocation、head、branch 和 block，不表示唯一的物理或因果起源。不同合法切面是同一总差异的不同内部记账视角，不能把跨层数值直接相加并称为“总产生量”。

### 5.1.2 要解释的量

定义每个输入坐标上的归因差异

\[
G_i(x;b,\gamma)
=E_i^b(x)-\operatorname{IG}_i^\gamma(F).
\]

在任一冻结的合法切面 $C$ 上，已有恒等式给出

\[
G_i=\sum_{e\in C}R_{e,i},
\qquad
R_{e,i}=\sum_jR_{e,i\leftarrow j}.
\]

说人话：Endpoint 是只看真实图片终点的局部梯度账，IG 是从参考图走到真实图片的沿途平均账，$G$ 是两本账的差额。PEFA-R 把这笔差额按真实端口拆开，显示在某个合法切面上哪些端口同向承担差额、哪些端口互相抵消。

步骤 5.1 只使用已经通过闭合的 source-summed $R_{e,i}$。在来源积分收敛问题解决前，不使用 $R_{e,i\leftarrow j}$ 的 $7\times7$、$14\times14$ 或 pixel-level 版本支撑结论。$\Omega$ 只保留为结构诊断和辅助读出，不再作为有限干预效应的主要预测量。

### 5.1.3 实验 A：已知位置的非线性注入

这是主验证。目的不是制造更高的分类变化，而是建立一个“答案事先已知”的定位任务。

1. 在冻结的合法切面上选择一个真实端口 $e^*$，向该端口加入有界的二次非线性包装器。包装器必须在 clean activation 处满足“输出不变、局部一阶 Jacobian 不变”，只改变离开 clean 点后的二阶行为。
2. 每次只修改一个预注册端口；另设相同尺度但错误端口、线性包装器和零强度包装器作为负控制。
3. 修改前后分别计算 Endpoint、IG、PCIA 和 PEFA。clean logit、clean prediction、Endpoint 及完整切面一阶闭合必须保持在冻结容差内，否则任务为 `INVALID_INTERVENTION_CONSTRUCTION`。
4. 检查新增的 Endpoint–IG 差异是否被 PEFA 定位到真正修改的端口，而不是邻近端口、同一 producer 的其他 consumer 或高激活端口。
5. 比较 Endpoint 端口质量、PCIA、普通梯度范数、激活范数、随机排序和 PEFA-R。由于 Endpoint 在 clean 点被设计为基本不变，它不能事后吸收注入位置的信息。

主结果必须以 image 为统计单位，至少报告：真实端口的 top-1/top-k 定位率、真实端口相对其他端口的 rank、修改前后 $R_e$ 的变化量、$G$ 的方向一致性，以及相对每个简单基线的配对差。不同切面和不同注入强度分开报告。

该实验若通过，只能说明 PEFA 对“已知的端口非线性变化”具有定位敏感性，不能单独证明自然模型中的机制解释正确。

### 5.1.4 实验 B：自然模块的非线性削弱

在实验 A 通过后，才允许检验真实 ViT 中已有的非线性。候选模块固定为 attention softmax、$QK$ 双线性项、$AV$ 双线性项、GELU 和 LayerNorm；线性 projection 与 residual add 作为低曲率负控制。

对某个模块 $h$，在该图像的 clean activation $z_*$ 处构造局部仿射版本

\[
h_{\mathrm{lin}}(z)=h(z_*)+J_h(z_*)(z-z_*),
\]

并用

\[
h_\lambda(z)=h_{\mathrm{lin}}(z)
+\lambda\bigl(h(z)-h_{\mathrm{lin}}(z)\bigr),
\qquad \lambda\in\{1,0.5,0\}
\]

逐步削弱该模块的非线性余项。$\lambda=1$ 是原模型，$\lambda=0$ 是 clean 点切线模型。该构造在 clean 点保留模块输出和一阶 Jacobian，因此目标 logit、预测和 Endpoint 应保持不变；它改变的是参考点到输入的沿途行为及 IG。任何 clean parity 超过冻结容差的任务均无效。

实验先在固定 block 内比较同类端口，再比较预注册模块类别。PEFA 的端口分数必须在看到削弱结果前冻结。主要检查：

- PEFA 认为承担或抵消 $G$ 较多的端口，其非线性被削弱后，$G$ 是否发生更大的、方向相符的变化；
- $\lambda$ 从 1 降到 0 时，$G$ 的变化是否具有稳定的剂量顺序；
- PEFA-R 是否稳定优于 PCIA、Endpoint 端口质量、梯度范数、激活范数和随机基线；
- 结果能否在 ViT-B/16 和 DeiT-S/16 两个模型上同向复现。

这项实验检验的是“PEFA 能否定位归因差异所经过的非线性端口”，不是“该端口对分类最重要”。局部仿射替换会改变沿途计算，也可能通过下游模块传播，因此只能按预注册端口和切面解释，不能声称找到了唯一的非线性来源。

### 5.1.5 实验 C：归因实现错误的定位审计

若实验 A 有效，可并行建立一个不依赖自然效应大小的审计任务。对真实 ViT 实现逐项注入已知错误：遗漏或重复 residual、错误合并 fan-out cotangent、交换 consumer input slot、截断二阶图、只保留 Hessian 对角、降低积分节点和强制低精度相消。

比较普通 output/IG completeness、Endpoint 单点检查与 Endpoint–PCIA–PEFA 合同，判断哪套检查能发现错误，并定位到正确的 block、切面和端口类别。这里的价值主张是“归因实现的错误检测与定位”，不是模型因果解释。旧步骤 2–5 已用过的负控制只能作为开发集；正式结果必须增加未参与规则设计的新 mutation，并在运行前冻结预期失败类型。

### 5.1.6 分阶段门槛与停止规则

1. **A0 数值可行性。** 先在 CPU float64 fixture 和每模型 1 张开发图上验证包装器的 clean value/Jacobian parity、完整切面闭合和剂量方向。只检查实现，不产生科学结论。
2. **A1 受控定位 pilot。** 使用未进入原步骤 5 的机械选取 calibration 子集。只有两个模型都在预注册定位指标上优于所有简单基线，并且负控制不产生假定位，才进入实验 B。
3. **B1 自然非线性 pilot。** 只有两个模型都显示稳定的方向、剂量关系和相对基线增量，才允许申请新的未见 holdout。任一模型失败，结论为 `NOT_SUPPORTED_NONLINEARITY_LOCALIZATION`，不通过增加分辨率、改模块集合或删样恢复。
4. **C1 审计定位。** 独立判定 `SUPPORTED / NOT_SUPPORTED / INVALID`。即使 C1 通过，也只能将项目定位为端口分辨归因审计工具，不能把它写成更好的 saliency 或干预预测方法。

步骤 5.1 的 claim 必须分别判定：

- `CONTROLLED_CURVATURE_LOCALIZATION`；
- `NATURAL_NONLINEARITY_LOCALIZATION`；
- `ATTRIBUTION_ERROR_LOCALIZATION`；
- `INCREMENTAL_OVER_SIMPLE_BASELINES`；
- `NUMERICAL_VALIDITY_AND_COST`。

只有受控定位、自然定位、基线增量和数值有效性在两个模型上同时为 `SUPPORTED`，才允许申请一轮新的确认性实验。否则保留旧主定位 `ENDPOINT_EXTENSION_ONLY`。审计定位可以形成独立的系统工具贡献，但不能替代自然定位门槛。

### 5.1.7 允许与禁止的结论

若完整门槛通过，允许表述：

> Endpoint–PCIA–PEFA 能在冻结的 ViT 图、合法切面和参考路径下，将 Endpoint–IG 差异分配到真实消费端口，并比简单一阶或幅值基线更准确地定位受控及自然非线性变化所对应的端口。

无论结果如何，均禁止表述：

- PEFA 是新的基础归因算法；
- PEFA 普遍优于 IG、Endpoint 或现有 saliency 方法；
- $R$ 或 $\Omega$ 等于真实有限干预效应；
- 某端口是 Endpoint–IG 差异唯一的因果来源；
- 步骤 5.1 的结果推翻原步骤 5 的 `NOT_SUPPORTED_EMPIRICAL_VALUE`。

### 5.1.8 执行结果与终态

最终终态为 `NOT_SUPPORTED_INCREMENTAL_OVER_SIMPLE_BASELINES`，理由是 `A1_CONTROLLED_LOCALIZATION_SUPPORTED_BUT_PCIA_DELTA_TIED_PEFA_R_DELTA`。逐项结论如下：

- `CONTROLLED_CURVATURE_LOCALIZATION = SUPPORTED`。A0 CPU float64 fixture 与两模型真实图均通过 clean value/Jacobian parity、五项完整切面闭合、零强度/线性控制和剂量方向检查。A1 的 16/16 个任务均在首次 attempt 被接受；对两个模型、primary/decoy 两类端口和强度 0.5/1.0，PEFA-R 的 top-1、top-k 和平均 percentile rank 均为 1.0。
- `INCREMENTAL_OVER_SIMPLE_BASELINES = NOT_SUPPORTED`。在上述全部八个模型 × 角色 × 强度组中，PCIA change baseline 的 top-1、top-k 和平均 percentile rank 同样均为 1.0；PEFA-R 相对 PCIA delta 的 percentile 与 top-1 增量均为 0，未达到冻结的 0.05 和 0.125 门槛。
- `NATURAL_NONLINEARITY_LOCALIZATION = NOT_RUN_A1_GATE_CLOSED`。B1 的前置增量门未通过，因此没有运行；这不是 B1 的科学负结果。不得事后改基线、改阈值、删样或扩大分辨率来打开该门。
- `ATTRIBUTION_ERROR_LOCALIZATION = SUPPORTED`。独立 C1 held-out `consumer_head_slice_rotation` 在两模型均被合同检测为 `FAIL_PORT_ID_SEMANTIC_MISMATCH`，并正确定位到 block 5、`HEADS_WITH_BYPASS_FULL` 和 head-port 类别。该结论只支持端口分辨归因审计能力，不支持自然机制或 saliency 优越性。
- `NUMERICAL_VALIDITY_AND_COST = SUPPORTED`。Step 5.1 使用 `1.1972829116923434` H20-hours；接续既有 Step 5 completion 的保守上界后，累计 Step 5 为 `14.182787541702375` H20-hours，上限为 64 H20-hours。

因此主线定位保持 `ENDPOINT_EXTENSION_ONLY`，原步骤 5 的 `NOT_SUPPORTED_EMPIRICAL_VALUE` 保持不变。`b1_authorized_by_gate=false`，确认性实验未授权，evaluation 保持未访问，步骤 6 未授权且未启动。这里的正结论严格限于：PEFA-R 能定位本实验构造的受控曲率变化，且合同能定位预注册的端口语义错误；现有证据不支持 PEFA-R 相对简单 PCIA change baseline 的增量价值，也没有检验自然非线性定位。

## 步骤 5.2：先预测、后干预，检验 Endpoint–IG 差异的端口解释

### 5.2.1 为什么需要新实验

步骤 5.1 的结果和终态全部保持不变。本节不重开 A1，不越过旧门槛运行 B1，也不把 `NOT_RUN_A1_GATE_CLOSED` 改写成自然非线性实验的负结果。

A1 无法区分 PEFA-R change 与 PCIA change，不只是因为两者碰巧都达到满分，而是因为该实验满足

\[
R_e=Q_e-A_e.
\]

A1 的包装器在 clean 点保持端口 Endpoint 量不变，即 \(\Delta Q_e=0\)。因此

\[
\Delta R_e=-\Delta A_e,
\qquad
\lVert\Delta R_e\rVert_1=\lVert\Delta A_e\rVert_1.
\]

所以，用修改前后的 \(\Delta R_e\) 和 \(\Delta A_e\) 去找被修改端口，本来就会得到相同排序。A1 证明了实现能够定位受控变化，但这种事后定位任务不能证明 PEFA 比 PCIA 多提供了经验信息。不得通过重跑、换范数、删样或调整门槛消除这个并列。

步骤 5.2 改问一个真正可区分的问题：

> 在不看任何干预结果时，只根据原始模型提前判断哪些自然 attention head 最能维持 Endpoint 与 IG 的差异；随后逐个削弱这些 head 的非线性，检查提前判断是否与真实的差异变化一致。

这里真正要解释的是

\[
G(x)=E^b(x)-\operatorname{IG}^{\gamma}(F).
\]

Endpoint 与 IG 不是在本节中争夺胜负的两个预测器。它们的差额 \(G\) 才是研究对象。PEFA-R、PCIA 和端口 Endpoint 是对“哪些端口与这笔差额有关”的不同候选解释。

还必须明确：source-summed PEFA-R 由 \(R_e=Q_e-A_e\) 精确确定，不是独立于端口 Endpoint 与 PCIA 的第三份信息。本节最多检验“有符号差额 \(Q_e-A_e\) 是否比单独看 \(Q_e\) 或 \(A_e\) 更适合预测 \(G\) 对自然非线性削弱的响应”，不能声称 PEFA 含有超出 \(Q_e\) 与 \(A_e\) 联合信息的新信息。

### 5.2.2 冻结预测，禁止看完干预再打分

对每张新样本和每个候选 head，先在**未修改的原模型**上计算并封存：

- PEFA-R 分数：\(s_R(e)=\lVert R_e\rVert_1\)；
- PCIA 分数：\(s_A(e)=\lVert A_e\rVert_1\)；
- 端口 Endpoint 分数：\(s_Q(e)=\lVert Q_e\rVert_1\)；
- 普通梯度范数、激活范数和冻结随机排序。

同时封存 \(R_e\)、\(A_e\) 和 \(Q_e\) 的有符号输入坐标图，用于方向一致性分析。全局 Endpoint 本身不能区分同层不同 head，因此这里只能使用其合法切面上的端口分解 \(Q_e\) 作为 Endpoint 基线。所有积分节点、精度、聚合方法、候选 head 和并列处理规则都必须在产生干预结果前冻结。

严禁把修改后的 \(\Delta R_e\)、\(\Delta A_e\)、logit 变化或任何干预结果重新喂给排序器。本节与 A1 的根本区别是：A1 回答“哪个端口已经被改了”，步骤 5.2 回答“在还没改之前，能否预测改哪个端口最会改变 Endpoint–IG 差额”。

### 5.2.3 第一阶段只比较 block 5 的同类 attention heads

第一阶段在 DeiT-S/16 和 ViT-B/16 中分别固定 block 5，只比较该 block 内同一语义、同一粒度的 attention heads。对 head \(e\)，把从该 block 的 normalized residual 输入到该 head 输出贡献的映射记为 \(h_e\)。在该样本的 clean activation \(z_*\) 处构造

\[
h_{e,\mathrm{lin}}(z)
=h_e(z_*)+J_{h_e}(z_*)(z-z_*),
\]

并使用

\[
h_{e,\lambda}(z)
=h_{e,\mathrm{lin}}(z)
+\lambda\bigl(h_e(z)-h_{e,\mathrm{lin}}(z)\bigr),
\qquad \lambda\in\{1,0.5,0\}.
\]

每次只修改一个 head。该构造应在 clean 点保持 head 输出和一阶 Jacobian，因此模型输出、输入梯度和 Endpoint 应保持不变；它只削弱从 reference 到输入的路径上该 head 的非线性行为。若 clean logit、预测、输入梯度、Endpoint 或合法切面闭合超出冻结容差，该任务记为 `INVALID_INTERVENTION_CONSTRUCTION`，不能进入科学统计。

第一阶段不同时比较 softmax、GELU、LayerNorm、QK、AV 或不同 block。原因不是认定其他模块无效，而是先保证每个候选接受相同类型、相同粒度的干预，避免“哪个模块更容易被改”冒充“哪个端口更能解释差异”。只有本阶段通过后，才可另写协议申请扩展模块或层；不得用扩展搜索挽救失败的 block 5 结果。

### 5.2.4 实际结果与评价方法

原模型的归因差额为 \(G^{(1)}\)。逐个削弱 head 后，计算

\[
\Delta G_e^{(\lambda)}
=G_e^{(\lambda)}-G^{(1)},
\qquad
Y_e^{(\lambda)}
=\frac{\lVert\Delta G_e^{(\lambda)}\rVert_1}
{\lVert G^{(1)}\rVert_1+\varepsilon}.
\]

\(Y_e^{(\lambda)}\) 是主要结果：它直接表示削弱某个 head 的自然非线性后，Endpoint–IG 差额实际改变了多少。由于 Endpoint 在 clean 点应保持不变，数值上还应满足 \(\Delta G_e^{(\lambda)}\approx-\Delta\operatorname{IG}_e^{(\lambda)}\)；该关系作为实现检查，不另算一条科学证据。普通 logit 下降不作为主要结果。

每张图先在同层 heads 内比较“干预前预测排序”和“真实 \(Y_e\) 排序”，再以 image 为统计单位跨样本汇总。至少报告：

- 各预先冻结分数与 \(Y_e^{(0)}\) 的逐图 Spearman 相关；
- top-1 命中率和 top-k 真实效应捕获率，其中 \(k\) 按各模型 head 数在协议中预先冻结；
- 从 \(\lambda=1\) 到 \(0.5\) 再到 \(0\) 的剂量顺序；
- \(-R_e\) 与实际 \(\Delta G_e^{(0)}\) 的余弦和符号一致率，作为方向性次要结果；
- PEFA-R 相对每个简单基线及“当次最强简单基线”的逐图配对差和不确定区间。

方向性分析不能替代主要排序结果。局部线性化会改变整条后续计算，\(-R_e\) 不被假定为 \(\Delta G_e\) 的严格解析解；二者是否对齐正是需要检验的问题。

### 5.2.5 样本、数值与分阶段门槛

1. **P0 协议与数值检查。** 先用解析 fixture 和不进入正式统计的开发图，冻结 head 边界、局部线性化实现、路径、reference、积分节点、精度、容差、主指标、最小增量和资源上限。积分收敛必须在 source-summed \(R_e\)、IG 和 \(G\) 上独立通过，不能按样本增加节点直到通过。
2. **P1 新 calibration pilot。** 使用未参加 A1、按既有 split order 或其他 outcome-blind 元数据机械选取的新 calibration 样本。样本选择不得查看 PEFA 排名、干预效应或分类边界距离。两个模型分开报告，不允许合并后掩盖单模型失败。evaluation 继续不可访问。
3. **P1 通过条件。** 数值与 clean parity 全部有效；PEFA-R 对 \(Y_e\) 有预注册的正预测力；并且它相对当次最强简单基线的优势达到预先冻结的最小效应，在 DeiT-S/16 和 ViT-B/16 上均成立。剂量与方向结果作为独立 claim 报告，不得用次要指标替代主要增量门。
4. **停止规则。** 若 PEFA-R 在任一模型上不优于最强简单基线，签发 `NOT_SUPPORTED_PREDICTIVE_INCREMENT`，停止扩展到其他 block、GELU、LayerNorm、QK、AV、\(14\times14\) 或 pixel-level。若所有方法都不能预测 \(Y_e\)，另记 `NOT_SUPPORTED_NATURAL_GAP_PREDICTION`。若积分收敛或线性化 parity 失败，记 `INVALID_NUMERICAL_OR_INTERVENTION`，只允许修复实现后在新 root 重跑同一阶段。
5. **后续边界。** 只有 P1 在两个模型上都通过，才可提交新的 holdout 协议；这不自动开放 evaluation、正式生产或步骤 6，仍需用户明确授权。

### 5.2.6 允许与禁止的结论

若 P1 通过，允许表述：

> 在两个冻结 ViT 的 block 5 attention heads 中，原模型的端口 Endpoint–IG 差额 \(R_e=Q_e-A_e\) 能在干预前预测：削弱哪个 head 的自然非线性会更明显地改变整体 Endpoint–IG 差额；该预测优于单独使用 PCIA、端口 Endpoint、梯度或激活幅值。

若 PEFA-R 能预测但未优于简单基线，只能表述为“Endpoint–IG 差额具有端口级可定位性，但 PEFA-R 未显示增量选择价值”。若 P1 未通过，则保留 PEFA 的数学分解与审计用途，不再把自然非线性干预预测作为主张。

无论结果如何，均禁止表述：

- Endpoint 比 IG 更正确，或 PEFA 是比 Endpoint/IG 更好的 saliency 方法；
- PEFA-R 含有超出 \(Q_e\) 与 \(A_e\) 联合信息的独立信息；
- 被排序第一的 head 是 Endpoint–IG 差异唯一的真实来源；
- 局部线性化等同于自然模型中的真实因果删除；
- 步骤 5.2 可以覆盖步骤 5 或步骤 5.1 已封存的阴性结论。
