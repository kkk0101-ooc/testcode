# Endpoint–PCIA–PEFA 研究执行规划

## 一、重构后的研究目标

本项目不再把 PCIA 预设为新的基础归因量，而是建立并检验下面这条递进链：

\[
\boxed{
\text{Endpoint}
\;\longrightarrow\;
\text{端口分辨 Endpoint}
\;\longrightarrow\;
\text{PCIA 一阶路径项}
\;\longrightarrow\;
\text{PEFA 形成归因}
\;\longrightarrow\;
\text{端口路由曲率与干预}
}
\]

三类对象承担不同角色：

- **Endpoint** 是既有起点：\(E_i(x)=x_i\,\partial_iF(x)\)，等同于 Gradient × Input；既有 Endpoint 工作提供局部扫描、真实 Jacobian 分解和 ViT 结构接口，不能改称为新基础归因。
- **PCIA** 是一阶路径基线：它把路径输入归因分解到真实使用端口，但其“输入坐标 × 内部单元”骨架与 conductance 已有明显重合。因此，PCIA 只保留为端口化、切面化的一阶结构对照，不单独承担“全新基础量”的主张。
- **PEFA**（Port-resolved Endpoint Formation Attribution）是待检验的新候选：它归因的不是输出差，而是最终 Endpoint 信用如何沿路径被建立、转移和抵消。潜在贡献来自新的被解释对象、端口分辨张量、Endpoint 守恒关系，以及端口路由曲率，而不是“再次使用路径积分”本身。

最终要回答三个问题：

1. PEFA 是否在数学上严格区别于 conductance、Integrated Hessians、EAP/EAP-IG 和现有 meta-attribution？
2. PEFA 是否能在真实 ViT 使用端口上精确闭合，并揭示 Endpoint 与 IG 之间的非线性形成项？
3. PEFA/路由曲率是否能预测 Endpoint 变化或内部干预效应，而不仅是生成另一组热图？

## 二、冻结的候选数学对象

设标量目标为 \(F:\mathbb R^d\to\mathbb R\)，参考输入为 \(b\)，从 \(b\) 到 \(x\) 的分段 \(C^1\) 路径为 \(\gamma\)。所有随路径变化的根变量都必须纳入 \(\gamma\)；固定根变量的路径导数为零。

### 2.1 Endpoint 与真实端口分解

参考点相对的 Endpoint 定义为

\[
E_i^b(x)=(x_i-b_i)\frac{\partial F(x)}{\partial x_i}.
\]

原始 Endpoint 是 \(b=0\) 的特例。对合法切面 \(C\) 中的真实使用端口 \(e\)，定义

\[
D_{e,i}(u)
=
\left[
J_{z_e,u}(u)^{\mathsf T}
\frac{\partial F}{\partial z_e}
\right]_i,
\qquad
Q_{e,i}^b(u)=(u_i-b_i)D_{e,i}(u).
\]

若 \(C\) 与每条有效根—目标路径恰好相交一次，则

\[
\sum_{e\in C}D_{e,i}(u)=\partial_iF(u),
\qquad
\sum_{e\in C}Q_{e,i}^b(x)=E_i^b(x).
\]

端口 ID 至少包含 producer tensor identity、consumer operator identity、input-slot identity 和 invocation index；fan-out 后的不同消费端口不得共享聚合余切。

### 2.2 PCIA：PEFA 的一阶直接项

定义端口—输入的一阶路径项

\[
A_{e,i}^{\gamma}
=
\int_0^1
\dot\gamma_i(t)D_{e,i}(\gamma(t))
\,\mathrm dt.
\]

对合法切面求和恢复 path IG；再对输入坐标求和恢复 \(F(x)-F(b)\)。该关系是必要基线和实现检查，但不能单独支撑 PCIA 的基础新颖性。

### 2.3 PEFA：最终 Endpoint 信用的形成归因

定义

\[
\boxed{
T_{e,i\leftarrow j}^{\gamma}
=
\int_0^1
\dot\gamma_j(t)
\frac{\partial Q_{e,i}^b(u)}{\partial u_j}
\bigg|_{u=\gamma(t)}
\,\mathrm dt
}
\]

其中 \(e\) 表示真实使用端口，\(i\) 表示最终形成的 Endpoint 坐标，\(j\) 表示形成该信用的输入变化来源。其基本闭合关系为

\[
\sum_jT_{e,i\leftarrow j}^{\gamma}=Q_{e,i}^b(x),
\qquad
\sum_{e\in C}\sum_jT_{e,i\leftarrow j}^{\gamma}=E_i^b(x).
\]

展开乘积导数得到

\[
T_{e,i\leftarrow j}^{\gamma}
=
\delta_{ij}A_{e,i}^{\gamma}
+R_{e,i\leftarrow j}^{\gamma},
\]

其中新的曲率运输项为

\[
R_{e,i\leftarrow j}^{\gamma}
=
\int_0^1
(\gamma_i(t)-b_i)\dot\gamma_j(t)
\frac{\partial D_{e,i}}{\partial u_j}
\bigg|_{u=\gamma(t)}
\,\mathrm dt.
\]

因此在输入层面有

\[
E_i^b(x)
=
\operatorname{IG}_i^{\gamma}(F)
+\sum_{e\in C}\sum_jR_{e,i\leftarrow j}^{\gamma},
\]

即 PEFA 将 Endpoint 与 IG 的差精确分配给“来源坐标 × 真实端口”的累计非线性形成项。

### 2.4 端口路由曲率

定义端口梯度通道的反对称曲率

\[
\Omega_{e,ij}(u)
=
\frac{\partial D_{e,j}}{\partial u_i}
-\frac{\partial D_{e,i}}{\partial u_j}.
\]

当 \(F\) 二阶光滑且 \(C\) 为合法完整切面时，Hessian 对称性给出

\[
\boxed{\sum_{e\in C}\Omega_{e,ij}(u)=0}.
\]

单端口的非零 \(\Omega_e\) 表示内部信用路由对输入变化顺序敏感；完整切面上的相消表示总模型梯度仍是保守场。该对象是结构诊断量，不自动等于因果效应。

## 三、全程硬约束

- **不倒签新颖性。** 在查新和等价性审计完成前，只称 PEFA 为“候选框架”；不得声称路径积分、二阶归因、特征对归因或边归因本身首次提出。
- **不把旧证据改名。** 既有 Endpoint 结果只证明 Endpoint/局部切面性质；既有 Path IG 或 Endpoint 结果不能重新标记为 PCIA 或 PEFA 结果。
- **真实端口优先。** 同一张量的不同消费者、输入槽和调用次数是不同边；residual bypass、Q/K/V、head 和完整 MLP 切面必须显式注册。局部 attention cut 不得冒充全局切面。
- **区分一阶与二阶自动微分。** 计算局部 PCIA 通道时，端口余切按一阶 VJP 语义固定；计算 \(\partial_jD_{e,i}\)、\(R\) 和 \(\Omega\) 时必须保留完整二阶依赖。若误用 `detach`/`stop-gradient` 截断二阶项，验证器必须失败。
- **先闭合、后聚合。** 所有恒等式先在原始 normalized RGB \([c,h,w]\) 坐标和未聚合端口上验证，再做 patch、head、层或空间展示聚合。
- **先冻结、后读结果。** 每一步在接触对应 outcome 前冻结对象、基线、路径、积分规则、精度、容差、样本、统计量、资源预算和失败类型；不得事后调节点、删样、扩大样本或放宽阈值。
- **数学成立与科学有效分开。** 闭合 PASS 只说明实现符合定义；是否带来稳定解释、预测干预或论文贡献必须单独判定。
- **阶段门禁。** 当前步骤失败时只修复或正式收缩当前步骤，不自动进入后续步骤。CPU 原型未通过前不得启动正式 GPU；成本门未通过时不得扩大生产。

## 步骤 1：完成碰撞查新并冻结 Endpoint–PCIA–PEFA 合同

**工作**

- 截至执行日系统核查 IG、conductance/neuron IG、Internal Influence、Integrated Hessians、高阶/元归因、DeepLIFT、LRP、Shapley Flow、path-specific attribution、ACDC、EAP/EAP-IG、DPA，以及最新 transformer flow/circuit attribution。
- 对每项逐字段判断：被解释对象、索引结构、守恒终点、真实使用端口、合法切面、二阶项、路径/参考依赖、实现不变性、Q/K/V–head–residual–MLP 覆盖和因果边界。
- 做符号等价性审计：分别尝试把 \(T\)、\(R\)、\(\Omega\) 化约为 conductance、Integrated Hessians、对 \(E_i^b\) 的普通 IG、EAP-IG 或已有 meta-attribution。不能只比较名称或应用场景。
- 冻结 \(F,b,\gamma\)、变化根变量、输入坐标、端口 ID、合法切面、积分规则、数值精度、闭合残差、模型/数据、随机性、资源和失败类型。核验既有 Endpoint 代码、模型、数据与报告的 provenance，旧 source binding 漂移不得静默继承。

**产物与门槛**

- 更新 `literature_matrix.md`、`method_contract.md`、`asset_inventory.md`；其中必须单列 conductance 与 Integrated Hessians 的最近邻公式。
- 只有在 \(T/R/\Omega\) 至少有一个对象未被现有工作等价覆盖、且其可证伪主张写清后，才进入步骤 2。
- 若 \(T\) 只是“对 Endpoint 做 IG”的直接实例，则降级为组合框架；若 \(R/\Omega\) 也被完整覆盖，则签发 `NO_GO_FOUNDATIONAL_NOVELTY`，转为 Endpoint 系统化扩展，不制造新名称。

## 步骤 2：建立 CPU float64 参考实现与恒等式测试

**工作**

- 使用线性、双线性、饱和非线性、fan-out、residual 和多输入算子构成的微型 DAG，按定义独立实现 Endpoint、端口 \(D/Q\)、PCIA \(A\)、PEFA \(T/R\) 和路由曲率 \(\Omega\)。
- 对比解析解、自动微分和有限差分；路径积分采用预先冻结的 Gauss–Legendre 节点计划，不允许按样本自适应到“通过”为止。
- 验证五类等式：端口 Endpoint 闭合、PCIA→IG、PEFA→Endpoint、\(T=\delta A+R\)、完整切面曲率零和。
- 注册负控制：遗漏/重复 residual，合并 fan-out 余切，交换 input slot，重复串联切面，错误 detach 二阶项，以及只取 Hessian 对角。

**产物与门槛**

- 参考实现、解析 fixture、单元测试、`mvp_validation.json` 和逐负控制收据。
- 正确实现须在冻结容差内通过全部恒等式；每个负控制都必须触发预期失败。任何恒等式仅在展示聚合后成立都视为失败。
- 若二阶量在 ReLU 等非光滑点不可定义，必须冻结分段光滑/几乎处处口径和节点命中规则，不得用数值噪声掩盖。

## 步骤 3：完成理论链、等价边界与表征条件

**工作**

- 正式证明 PEFA 逐端口/逐 Endpoint 坐标闭合、\(T=\delta A+R\)、Endpoint–IG 差分恒等式和完整切面 \(\Omega\) 零和；明确所需的光滑性、图冻结、端口分离和路径条件。
- 区分路径重参数化、路径选择、参考点、输入坐标变换、端口内可逆重参数化、并行细化与跨图重写；只声明实际可证明的不变性。
- 给出退化情形：线性模型中 \(R=0\)、单输入维度中无反对称曲率、完整模型梯度场中总 \(\Omega=0\)，以及 PEFA 退化为普通元归因的条件。
- 说明 \(R\) 是 Endpoint 形成的累计曲率项、\(\Omega\) 是端口路由诊断；二者都不是内部激活替换的天然因果效应。

**产物与门槛**

- `theory_endpoint_pcia_pefa.md`：定义—引理—定理—反例—适用边界的完整链；所有数值观察必须与理论命题分栏。
- 独立符号推导与步骤 2 的解析 fixture 必须一致。证明不完整的内容降级为 conjecture；若核心等式依赖不可接受的图限制，签发 `NO_GO_GENERALITY` 或收缩适用范围。

## 步骤 4：适配 ViT 真实端口并通过成本门

**工作**

- 在不改写既有历史证据的前提下，从当前 Endpoint 实现复用目标解析、unfused attention 捕获和局部切面验证；为 PEFA 单独建立新的 source binding 与端口注册表。
- 依次实现 residual identity/branch、attention heads、单 head 的 Q/K/V、projection 和完整 MLP 的合法切面；先单 block，再完整 ViT。
- 使用 HVP/JVP/VJP 组合和 patch-group 流式计算，避免显式构造 \(d\times d\) Hessian 或完整 \(|C|\times d\times d\) 张量；任何稀疏化/聚合必须证明保留所需闭合。
- 测量每图前反向次数、积分节点、峰值内存、临时/持久存储和相对 Endpoint/IG/PCIA 的成本。

**产物与门槛**

- ViT 端口注册表、机器可读合法切面、实现测试、`vit_validation.json` 和 `cost_report.json`。
- Q/K/V、head、residual、MLP 每类至少一个切面通过步骤 2 的五类恒等式和全部适用负控制，才允许进入 pilot。
- 若只能依靠不可审计的聚合近似闭合，签发 `FAIL_PORT_FIDELITY`；若预估生产成本超过冻结预算，签发 `NO_GO_COST`，先做数学/系统论文或收缩坐标分辨率，不直接扩大 GPU。

## 步骤 5：执行冻结 pilot 与“表征—贡献—干预”验证

**工作**

- 在步骤 1–4 全部通过后，冻结模型、目标、样本、基线、路径、切面、积分节点、精度、预算和统计方案，再运行小规模 pilot；pilot 通过前不得进入大样本生产。
- **表征：** 描述 \(D/Q/R/\Omega\) 在层深、residual、Q/K/V、head 和 MLP 上的 signed/absolute mass、抵消率、路由集中度与最坏闭合样本。
- **贡献：** 检验 \(R\) 是否稳定解释 Endpoint–IG 差，比较 Endpoint、IG、conductance/PCIA、Integrated Hessians、PEFA 和随机/范数基线；不同 reference 信息条件必须分组报告。
- **干预：** 预注册输入微扰和端口 patch/ablation，检验 PEFA 或 \(\Omega\) 排名能否预测 Endpoint 图变化、目标 logit 变化或路由重分配。相关性证据与因果干预证据分开。
- 做目标、参考、路径、模型随机化和小扰动稳定性检查；统计单位以 image 为主，先逐图聚合再做区间或检验。

**产物与门槛**

- 冻结 pilot root、任务终态、验证报告、资源账本和 claim-level `SUPPORTED / NOT_SUPPORTED / INVALID` 表。
- 至少同时满足“数学闭合、负控制检出、成本可承受、相对简单基线有增量、预注册干预有预测力”，才允许将 PEFA 升为主线候选。
- 若只有闭合而无增量效用，保留数学结果并签发 `NOT_SUPPORTED_EMPIRICAL_VALUE`；不得事后换指标、删样或扩大样本制造成功。

## 步骤 6：做主线决策、正式生产与论文交付

**工作**

- 根据步骤 1–5 的冻结证据选择唯一主定位：
  1. `PEFA_FOUNDATIONAL_CANDIDATE`：对象、守恒和实证增量均成立；
  2. `PORT_RESOLVED_SYSTEMATIZATION`：数学组合有价值，但基础操作已有先例；
  3. `ENDPOINT_EXTENSION_ONLY`：PEFA 无稳定增量，保留 Endpoint 主线和负结果。
- 只有 pilot 门槛通过后才冻结正式样本量并运行生产；正式结果不得反向修改定义、阈值或定位规则。
- 论文按“Endpoint 已知基线 → PCIA/conductance 一阶边界 → PEFA 形成归因 → 路由曲率 → 干预证据”组织；每条主张回链到协议、代码、环境、资产、统计量和不可变结果。
- 公开失败情形、路径/参考/图依赖、非光滑边界、计算代价和非因果限制；同步方法、实验、附录与可复现包。

**最终通过门槛**

- 新颖性、数学正确性、端口忠实性、数值闭合、实证效用和成本六个维度分别判定，不能以其中一个 PASS 代替其他维度。
- 若证据只支持“系统化/统一实现”，论文和项目名称必须同步收缩；不得把 PCIA 或 PEFA 描述为与 IG 并列的新基础归因法。
- 最终交付必须包含 prompt-to-artifact 审计、逐主张证据索引、可复现命令、失败收据和 go/no-go 决策。

## 四、立即执行边界

下一项工作仅为**步骤 1：碰撞查新与合同冻结**。在其通过前：

- 不启动步骤 2–6；
- 不运行正式 GPU 或读取正式 outcome；
- 不把既有 Endpoint/Path 结果改名为 PCIA/PEFA 证据；
- 不在论文中使用“全新基础归因量”措辞。

本规划的第一决策点不是“如何把 PEFA 做大”，而是先证明它没有被现有方法等价覆盖，并给出能够失败的数学与实证判据。
