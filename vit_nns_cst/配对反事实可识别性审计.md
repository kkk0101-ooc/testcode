# NNS-CST 配对反事实可识别性审计

日期：2026-09-22  
阶段：N0  
主问题：前景物体固定时，背景上下文语义的变化如何影响 ViT 表征、贡献和行为  
裁定：`IDENTIFIABLE`（设计层面；N2 必须做测量验证）

## 1. 结论与边界

至少一个语义变化对照和一个同强度非语义变化对照可以由当前资产构造：

- **semantic edit**：同一 recipient 前景像素、mask、尺度、位置和目标类别不变；只把背景从语义层 $g_+$ 换为不同语义层 $g_-$，例如与物体类别一致的场景换为冲突场景；
- **matched null edit**：同一 recipient 前景及同一合成管线不变；背景仍留在 $g_+$ 内，但更换背景实例或施加语义保持的 photometric/render 变化，并在编辑面积、像素距离、色彩、频谱、边界和压缩统计上与 semantic edit 匹配。

因此 N0 的设计级 `IDENTIFIABLE` 门成立。它只说明可以提出一个会失败的识别实验，不说明现有图像已经满足匹配，也不说明模型存在相关行为。N2 必须在隔离 pilot 中测量 semantic label 可靠性、低级差异重叠、合成伪影和模型行为。若不能形成有共同支持的 semantic/null matched sets，终态必须是 `NO_GO_NOT_IDENTIFIABLE`；不能放宽阈值、删掉不利 pairs 或把非配对自然图替代为正式反事实。

本研究识别的是**对构造图像实施背景语义干预时，模型输出和内部对象的效应**。它不自动识别人类视觉机制、自然数据生成过程或未干预总体中的因果效应。

## 2. 因果对象

对 source-level unit $i$ 定义：

- $O_i$：前景物体 identity、像素、几何、尺度、位置和 mask；
- $C_i$：冻结的目标 object class 与 classifier margin；
- $G_i$：背景语义层，例如 `CONGRUENT`、`INCONGRUENT`；
- $B_i$：具体背景 donor identity；
- $L_i$：低级变化向量，包括编辑面积、RGB/色差、$L_1/L_2$、SSIM/LPIPS 候选、空间频谱、边界梯度和压缩统计；
- $A_i$：合成管线与伪影，包括 alpha band、inpainting/fill、resize、interpolation、codec 和随机种子；
- $X_i(G,B,A)$：由冻结 producer 构造的输入；
- $Y_i$：冻结 object-class margin 或其他预注册模型行为；
- $H_{i,\ell}$、$P_{\ell,c}$、$s_{\ell,c}$：层激活、仅由 discovery 学得的语义投影和冻结 readout。

主处理不是“任意换一张背景”，而是 $G:g_+\to g_-$。$B$、$L$、$A$ 是必须平衡或显式测量的 nuisance。目标效应限定在低级共同支持区域 $\mathcal M$：

$$
\tau_Y = \mathbb E_i\left[
Y_i(G=g_-)-Y_i(G=g_+)
\mid O_i,C_i, L_i\in\mathcal M, A_i=a_0
\right].
$$

为估计语义变化相对非语义变化的增量，预注册 paired contrast：

$$
\tau_Y^{\mathrm{sem|null}} =
\mathbb E_i\left[\Delta_i^{\mathrm{sem}}-\Delta_i^{\mathrm{null}}\right],
$$

其中两种 $\Delta$ 共用相同 recipient 和 target，且其 $L$ 在冻结容差内匹配。表征、NNS 定位和 intervention 使用同一 source-level pairing，不把 token、layer、rank 或多个 donor 当独立样本。

## 3. 主四臂配对设计

每个 recipient 前景构造四个均经过同一 producer 的版本，避免“原图未合成、处理图已合成”这一管线混杂：

| 臂 | 背景语义 | 背景实例/处理 | 用途 |
|---|---|---|---|
| `S0_BASE_COMPOSITE` | $g_+$ | donor $b_0$，按统一 alpha/resize/render 合成 | 统一处理后的基线 |
| `S1_SEMANTIC_SWAP` | $g_-$ | donor $b_s$，跨语义层 | 语义变化 |
| `N1_WITHIN_STRATUM_SWAP` | $g_+$ | donor $b_n\ne b_0$，语义层不变 | 背景实例/像素变化 null |
| `N2_RENDER_NULL` | $g_+$ | 对 $b_0$ 做语义保持的颜色、频谱或压缩/渲染变化 | 管线和低级强度 null |

`N1` 是最低必需的同强度非语义对照，`N2` 用来拆分 donor instance 与 renderer artifact。semantic pair 与 null pair 只在冻结的 $L$ 匹配规则下进入估计；匹配失败记为不支持，不允许按模型输出补选 donor。

建议同时生成反向 donor 平衡版本：让同一 donor 在不同 recipient 中轮换，避免某一背景实例固定对应 treatment。每个 source family 的所有版本只属于一个 split。

## 4. 因果对比表

| 对比 | 保持不变 | 改变 | 主要混杂 | 控制与失败门 |
|---|---|---|---|---|
| 同前景、换背景 | 前景像素/几何、mask、目标类别、producer | 背景语义与背景实例 | 边界融合、全局颜色、texture、donor identity | 四臂统一合成；跨层 semantic swap 与层内 null swap 在 $L$ 上匹配；无共同支持则失败 |
| 同背景、换前景 | 背景 donor 与 producer | 物体语义 | 物体面积、位置、遮挡、类别 margin 定义 | 仅作 secondary family；在 mask 面积、位置、形状与 target mapping 上匹配；不用于替代 primary |
| 一致/冲突背景 | 同一前景与 object class | context congruence | 数据集先验、背景标注、编辑质量 | 背景标签 outcome-blind 双人标注/外部 ontology；类别分层；盲化质量审计 |
| null edit | 语义层、前景、target、producer | 背景实例或压缩/渲染细节 | null 仍可能改变微弱语义，或强度不可匹配 | 语义保持复核；多维低级距离共同支持；未匹配者不进入 formal pair |

## 5. 处理构造和冻结规则

### 5.1 前景固定

1. 使用外部 ImageNet-S mask，不使用模型 attention/NNS 选择区域。
2. 对所有四臂复制同一前景 RGB、mask、位置、缩放和 alpha band。
3. mask 边缘处理、resize、插值、颜色空间和最终编码完全一致。
4. 不允许按模型 margin 或 activation 选择 mask erosion/dilation。边缘敏感性只作为预注册 robustness family。

### 5.2 背景语义

背景标签在任何 model outcome 前冻结。最低标签为 `CONGRUENT`、`INCONGRUENT`、`AMBIGUOUS`，其中 `AMBIGUOUS` 不进入 formal comparison。背景 crop 需在去除 donor foreground 后标注；不能因 donor 原图类别推断实际可见背景语义。

正式标签需满足预注册的双人独立标注与分歧裁定，或使用可审计外部 scene ontology。标注者只看用于标注的背景，不看模型输出、层、NNS 或候选效应。类条件 congruence 表必须在 validation 前冻结。

### 5.3 同强度 null matching

每个 edit 记录低级向量

$$
L=(q_{\mathrm{area}},d_{1},d_{2},d_{\mathrm{color}},d_{\mathrm{freq}},d_{\mathrm{edge}},d_{\mathrm{codec}}).
$$

“同强度”不是单个 $L_2$ 相等。N2 在不知道模型结果的条件下，为 semantic edit 从 null pool 选择满足所有预注册 caliper 的候选；选择键仅含 source lineage、semantic labels、producer parameters 和 $L$。若需使用 LPIPS 等学习指标，它只能作为编辑强度 covariate，模型、版本和权重须预先登记，且不得是研究中的 ViT checkpoint。

在 formal 阶段，matching rule、calipers、tie-break、最大复用次数和 unmatched policy 均在 outcome 前冻结。报告各维度 standardized mean difference、support overlap 和 unmatched 数；不能只报告一个平均距离。

### 5.4 生成伪影

所有臂均重走完整 producer。`N2_RENDER_NULL` 对同一语义背景施加可调强度、语义保持的非语义扰动，用以估计 alpha boundary、resize、color harmonization 和 codec 效应。额外保存 edit boundary ring，使定位结果可分别在 foreground、background interior 和 boundary ring 评价；边界显著不能计为语义定位成功。

## 6. 可识别性假设与可检验诊断

| 假设 | 含义 | N2/N3 诊断 | 失败处理 |
|---|---|---|---|
| Consistency | 同一 registry 条目唯一确定生成图；重复生产 bytes 或数值摘要一致 | producer version、seed、参数、input hashes；重复构建 | `INVALID_PRODUCER` |
| Positivity/common support | 对主要 object strata 均存在 $g_+$、$g_-$ 和匹配 null donor | 每类/stratum donor 数、$L$ overlap、unmatched rate | `NO_GO_NOT_IDENTIFIABLE` 或缩小预先允许的 estimand；不得事后换概念 |
| Semantic validity | $g_+$ 与 $g_-$ 确实改变预定语义，null 保持语义 | outcome-blind 双标注、agreement、盲测 | `NO_GO_NOT_IDENTIFIABLE` |
| Low-level exchangeability | 匹配后 treatment 与 null 的低级差异可比 | 多维 balance table、classifier 仅用 $L$ 预测 arm 的能力 | 重新设计 pilot；confirmation 前失败 |
| Artifact parity | treatment 与 null 经过同一合成机制，伪影不携带 arm label | boundary/codec statistics；仅 artifact 区域的 arm classifier | `NO_GO_NOT_IDENTIFIABLE` |
| No outcome-guided selection | pair、donor、caliper 和 QC 不使用模型 outcome | manifest field whitelist、访问日志、独立 validator | 污染 group 永久退出 confirmation/replication |
| Source independence | 同源及所有派生版本不跨 split | source ID、image hash、donor ancestry、edit lineage 全图去重 | `INVALID_COHORT` |
| Interference bounded | 一个 pair 的构造不依赖其他 pair 的模型结果；donor 复用被限制和成组重采样 | donor reuse ledger；source/donor 双层 sensitivity | 调整独立单位或不作总体推断 |
| Target stability | 同一 object target/margin 在各臂含义一致 | 固定 class mapping 和 margin；不按预测类别换 target | `INVALID_TARGET` |

这些假设不能由 N0 的文件存在性证明。`IDENTIFIABLE` 是“存在可执行的验证路径”，不是“所有识别假设已满足”。

## 7. 主要混杂与否证对照

| 风险 | 会造成的假阳性 | 必需否证对照 |
|---|---|---|
| 背景像素差远大于语义差 | projector 学到颜色/texture/频谱 | $L$-matched within-stratum null；只用 $L$ 的 arm classifier |
| alpha 边缘或 inpainting seam | NNS 热图沿物体边缘，看似定位准确 | render null；boundary ring 单独评价；mask erosion/dilation robustness |
| donor identity 泄漏 | 特定 donor 被当成语义 | 多 donor、donor 轮换、donor-held-out validation |
| object category 与 congruence 绑定 | 类别先验被误当背景机制 | 同 object source 的配对；类别分层重采样；每类双语义 donor |
| 合成图 off-manifold | 干预效应来自不自然输入 | 盲化质量门、自然度诊断、剂量曲线、过强 edit 排除规则预注册 |
| probe/data leakage | selection 数据上的可分性虚高 | discovery/validation/confirmation 严格拆分；source+donor lineage 去重 |
| subspace non-uniqueness | 任意方向 patch 都有效 | projector 换基测试、random same-rank、PCA/CAV、orthogonal complement、Makelov 型反例 fixture |
| generic damage | erasure 降低所有输出 | paired injection 与 erasure、dose、non-target concepts/classes、same-norm random control |
| output-guided donor selection | treatment 被人为挑成强效样本 | donor selection 字段白名单与 seal；任何 outcome exposure 永久降级 |

## 8. 从输入到机制的分层判定

识别结论必须依次通过，不能跳步：

1. **编辑有效**：semantic label 改变，null label 保持，且低级/伪影达到共同支持；
2. **行为存在**：semantic-null paired contrast 在预注册 margin 上超过最小实际幅度；否则 `NO_BEHAVIOR_TO_EXPLAIN`；
3. **表征成立**：held-out projector 超过单 head/channel、PCA、CAV/probe 和 random same-rank；
4. **输入 grounding**：Path NNS 对真实 edit region 的定位超过 pixel difference、gradient norm、attention、relevance 基线，并排除 boundary ring；
5. **贡献闭合但不止闭合**：semantic/complement complete-cut 恢复总归因，同时 projector identity 有独立效度；
6. **传输预测**：局部 JVP/VJP 对 held-out 有限 intervention 有预测力；
7. **因果中介**：injection/erasure 双向、剂量化、相对同秩同范数 controls 特异，并保持非目标行为。

前一层通过不保证后一层。workflow 完整也不等于科学支持。

## 9. 数据隔离与独立单位

- primary 独立单位是 recipient `source_group_id`。同一 recipient 的 semantic/null variants、多个 donor、层、token、rank、剂量必须一起重采样。
- donor reuse 产生交叉依赖时，formal analysis 至少做 recipient cluster 与 donor cluster sensitivity；若 donor 过少，不能声称 source-level 独立。
- 一个 source 作为 recipient 或 donor 被 pilot/validation/outcome 查看后，其自身及所有派生版本都不得进入 confirmation/replication。
- 现有 `confirmatory_holdout` 路由保持封存。N0 不把它自动指定为 NNS-CST confirmation；N3 需在未读 outcome 前生成独立 cohort 和 pair seal。
- 任何人工质量审核本身构成图像 exposure；审核 split 和审核者访问必须入 ledger。

## 10. N2 最低测量门

N0 不替 N2 预设数值阈值，但 N2 必须在 outcome-blind protocol 中先冻结并实测：

1. background semantic 双标注一致性与 ambiguous rate；
2. 每个主要 category/stratum 的 donor availability；
3. semantic 与 null 的多维 $L$ overlap、balance 和 unmatched rate；
4. blind edit quality、boundary artifact 和 render-null diagnostics；
5. source/donor lineage 零交叉；
6. primary model 的 semantic-null 行为差异及最低实际幅度；
7. 不用 RGB、只用 $L$ 或 artifact crop 预测 treatment arm 的可分性；
8. producer 重现性和 validator 独立重算。

如果语义变化和同强度非语义变化不能同时通过前六项，N2 终态为 `NO_GO_NOT_IDENTIFIABLE`。如果编辑可识别但模型没有预注册行为效应，终态为 `NO_GO_NO_BEHAVIOR`。两者不得混淆。

## 11. 门裁定

`IDENTIFIABLE = true`，因为当前 mask/source 资产允许在同一前景、几何、target 和渲染管线下构造跨背景语义层的 semantic swap，并以层内 donor swap 与 render null 构造至少一个同强度非语义对照；低级差异、伪影、donor 和类别混杂都有明确、可失败的测量。

该裁定附带以下硬条件：

- 背景语义标签和 congruence ontology 必须 outcome-blind 冻结；
- 正式 pair 生成前必须存在 closed lineage schema 和独立 validator；
- semantic/null 必须在预注册多维低级指标上存在共同支持；
- 任何 outcome-guided donor、pair、caliper 或 QC 选择使对应 source family 永久退出 confirmation/replication；
- N2 实测失败时必须诚实改判，不得用更多搜索或更宽阈值恢复。
