# NNS-CST 相关工作与新颖性矩阵

日期：2026-09-22  
阶段：N0  
检索截止：2026-09-22  
裁定：`NOVELTY_CANDIDATE`

## 1. 结论

NNS-CST 的基础组件均已有明确先例。概念方向、低秩或稀疏特征、activation patching、分布式子空间干预、输入归因、隐藏单元 conductance、自动 circuit discovery 和 ViT relevance propagation 都不能单独构成创新。特别是 DAS/Boundless DAS 已经学习分布式对齐子空间并实施 interchange intervention，Makelov 等人则证明一次 subspace patching 可以产生错误的语义解释。

截至检索截止日，尚未定位到一项工作把下面六个对象绑定为**同一个冻结且可审计的视觉语义对象**：

1. 由严格配对反事实及同强度非语义对照识别子空间；
2. 以投影算子而非任意基向量为主对象，主指标对子空间内换基不变；
3. 对冻结语义读出计算输入坐标的 Endpoint/Path NNS；
4. 在合法 complete cut 上把最终输出贡献分成 semantic/complement 并验证闭合；
5. 用 JVP/VJP 描述 attention、MLP、residual 间的局部子空间传输；
6. 用配对注入和擦除检验必要性、充分性、剂量关系与目标特异性。

因此保留一个窄的、组合式但可证伪的系统候选。这里的 `NOVELTY_CANDIDATE` 不等于“首个”、不证明方法有效，也不允许把 Endpoint、IG、complete-cut、probe 或子空间 patching 重新命名为新算法。若后续发现已有方法在同一冻结对象上覆盖上述联合性质，N1 前必须改判 `NO_GO_NOVELTY`。

## 2. 审计口径

- 检索对象包括同行评审论文、正式论文页面、作者代码和截至截止日可检索的预印本。预印本只用于判断邻近性，不与同行评审证据等同。
- “代码可用”只说明存在公开实现或本地可复用基础设施，不证明实现与论文完全等价。
- “数据规模”记录论文所用数据层级或作者报告的范围；本轮没有复现实验。
- 没有模型加载、图像解码、训练、推理、NNS 计算或 outcome 查看。
- 这是有界检索，不是对所有论文、版本或未公开工作的穷尽性否定证明。

## 3. 相关工作矩阵

| 方法族与正式来源 | 方法对象与代表公式 | 代码、数据规模与验证 | 已有工作已经做了什么 | NNS-CST 仍需证明什么 |
|---|---|---|---|---|
| TCAV/CAV：Kim et al., ICML 2018 | 在层激活上训练概念方向 $v_C$，计算 $S_{C,k,\ell}(x)=\nabla_{h_\ell}f_k(x)^\top v_C$，TCAV score 为正方向导数比例 | 官方 TensorFlow TCAV；论文在 ImageNet 分类器等任务上用多组概念样本和随机概念做统计检验 | 概念方向和输出敏感性早已存在 | 配对反事实是否支持稳定的低秩投影；它是否优于同容量 probe/CAV，并被模型因果使用 |
| CBM、probe、PCBM：Koh et al., ICML 2020；Yuksekgonul et al., 2022 | 显式 $x\to \hat c\to \hat y$，或在冻结表示上学习 $\hat c=w^\top h$ 后以概念预测类别 | 有公开实现；覆盖 CUB 等带概念标注数据和多种视觉/表格任务；以概念/任务准确率、干预和编辑验证 | 可解释概念瓶颈、线性概念 probe 和概念干预均已有 | 不把可解码性当机制；需要 held-out 表征优势、完整贡献和特异的双向干预 |
| Network Dissection：Bau et al., CVPR 2017 | 将单元响应阈值掩码与语义分割掩码比较，代表量为 $\operatorname{IoU}(M_u,M_c)$ | 公开代码/数据；在场景 CNN 和 Broden 概念标注上评估单元语义对齐 | 单 neuron/channel 与视觉概念的空间对应已有系统测量 | 证明分布式、可旋转子空间优于单元对象，并避免由阈值或数据集概念词典产生的假专门化 |
| Feature Visualization 与 neuron attribution：Olah et al., Distill 2017；Captum NeuronGradient/Input×Gradient | 优化 $x^*=\arg\max_x h_u(x)-R(x)$，或计算 $x\odot\nabla_x h_u$ | 有 Distill/OpenAI 参考实现和 Captum API；主要以合成可视化、自然样本和定性/扰动检查验证 | 神经元目标的合成可视化、输入梯度和 Gradient × Input 均非新对象 | 对冻结子空间读出给出外部 mask 定量定位，并与像素差、梯度范数、attention 等基线比较 |
| 视觉/多模态 SAE：PatchSAE (arXiv:2412.05276)、SAE-V (arXiv:2502.17514) | 以稀疏码 $z=\phi(W_eh+b_e)$ 重构激活，最小化 $\lVert h-W_dz\rVert_2^2+\lambda\lVert z\rVert_1$ | 作者代码/检查点的可用性因项目而异；在图像 patch/token 或多模态激活上以重构、稀疏度、可视化和下游解释评估 | 视觉或多模态表征中发现稀疏特征已经存在 | 配对因素识别的投影是否比 SAE 特征更稳定；语义是否经真实边传播并具有成对因果效应 |
| Prisma 与 ViSAE：Prisma (arXiv:2504.19475)、ViSAE (arXiv:2606.06664) | 对视觉模型表征训练/分析稀疏特征，并将特征连接到空间概念、行为或干预 | 截止日可检索为视觉 SAE 工具/预印本；覆盖多个视觉模型或层，常用 feature visualization、检索、稀疏度和干预 | 视觉 SAE 的规模化工具、跨层特征审计和概念干预进一步缩小了空白 | 不声称“首次在 ViT 上训练 SAE”；比较其特征对象与配对、基不变子空间在稳定性和因果特异性上的差异 |
| Transcoder/crosscoder：Dunefsky et al., arXiv:2406.11944；视觉 CLT arXiv:2604.13304 | 用稀疏 $z$ 近似模块映射 $F(h)$ 或共同编码多层/多模型表示，例如 $\hat F(h)=W_dz+b$ | 有语言模型 transcoder/crosscoder 工具；视觉扩展在大规模 token/层上以重构、稀疏 circuit 和干预验证 | 稀疏特征跨模块、跨层连接和 feature circuit 已有先例 | 局部传输不能仅由 decoder 权重定义；需对冻结 $P_{\ell,c}$ 用真实 Jacobian/JVP 测量，并与有限干预一致性比较 |
| Causal mediation：Vig et al., NeurIPS 2020 | 用自然直接/间接效应比较介入前后输出，例如 $\operatorname{NIE}=Y_{x,M(x')}-Y_{x,M(x)}$ | 公开 NLP 代码；在 transformer 语言任务上按层/单元做中介效应统计 | 内部表征的因果中介分析并非新概念 | 在视觉配对中冻结处理、mediator、outcome 和 matched controls；不能把相关性或单次 patch 当作中介证据 |
| Causal tracing/activation patching：Meng et al., NeurIPS 2022；Zhang & Nanda, 2024 | 在 clean/corrupt 输入间替换激活，效应 $\Delta_e=F(x^{\mathrm{patched}(e)})-F(x^{\mathrm{corrupt}})$ | ROME/TransformerLens/NNsight 等实现；从单提示到大规模提示集；以恢复分数、编辑和消融验证 | clean/corrupt patching、causal tracing 及其 metric/corruption 敏感性已被系统研究 | 预注册视觉 pair 和编辑管线；同时验证 injection/erasure、剂量、随机同秩和正交补，报告 off-manifold 风险 |
| DAS/Boundless DAS：Geiger et al., TMLR 2024；pyvene | 学习旋转 $R$ 和子空间掩码 $P$，在 $R$ 坐标中做 interchange intervention，再以 interventional behavior 训练/验证 | pyvene 可用；在合成任务和语言模型上以 interchange intervention accuracy 验证分布式因果对齐 | 可学习分布式子空间和子空间 interchange intervention 已直接覆盖 NNS-CST 的核心邻域 | 差异不能是“再做一次 DAS”；需要视觉配对控制、基不变投影、输入 grounding、complete-cut 记账和局部传输的联合预测 |
| Subspace patching 反例：Makelov et al., ICLR 2024, arXiv:2311.17030 | 展示 patching 效应可由包含非语义方向的子空间或数据/读出零空间产生，干预成功不唯一识别语义表征 | 作者分析代码；在语言模型案例上用构造与实证反例验证 | 单次成功 patch 不足以证明子空间的语义身份 | 必须用独立 paired labels、held-out 稳定性、换基不变性、双向干预、orthogonal/random controls 和特异性共同排除幻觉 |
| ACDC：Conmy et al., NeurIPS 2023 | 以候选计算图为对象，反复 patch/删除边并按效应阈值保留 circuit | 官方代码；在已知或人工审计的 transformer tasks 上比较恢复与 circuit 大小 | 自动删除边、得到稀疏 causal circuit 已有 | 不以稀疏图外观为目的；预注册合法 complete cut，并区分结构闭合、归因大小和语义身份 |
| EAP/EAP-IG/AtP*：Syed et al., 2023；Kramár et al., arXiv:2403.00745 | 一阶 attribution patching $\widehat{\Delta}_e=(a_e^{b}-a_e^{a})^\top\nabla_{a_e}F$；IG 版本沿 activation path 积分 | 有 TransformerLens 等实现；在多类语言 circuit 任务上以 verified recall、真 patching 排名和成本验证 | 梯度近似 edge patching、积分路径和 Q/K 饱和修正已有 | NNS-CST 的 JVP/VJP 不是新梯度技巧；需验证其预测真实有限子空间 intervention，不能以一阶分数代替因果效应 |
| Visual circuit discovery：Automatic Discovery of Visual Circuits (arXiv:2404.14349)、Vi-CD (arXiv:2604.14477) | 在 ViT 节点/边或视觉特征上做自动筛选、patching、归因和 circuit 组织 | 截止日包含公开预印本/实现线索；在 ImageNet 类视觉数据和 ViT 上以性能恢复、稀疏度、空间或概念对齐评估 | ViT 自动 circuit discovery 已存在，不能声称首次发现视觉 circuit | 证明同一 paired semantic projector 能跨模块输运，并超过节点/边显著性和视觉恢复基线 |
| ViT concept circuits：arXiv:2609.09055 | 把稀疏/概念特征组织成 ViT 内部概念 circuit，并关联视觉输入与输出 | 截止日为新近预印本；检索时间过近，结论和代码成熟度需在 N1 前复查 | 直接占据“ViT 概念 circuit”表述，显著提高重叠风险 | 禁用宽泛“concept circuit novelty”；只保留严格 paired projector、complete-cut accounting 和双向特异干预的联合可检验差异 |
| IG 与 Conductance：Sundararajan et al., ICML 2017；Dhamdhere et al., 2018 | $\operatorname{IG}_j=(x_j-x_{0j})\int_0^1\partial_jF(x_0+\alpha(x-x_0))d\alpha$；conductance 把路径归因流经隐藏单元 | Captum 等实现；在 ImageNet/Inception、文本和化学模型上以敏感性、完整性、消融和特征选择验证 | path attribution、隐藏单元 attribution flow 和 completeness 都已有 | Path NNS 必须如实定位为内部标量 IG；新增候选仅是冻结语义对象与完整切面/传输/干预的绑定 |
| Transformer attribution/decomposition：Chefer et al., CVPR 2021；GlobEnc (NAACL 2022)、ALTI (EMNLP 2022)、DecompX (ACL 2023) | attention rollout/relevance 或逐层分解残差贡献，常写为 token mixing/贡献矩阵连乘与归一化 | 多数有作者代码；在文本 transformer 与 ViT 上以删除/插入、分类忠实度、分割/定位等验证 | attention、skip connection、token mixing 和逐层贡献传播已有大量方法 | complete-cut NNS 必须与 attention map、rollout、decomposition 基线比较；闭合不等于语义或因果有效 |
| AttnLRP：Achtibat et al., ICML 2024 | 为 attention 和非线性层定义 LRP 规则并守恒地传播 relevance | 官方 LRP-eXplains-Transformers；覆盖 LLM、ViT、多架构，以 faithfulness 和 latent attribution 验证 | 输入与 latent transformer attribution、近单次 backward 的高效传播已有 | 不宣称首次 latent attribution；必须用真实 endpoint/path Jacobian 和 complete-cut 合同说明对象差异，并实证比较 |
| LibraGrad：Mehri et al., CVPR 2025 | 通过 backward path pruning/scaling 修正 transformer 梯度流不平衡 | 官方代码；论文报告 8 架构、4 尺度、5 数据集，以 faithfulness、completeness error 和 segmentation AP 验证 | ViT 梯度路径修正及强 attribution baseline 已有 | 把 LibraGrad/普通梯度列为定位基线；NNS-CST 不通过修改 backward rule 赢得概念身份 |
| NNS：Dou et al., Neural Networks 2023 | 由输入坐标初始化 neuron-level 相关量并沿网络传播，CNN filter 图按激活加权聚合 | 未定位到官方代码；本地只有论文公式转录和独立实现；论文在 CNN/视觉样本上做神经元级可视化 | NNS 名称、neuron-level visualization 和基础传播思想已有 | Endpoint 明示为 $x\odot\nabla s$；Path NNS 明示为内部标量 IG，不提出基础归因新颖性 |
| 本地 NNS-ViT Endpoint/complete-cut | Endpoint：$x\odot\nabla_xs(x)$；Path：相对 $x_0$ 的内部标量 IG；complete cut 将同一输出的输入归因分配到合法切面 | 本地有 ViT target/edge capture、complete-cut VJP、JVP/VJP 和 intervention 基础设施；历史结果不继承为 NNS-CST 科学证据 | 端口注册、ViT edge 捕获、闭合检查和有限干预已有可复用代码 | 新实现需增加 semantic-subspace estimator、basis-invariant projector、pair generator 和 transport contract；用新数据重新验证 |

## 4. 组件级新颖性账本

| 候选表述 | 是否可声称新颖 | 原因 |
|---|---:|---|
| 在 ViT 上训练 SAE 或线性概念 probe | 否 | PatchSAE、SAE-V、Prisma、ViSAE、TCAV/CBM 已覆盖 |
| 对一个方向或子空间做 activation patching | 否 | DAS/Boundless DAS、causal tracing 和 subspace patching 已覆盖 |
| 用 Gradient × Input 或 IG 画概念热图 | 否 | Input×Gradient、IG、Conductance、AttnLRP 等已覆盖 |
| 自动找 ViT 节点/边并组成 circuit | 否 | ACDC、视觉 circuit discovery、Vi-CD 已覆盖 |
| 用 JVP/VJP 或一阶梯度预测边效应 | 否 | EAP、EAP-IG、AtP* 已覆盖相邻对象 |
| 用配对反事实识别视觉语义低秩投影 | 候选，不单独声称 | 接近 CAV、DAS 和 paired activation differences；必须靠严格 control covariance 与 held-out 性质区分 |
| 将冻结投影同时绑定输入 grounding、完整切面、局部传输和双向有限干预 | 候选 | 尚未定位同构联合合同；价值来自可证伪的跨证据一致性，不来自各组件 |

## 5. NNS-CST 的可证伪增量

候选增量只在以下主张能够被预注册并独立失败时成立：

| 编号 | 新的可验证性质 | 最低反证条件 |
|---|---|---|
| N-A | 配对语义信号形成对子空间内旋转不敏感的 projector | 换基改变主结果，或同秩 PCA/CAV/random 达到同等 held-out 表现 |
| N-B | projector 的输入来源与外部编辑区一致 | 不超过像素差、gradient norm、attention、LibraGrad/相关 attribution 基线 |
| N-C | semantic/complement 在合法 cut 上闭合，且 semantic 份额有独立语义效度 | 只闭合但不优于随机/错配 projector，或跨 cut 语义结论不稳定 |
| N-D | 局部 transport 对预注册模块的有限 intervention 有预测力 | JVP/VJP 传输分数不能预测 held-out injection/erasure，或不优于简单 edge baseline |
| N-E | 子空间对目标行为具有双向、剂量化、特异中介效应 | 仅单向 patch 有效，随机同秩/正交补同样有效，或非目标行为同幅改变 |

任何一个性质阴性都必须按主张独立报告。形式闭合、漂亮热图、probe accuracy 或一个成功 patch 不能替代这些性质。

## 6. 门决策与后续约束

`NOVELTY_CANDIDATE = true`，理由是未发现完整覆盖上述联合、冻结、可证伪对象的现有工作。但该结论具有三项约束：

1. 论文表述必须写成“联合测量与干预合同的候选增量”，不得使用“首个”“全新基础算法”或“首次视觉 concept circuit”；
2. N1 冻结数学合同时必须逐项对照 DAS/Boundless DAS、Makelov 反例、视觉 SAE/概念 circuit 和 EAP 系列；
3. 若任一正式来源已经同时满足 N-A 至 N-E，立即裁定 `NO_GO_NOVELTY`，不得靠改名保留项目。
