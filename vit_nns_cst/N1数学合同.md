## 1. 对象和符号

模型层 \(\ell\) 的激活写为 \(A_\ell\in\mathbb R^{B\times T_\ell\times D_\ell}\)，固定布局为 BATCH_TOKEN_CHANNEL。token 集合只能显式取 CLS_ONLY、PATCH_ONLY 或 CLS_PLUS_PATCH_14X14。不同 topology 之间必须给出冻结的一一 token 映射；隐式 resize、删除或按数组位置猜测均签发 TOKEN_ALIGNMENT_ERROR。

同一 source_group_id 的语义正负配对差异为

\[
\Delta a_{i,t}=a^{+}_{i,t}-a^{-}_{i,t}.
\]

每个 source 内 token 权重 \(w_{i,t}\ge 0\) 且和为 1；完成 token 聚合后，每个 source 等权。配对差本身完成 source 内中心化，不再减去跨 source 均值，以免消去方向一致的处理效应。

## 2. 计算图和端口身份

每个注册模型必须覆盖：

- patch embedding 后 residual stream；
- 每个 block 的 norm1/norm2 输入和输出；
- 每个 attention head 的 query、key、value 输入，value，pre-projection output；
- attention merged output 与 attention identity residual use-edge；
- MLP expand、activation、contract output 与 MLP identity residual use-edge；
- CLS、final norm 输入/输出和 classifier margin。

一个真实 use-port 的身份是以下字段的联合值：model_id、checkpoint_sha256、graph_revision、block_index、branch、producer_tensor、consumer_operator、input_slot、invocation_index。

port_id 必须由这些字段的规范串 SHA-256 前缀导出。模块名或 hook 顺序均不是身份。producer 相同但 consumer、slot 或 invocation 不同的 use 是不同端口。manifests/model_port_registry.json 是 N1 冻结注册表；它只描述受支持的标准 unfused timm ViT 计算图，不声称已经运行这些模型。

合法 cut 必须让从输入到目标的每条路径恰好交一次。漏边签发 CUT_MISSING_EDGE，重复端口签发 DUPLICATE_PORT，端口字段或派生 ID 不一致签发 PORT_IDENTITY_MISMATCH。

## 3. 控制协方差和子空间估计

由同强度 null edit 的差异向量形成 nuisance span \(U_0\)。N1 参考实现通过

\[
r_i=(I-U_0U_0^\top)\Delta a_i
\]

先去除低级控制方向，再计算加权二阶矩

\[
C=\frac{\sum_i w_i r_i r_i^\top}{\sum_i w_i}+\lambda I.
\]

语义子空间 \(U_r\) 是 \(C\) 的前 \(r\) 个正特征方向，rank 候选固定为 1、2、4、8、16，ridge 候选固定为 0、1e-8、1e-6；只能在 N2 pilot 中选择。N1 合成 fixture 的 rank 和 ridge 已在 fixture registry 预先固定，不做结果驱动搜索。

若控制方向为零或线性依赖，签发 NEAR_SINGULAR_CONTROL_COVARIANCE；控制后语义完全消失签发 NO_SEMANTIC_AFTER_CONTROL。所有正式生产 reduction 必须转 float64 并使用 math.fsum 或确定性等价实现。

## 4. 换基不变量和层间拓扑

对行正交基 \(U\)，语义投影算子为

\[
P_U=U^\top U,\qquad a_{sem}=P_Ua,\qquad a_\perp=(I-P_U)a.
\]

任何 \(r\times r\) 正交换基 \(R\) 产生 \(RU\)，但投影不变。两个等 rank 子空间的相似性为

\[
S(U,V)=\operatorname{tr}(P_UP_V)/r,
\]

距离为

\[
d(U,V)=\lVert P_U-P_V\rVert_F/\sqrt{\max(r_U,r_V)}.
\]

因此不能对单个基向量的编号或符号提出语义主张。不同 \(D_\ell\) 的层分别保留原生维度投影，跨层只能通过注册 transport map 比较，不能 padding 或截断后直接比较。

## 5. frozen readout

readout 只在 probe_train 或明确登记的 N2 pilot_discovery 上拟合。N1 参考形式为投影后的正负类均值差：

\[
q=\frac{P_U(\mu_+-\mu_-)}{\lVert P_U(\mu_+-\mu_-)\rVert_2},
\quad b=\tfrac12(q^\top\mu_++q^\top\mu_-),
\quad s(a)=q^\top a-b.
\]

序列化必须记录 method、weights、threshold、rank、dimension、合同 digest 和训练 split。validation 只选择已冻结候选，不得 refit；confirmation 不得更新 readout。

## 6. 传输和贡献合同

局部传输对象是冻结端口间 Jacobian 对语义方向的 JVP。N1 解析对象为

\[
\text{identity}: y=x,
\quad \text{linear}:y=Mx,
\quad \text{residual}:y=I x+B x,
\quad \text{two-branch}:y=M_1x+M_2x.
\]

后续生产实现必须同时暴露 JVP 与 VJP 接口，并检验 \(v^T(Ju)=(J^Tv)^Tu\)。N1 只冻结接口并验证解析传输，不实现或运行 timm/Torch adapter。

对同一合法 complete cut，输入坐标 \(x_j\) 与目标梯度 \(g_j\) 的贡献拆分为

\[
c_j^{sem}=(P_Ux)_j g_j,\qquad
c_j^{\perp}=((I-P_U)x)_j g_j.
\]

必须逐坐标满足 \(c_j^{sem}+c_j^{\perp}=x_jg_j\)，再检查标量求和闭合。先聚合再比较不能替代逐坐标闭合。这个 fixture 检查的是 N1 解析分解，不把 Gradient × Input 重新命名为新算法，也不声称已经完成 Path NNS。

## 7. 干预合同

对 recipient \(a_r\)、donor \(a_d\) 和剂量 \(\alpha\)：

\[
\text{erase}(a_r)=a_r-\alpha P_Ua_r,
\]

\[
\text{inject}(a_r,a_d)=a_r+\alpha(P_Ua_d-P_Ua_r).
\]

同 rank 随机子空间和正交补是强制对照。每项干预同时报告 absolute shift、相对于 recipient norm 的 shift、非有限检查及训练分布支持诊断；超过冻结 manifold limit 签发 OFF_MANIFOLD_INTERVENTION，不得把结果解释成因果证据。

## 8. typed failures

| failure | 触发条件 |
|---|---|
| RANK_EXCEEDS_DIMENSION | rank 小于 1 或大于通道维度 |
| RANK_DEFICIENT | 请求的正特征方向不存在 |
| ZERO_PAIR_DIFFERENCE | 所有配对差为零或 readout 差为零 |
| NO_SEMANTIC_AFTER_CONTROL | nuisance residualization 后无信号 |
| NEAR_SINGULAR_CONTROL_COVARIANCE | 控制方向为零或近线性依赖 |
| NONFINITE_VALUE | 输入或输出出现 NaN/Inf |
| MISSING_TOKEN | 激活维度或所需 token 缺失 |
| TOKEN_ALIGNMENT_ERROR | token 映射不是一一对应 |
| PORT_IDENTITY_MISMATCH | 端口字段、slot 或派生 ID 不一致 |
| DUPLICATE_PORT | 同一冻结端口重复出现 |
| CUT_MISSING_EDGE | 冻结端口集合缺项 |
| OFF_MANIFOLD_INTERVENTION | 干预位移超过冻结诊断界限 |

## 9. N1 fixture、mutation 与门禁

manifests/n1_fixture_registry.json 在执行前冻结七组 fixture：二维子空间换基、分布式 multi-head、亮度控制、四种解析传输、semantic/complement complete-cut、四种干预和 typed failures。

四项 mutation 必须分别检出：漏边、重复边、Q/K/V slot 交换和错误 token 对齐。determinism probe 在两个独立进程中使用不同 PYTHONHASHSEED，比较科学 payload 的 canonical SHA-256。微基准在同一 CPU 进程中重复 rank-2 子空间、transport 和 attribution 200 次，记录 wall time、CPU time、peak RSS 和 throughput；它用于 N2 成本规划，不是科学 PASS 门。

通过条件为：

1. N0 validator 当前重跑通过；
2. 数学合同、端口注册表、子空间合同、fixture registry 和 closed schemas 均冻结且互相绑定；
3. 七组解析 fixture 的全部预注册 assertion 通过；
4. 四项 mutation 都得到精确的预期 typed failure；
5. 两个独立 determinism payload digest 相同；
6. 微基准完成且资源数值有限；
7. 独立 standard-library validator 从原始 registries、测试记录和源码重算上述事实；
8. 完成 prompt-to-artifact 审计；N2 保持未开始。

只有全部满足才签发 PASS_N1_ANALYTIC_CONTRACT_AND_SKELETON。该终态只证明 N1 数学、接口和合成测试闭合，不证明真实模型适配、子空间存在、语义可识别、行为效应、NNS 定位或因果中介。
