# NNS-CST N2-V2 输入可识别性恢复协议

日期：2026-09-22  
状态：`FROZEN_INPUT_ONLY_BEFORE_ASSET_ACCEPTANCE_AND_MODEL_ACCESS`  
当前授权：只允许收口旧 N2、冻结 V2 输入协议、盘点新资产和准备盲审；N3、模型加载、行为门、激活、子空间、NNS、传输和干预均未授权。

## 1. 旧 N2 的不可变收口

`N2_R1C_20260922` 的科学终态保持 `NO_GO_NOT_IDENTIFIABLE`。R1、R1B、R1C 的 evidence root、旧协议、旧完成审计和 terminal receipt 不作任何修改。V2 不是 R1D，也不允许把旧 root 改判为 GO。

当前唯一成立的科学结论是：

> 现有 ImageNet donor 加前景移除/inpainting 的配对生产方案，不能可靠隔离背景语义与编辑伪影。

该终态不能推出模型没有背景依赖、不存在稳定语义子空间、NNS-CST 无效或模型行为门失败。旧 N2 从未加载 checkpoint，也没有运行行为、激活、Endpoint、Path NNS、JVP 或干预。

R1C 中 7 个 artifact-failed pair 只进入 producer 回归排除清单。它们及其全部 source lineages 永久不得成为 V2 科学 pilot、validation、confirmation 或 replication 样本。

## 2. V2 恢复对象与继承边界

V2 只恢复数据生成和输入可识别性。以下对象按 `config/n2_v2/input_identifiability_contract.json` 继承并保持 dormant：

- N1 数学合同和通过的 N1-R3 前驱；
- primary 模型及 checkpoint identity，但本输入阶段不得打开或反序列化 checkpoint；
- 唯一语义轴 `AQUATIC_TO_NON_AQUATIC_CONTEXT`；
- target raw logit、行为门、层、rank、readout、Path NNS、传输和干预定义。

在 identifiability freeze receipt 签发前，任何继承的模型侧对象都没有执行授权。V2 输入门通过后也必须停止，由新的显式授权启动行为门。

## 3. 背景资产路线

优先资产是天然 `scene-only` 水域和非水域背景。这里的 `scene-only` 是图像本身没有需要擦除的显著 donor 前景，不是先对物体图做 inpainting 后得到的背景。类别名、数据集标签或低 mask fraction 不能替代逐图盲审。

次选资产是受控渲染场景。该路线必须另行冻结 renderer、相机、几何、光照、材质、随机种子和许可证；水域与非水域两臂使用同一渲染管线，结论仅限渲染域。天然场景与渲染场景不得在同一 primary estimand 中混用。

明确禁止：

- 调 Telea 半径、换 inpainting 算法或继续寻找更小 donor mask；
- 任何 donor foreground removal、content-aware fill、generative fill 或局部修补；
- 使用 R1/R1B/R1C 的 recipient、donor、派生图或 source lineage；
- 按模型 logit、activation、NNS 或干预结果选择资产、caliper 或 pair。

若没有足够的 scene-only 或受控渲染资产，V2 停在 `BLOCKED_INPUT_ASSETS`。此时只能另立关联性问题，或停止当前语义轴；不得声称识别了背景语义机制。

## 4. 候选池、替补和低级共同支持

输入门至少需要 12 个未暴露 recipient、每个背景语义层至少 24 个合格 scene-only 资产。最终科学集合固定为 8 个 pair，另有 4 个按 outcome-blind 排序冻结的替补 recipient。

候选筛选和 pair 选择只允许读取 lineage、双盲标签、producer 参数和冻结低级差异向量。选择目标、tie-break、最大复用和替补顺序在 contract 中冻结。最终 8/8 pair 必须全部通过每一项 low-level caliper 及 aggregate caliper，`max_unmatched_rate=0`；不得再用 25% unmatched 上限。替补只能在模型访问前按冻结顺序用于替换输入门失败项。

来源多样性要求每张 background asset 在最终集合中最多使用一次，且不得让一个 scene source 固定对应某个 arm。所有祖先和派生版本按 source group 一起隔离。

## 5. 双人独立盲审

两名审查者必须在随机编号、隐藏 source、类别、arm 和模型信息的 review cards 上独立工作，互不讨论。每张 card 分别标注：

1. 背景语义：`AQUATIC_CONTEXT`、`NON_AQUATIC_CONTEXT` 或 `AMBIGUOUS`；
2. 是否存在显著非背景物体；
3. 是否存在 donor-removal residual、暗斑或填充纹理；
4. 是否存在异常合成边界；
5. 是否存在其他可识别 arm identity 的视觉线索。

语义标签的原始一致率必须至少为 0.95，Cohen's kappa 必须至少为 0.80。任何 `AMBIGUOUS` 或语义分歧都不能进入接受集。任一审查者在任一 artifact 项上标记 `true`，对应 asset/pair 立即失败；事后讨论或 adjudication 不能把它翻回接受。reviewer identity、review bundle digest、起止时间和“未讨论”声明必须分别封存。

## 6. 输入门状态机

顺序固定为：

1. 验证旧 N2 terminal bindings，生成旧 lineage 排除账本；
2. 验证新资产的许可、source lineage、历史 exposure 和 scene-only 候选资格；
3. 生成随机盲化 cards，并取得两份独立 review bundle；
4. 计算原始一致率和 Cohen's kappa，应用 artifact union-reject；
5. 只在审查合格池中运行冻结的低级 matching；
6. 冻结最终 8 pair 和 4 个替补，独立重算全部 caliper；
7. 仅当上述项目全部通过时签发 identifiability freeze receipt；
8. 停止，等待单独授权行为门。

任何前置失败都不得加载模型。允许的输入阶段状态为：

- `PASS_INPUT_IDENTIFIABILITY_FROZEN`；
- `BLOCKED_INPUT_ASSETS`；
- `BLOCKED_INDEPENDENT_REVIEWERS`；
- `BLOCKED_INPUT_ASSETS_AND_REVIEWERS`；
- `NO_GO_NOT_IDENTIFIABLE`；
- `INVALID_LINEAGE`；
- `INVALID_PROTOCOL`.

## 7. 当前 I0 root

`evidence/n2_v2_i0_20260922` 是独立、输入层-only 的 fresh root。当前本地没有通过审计的独立 scene-only 资产包，也没有两名已分配并完成审查的独立 reviewer，因此 I0 必须记为 `BLOCKED_INPUT_ASSETS_AND_REVIEWERS`。这不是对 V2 科学假设的阴性裁定。

I0 的正确完成条件是：旧 N2 仍可验证、V2 contract 和 schemas 闭合、旧 lineages 被排除、7 个旧失败 pair 被登记为回归拒绝样本、模型访问为零、后续门未运行。获得新资产和两名 reviewer 后必须新建 fresh root，不得原地把 I0 改成 PASS。
