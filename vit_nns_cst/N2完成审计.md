## 3. 独立验证覆盖

`validate_n2.py` 不读取 producer 的 PASS 作为最终依据。它重算 contract 和 source manifest SHA-256、24 个 source 的 split/use-policy、跨 split source-group 交集、NPZ 文件 SHA-256、数组 shape/dtype、32 个 arm array digest、8 个 matching score、15 类 low-level metric 值、foreground 逐像素恒等、blind QC 失败计数、语义 reviewer 缺口以及 sequential stop。pre-terminal validation 有 31 项；terminal 存在后再核验 14 个绑定和 N3 停止门，共 33 项，全部通过。

独立重算显示：

- 6/8 数值 matched，unmatched rate 25%；
- quantized raw input 与 producer metric 的最大差 0.00042781688733145584；
- recipient foreground 腐蚀区的四臂最大差 0；
- blind QC 7/8 失败，artifact failure rate 87.5%；
- 双人独立语义标签只完成 1 人，agreement 不可估计；
- checkpoint deserialization、inference、behavior outcome、activation、NNS 和 intervention 均为 0。

机器可读完成审计另以 closed schema 固化 30 项 prompt-to-artifact requirement；后置机制项目的状态是 `CORRECTLY_NOT_RUN_AFTER_GATE_FAILURE`，不被误记为缺失或已执行。

## 4. 结论与边界

N2 已完整执行到第一个强制停止门，并得到 `NO_GO_NOT_IDENTIFIABLE`。这个终态说明当前本地 donor/producer 不能把目标背景语义变化与非背景物体残留、inpainting 痕迹及未完成的双人标签可靠性分开。它不是 `NO_GO_NO_BEHAVIOR`，因为模型行为从未读取；也不是 `NO_GO_SUBSPACE_UNSTABLE` 或 `INVALID_NUMERICAL`，因为相应阶段未运行。

不得使用 R1/R1B/R1C 的 pairs 进入 N3、confirmation 或机制主张。任何未来恢复必须是新的研究版本，先获得新的独立背景资产或可靠标注与 artifact-free producer，再以尚未看过的新 pilot 数据开始；不能在本 root 上继续换 donor、放宽 QC 或运行模型。
