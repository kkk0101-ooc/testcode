# NNS-CST N1-R3 恢复修订

日期：2026-09-22  
状态：FROZEN_BEFORE_R3_EXECUTION

N1-R2 已有 registries、七组解析 fixture、四项 mutation、determinism、微基准和 validator 均通过，但完成审计发现 frozen readout 的实现 bundle 未携带 N1 数学合同要求的训练 split 与合同 digest，也没有专用 closed schema。R2 因而以 FAIL_N1_R2_READOUT_SERIALIZATION_INCOMPLETE 封存，不能作为 N1 PASS。

R3 的唯一方法变更是补齐 readout 序列化合同：

1. 新增 closed readout bundle schema；
2. serializer 强制接收并写入 fit_split 和 64 位 contract_sha256；
3. 明确 validation_refit_allowed=false 和 confirmation_refit_allowed=false；
4. 增加冻结 readout fixture，检查字段闭合、合同绑定、split 绑定、正负 score 方向和重算一致性；
5. 继承且从头重跑 R2 的全部七组 fixture、四项 mutation、双进程 determinism、微基准、单元测试和独立重算。

R3 不改变子空间估计器、rank、ridge、数值阈值、端口对象、干预对象或 N2 边界。R3 仍为 CPU-only、synthetic-only，不读取正式图像，不加载 checkpoint，不使用 GPU，不执行 N2。
