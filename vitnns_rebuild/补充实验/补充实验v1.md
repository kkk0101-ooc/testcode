目前稿件的证据链已经较完整，不建议再扩展大规模 Endpoint–Taylor 排行榜。新增实验应集中回答三个尚未解决的问题：

1. M3/M4 的层深规律究竟来自**训练**还是 ViT 架构与初始化；
2. 这些规律是否依赖 **ground-truth logit**；
3. M3 的空间扩展能否与 M4 的 routing/residual 分解在**同一目标**上直接联系。

在新增实验前，还有一项需要优先修正的比较问题。

# 一、首先修正：随机区域基线的绝对值顺序

你现在写：

> 随机基线先平均 20 条 signed effect 曲线，再取绝对值积分。

即当前计算近似为：

\[
\left|
\frac1R\sum_{r=1}^R e_r
\right|.
\]

而确定性方法先对 effect 取绝对值。公平的随机基线应计算：

\[
\frac1R\sum_{r=1}^R|e_r|,
\]

或者先为每个随机重复计算 absolute-effect AUC，再对 AUC 求平均。

由 Jensen 不等式：

\[
\left|\mathbb E[e]\right|
\le
\mathbb E[|e|],
\]

当前实现会因不同随机区域的正负效应相互抵消而系统性压低 random baseline。你的 Endpoint−random 优势只有约 \(0.0011\)–\(0.0107\)，因此这一修正可能影响“Endpoint 是否优于随机”的解释。

## 建议

重新计算并报告：

1. mean absolute random AUC；
2. random AUC 的重复间分布；
3. Endpoint−random 配对差；
4. Taylor−random 配对差；
5. 20 个随机重复是否足够稳定。

这不是可选补充，而是比较公平性修正。它不会影响 Endpoint 与 Taylor 的主要结论，但可能改变 Endpoint 相对 random 的结果。

# 二、最高优先级：训练模型与随机初始化模型对照

这是当前最重要的缺口。

你已经发现：

- token-channel Endpoint 随层深空间扩展；
- routing scale 随层深增加；
- Value-only approximation 在深层恶化；
- attention 与 MLP residual 呈现相反趋势。

但现有两个模型都是训练后的 ViT，无法区分这些规律来自：

- ViT 的全局 attention 架构；
- 初始化和残差参数化；
- 模型训练；
- 具体 checkpoint。

## 2.1 实验设计

对 ViT-B/16 和 DeiT-S/16 各建立至少 3 个随机初始化种子，保持：

- 架构；
- patch size；
- hidden dimension；
- head 数；
- normalization；
- 输入图像；
- token/channel 抽样规则；

与训练模型一致。

可使用缩小版设置：

- 32 或 64 张冻结图像；
- 12 个 blocks；
- 每层 8 个 tokens；
- 每层 16 个 channels；
- 全部 heads；
- 不需要执行大规模 finite replacement。

## 2.2 复核指标

### M3 指标

- normalized spatial entropy；
- own-token locality；
- normalized distance；
- map cancellation；
- CLS−patch entropy。

### M4 指标

- routing scale；
- Value-only Endpoint error；
- JVP discrepancy；
- attention residual identity scale；
- MLP residual identity scale；
- output–identity patch TV；
- path cancellation。

## 2.3 主要比较

\[
\Delta_{\mathrm{trained-random}}
=
T_{\mathrm{trained}}-T_{\mathrm{random}}.
\]

例如比较：

\[
(\text{late}-\text{early})_{\mathrm{trained}}
-
(\text{late}-\text{early})_{\mathrm{random}}.
\]

统计时应将随机种子纳入层级，不要把三个随机模型的所有单元直接当作独立样本。

## 2.4 可以回答什么

如果随机初始化模型也出现相同层深趋势：

> 该规律至少部分是 ViT 架构、初始化和参数化诱导的局部 Jacobian 属性，不能完全归因于训练。

如果训练模型趋势明显更强：

> 该结构趋势存在架构基础，并受到训练显著强化。

如果随机模型没有相同趋势：

> 结果更有力地支持这些模式与学习后的参数结构有关。

## 2.5 建议再加一个级联参数随机化 sanity check

由于 Endpoint 包含输入乘子 \(x\)，图像可能在视觉上保留输入纹理，即使参数已随机化。因此建议对少量样本执行 cascading randomization：

1. 从最后一个 block 开始重新初始化；
2. 逐步向前随机化更多 blocks；
3. 比较训练模型与随机化模型的 Endpoint map。

比较指标：

- patch absolute distribution cosine；
- signed cosine；
- Spearman；
- top-patch overlap；
- entropy/locality 变化。

这能回答：

> Endpoint 图是否真正依赖学习参数，而不仅仅因为乘上输入而看起来像原图？

这一实验也构成标准的 saliency sanity check。

# 三、第二优先级：目标稳健性实验

M4 的结构结论主要以 frozen ground-truth logit 为目标，因此目前严格成立的是：

> ground-truth-logit-conditioned local Jacobian pattern。

对错误分类图像，ground-truth logit 并不是模型实际选择的类别。

## 3.1 建议目标

至少比较：

1. ground-truth logit：
   \[
   F_{\mathrm{GT}};
   \]
2. clean-top1 logit：
   \[
   F_{\mathrm{top1}};
   \]
3. top1 margin：
   \[
   F_{\mathrm{top1}}-F_{\mathrm{runnerup}}.
   \]

前两个目标在正确分类图像上相同，因此必须分别报告：

- 正确分类子集；
- 错误分类子集。

Margin target 能在所有图像上提供不同于单一类别 logit 的决策相关目标。

## 3.2 需要复核的结果

不必重新运行全部 M3，只需复核 M4 的核心指标：

- routing scale 深度趋势；
- Value-only error；
- JVP discrepancy；
- saturation relation；
- attention residual identity scale；
- MLP residual identity scale；
- output–identity patch TV。

## 3.3 推荐最小规模

如果成本较高：

- 使用 100 张图；
- blocks 0、5、11；
- 全部 heads；
- 两个模型；
- GT、top1、margin 三个目标。

## 3.4 解释方式

如果趋势跨目标一致，可以说：

> 所观察到的 attention/residual 层深规律不局限于 ground-truth logit。

如果只在 GT target 中明显，应收缩为：

> 这些模式是目标条件化的，并随所解释的类别或决策量而改变。

# 四、第三优先级：M3–M4 同目标匹配桥接

目前：

- M3 使用 token-channel 标量；
- M4 主要使用类别 logit；
- 两者只能进行模型级描述性衔接。

因此你还不能说：

> 深层 routing 增强导致 token-channel Endpoint 空间扩展。

## 4.1 推荐设计

选择一个冻结小子集：

- 每模型 32 张图；
- blocks 0、5、11；
- 每层 4 个 patch tokens＋1 个 CLS；
- 每个 token 8 个 channels。

对同一个 post-block token-channel 目标：

\[
s_{b,t,c}=h_{b,t,c},
\]

在其上游 attention 和 residual 中计算：

- full Endpoint；
- routing Endpoint；
- value Endpoint；
- identity Endpoint；
- branch Endpoint。

这样 M3 的空间指标和 M4 的结构分解针对同一个标量目标。

## 4.2 主要指标

比较 full 与 value-only：

\[
\Delta H_{\mathrm{routing}}
=
H(E^{\mathrm{full}})
-
H(E^{\mathrm{value}}),
\]

\[
\Delta L_{\mathrm{routing}}
=
L(E^{\mathrm{full}})
-
L(E^{\mathrm{value}}),
\]

\[
\Delta D_{\mathrm{routing}}
=
D(E^{\mathrm{full}})
-
D(E^{\mathrm{value}}),
\]

以及：

\[
\operatorname{TV}
\left(
p(E^{\mathrm{full}}),
p(E^{\mathrm{value}})
\right).
\]

Residual 方面比较：

\[
\operatorname{TV}
\left(
p(E^{\mathrm{output}}),
p(E^{\mathrm{identity}})
\right).
\]

## 4.3 需要保持的解释边界

即使 full 比 value-only 更分散，也只能写：

> 对同一目标，包含 routing differential 的完整局部 Jacobian 具有比 Value-only approximation 更分散的 Endpoint 分布。

仍不能写：

> Q/K routing 在有限因果意义上导致了全局表征。

但它会显著加强 M3 与 M4 之间的机制连接。

# 五、建议补充：前向特征图与学习图像的定量关系

摘要写道：

> 逐层可视化进一步展示学习图像与前向特征图的对应关系。

目前主要证据是并列可视化。严格说，这能说明两者可以配对观察，但还没有证明“对应关系”的强弱。

有两个选择：

1. 增加定量实验；
2. 把措辞改成“并列展示二者的差异与互补关系”。

如果保留“对应关系”，建议增加以下分析。

## 5.1 比较对象

对 energy target：

\[
s_{b,c}
=
\frac12\sum_t h_{b,t,c}^2,
\]

定义前向空间分布：

\[
q_t
=
\frac{h_{b,t,c}^2}
{\sum_jh_{b,j,c}^2}.
\]

将 Endpoint absolute mass 下采样到 patch 网格：

\[
p_t
=
\frac{
\sum_{i\in P_t}|E_{b,c,i}|
}{
\sum_i|E_{b,c,i}|
}.
\]

比较：

- Spearman；
- cosine similarity；
- Jensen–Shannon distance；
- top-\(K\) patch overlap。

## 5.2 负向控制

至少加入：

- 同层错误 channel 配对；
- 跨层配对；
- patch 空间随机置换；
- 随机 channel 配对。

如果正确的 feature–Endpoint 配对显著高于负向控制，才能说：

> 学习图像与其对应前向通道具有超出层级和空间基线的关系。

如果相关性较低，也不是方法失败，而说明：

> 前向 activation map 与 input-dependence map 是互补而非等价的对象。

## 5.3 避免 selection bias

不能只分析每层“空间方差最大”的展示通道。应使用：

- M3 冻结抽样 channels；
- 或另一组预先冻结 channels。

否则高方差选择会人为提高空间结构的可见性。

# 六、建议补充：通道和图像抽样稳健性

M3 每层抽取 32 个 channels，空间趋势虽然在 100/100 图上方向一致，但仍可能依赖冻结 channel 列表。

## 6.1 低成本方案

如果保存了所有单元级统计，可对现有数据执行：

- channel bootstrap；
- token-stratum bootstrap；
- image bootstrap；
- leave-one-block-out；
- leave-one-spatial-stratum-out。

报告 late−early 趋势对抽样单元的敏感性。

## 6.2 更强方案

再冻结两组独立 channel seeds，每层各 32 个 channels，在较小图像子集上重复 M3：

- 32 或 50 张图；
- 两个模型；
- 相同 token strata。

比较三组 channel samples 的：

- entropy trend；
- locality trend；
- distance trend；
- CLS−patch trend。

这可以支持：

> 观察到的空间扩展不是由特定 channel 抽样偶然产生。

这样可以部分分离：

- 架构；
- 模型规模；
- 训练方法；
- checkpoint。

- spatial broadening；
- routing scale；
- Value-only error；
- residual identity scale；
- output–identity TV。

不需要重复全部有限替换实验。

# 十、不建议继续做的实验

- pointing game；

Figure 19–20 的功能性比较已经足以说明对象差异。

M3 的 6,144-unit audit 已经足够支撑抽样结论。更合理的是验证抽样稳健性，而不是把存储和计算扩展到百万级目标。

## 4. 不建议为让 Path IG 通过而反复调整协议

应如实报告：

> Path IG 在冻结实现和最多 512 点下未通过校准门。

# 最终建议

当前稿件不缺更多“Endpoint 是否比某方法更强”的实验，真正缺的是对机制发现来源的辨别。最值得增加的主实验是：

> **随机初始化／参数随机化控制。**

它能直接回答当前讨论中已经承认、但尚未解决的核心限制：

> 层深空间扩展、routing 增强和 residual 分化究竟是训练学到的规律，还是 ViT 架构本身产生的 Jacobian 几何。

其次，应量化前向 feature map 与 Endpoint 的关系；否则摘要中的“对应关系”最好改成：

> “逐层并列可视化展示了前向响应与局部输入依赖的差异和互补性。”

完成随机基线修正、训练控制、目标稳健性和 feature–Endpoint 定量分析后，这篇论文的实验闭环会更完整：不仅说明 Endpoint 如何定义、如何闭合和观察到什么，还能进一步说明这些规律从何而来、是否依赖目标，以及学习图像与实际前向响应究竟具有何种关系。
