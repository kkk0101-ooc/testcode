# NNS ViT unified paper figures R2

Redesigned: Figures 1–4, 6–7, 11, 13–14. Figures 5, 8–10 and 12 are inherited byte-for-byte from R1.

- [Figure index](figure_index.md)
- [Chinese captions](captions_zh.md)
- [English captions](captions_en.md)

PNG (400 dpi), PDF and SVG are supplied for all 14 figures. Quantitative values come from sealed CSV/JSON sources. Method diagrams use one fixed original image and explicitly illustrative grids.

The renderer requires CPU only and does no new model inference, intervention or hypothesis testing. Run scripts/render_nns_vit_unified_paper_figures_r2.py from a fresh root. Use --draft only while the root has no terminal receipt. Run scripts/validate_nns_vit_unified_paper_figures_r2.py after actual visual review. A sealed root is immutable.
