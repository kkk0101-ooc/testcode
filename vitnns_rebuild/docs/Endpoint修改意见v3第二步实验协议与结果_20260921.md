# Endpoint 修改意见 v3 第二步：实验协议与结果

状态：`PROTOCOL_FROZEN_BEFORE_EXECUTION`。本文件是第二步的统一活文档；执行完成后在同一文件追加结果，不另建碎片化计划文档。

## 1. 目标与边界

本阶段只执行 `修改意见/修改意见v3.md` 第二步的三项必须实验：多幅度有限干预、Q/K/V 路径总体统计、至少五组独立 channel/token 抽样复现。不新增展示性热图，不把结构闭合当作有限干预证据，不把 bootstrap 当作独立抽样，也不把训练 checkpoint 与随机初始化差异写成训练因果效应。

## 2. 多幅度有限干预

- 样本、目标、层、head 和 reference 与 ENDPOINT-M1 相同：每模型 400 图、冻结 GT logit、12 blocks、全部 attention heads、normalized-zero 和 blur 两种 reference。
- 幅度固定为 $\alpha\in\{0.05,0.1,0.25,0.5,1.0\}$。对 head 输出 $z$ 使用

$$
z_\alpha=(1-\alpha)z_{\mathrm{clean}}+\alpha z_{\mathrm{ref}}.
$$

- 真实有限效应为 $e_\alpha=F(z_{\mathrm{clean}})-F(z_\alpha)$；同一 clean 点的一阶 Taylor 预测为

$$
p_\alpha=\alpha\langle\nabla_zF,z_{\mathrm{clean}}-z_{\mathrm{ref}}\rangle.
$$

- 逐 component 保存 signed $e_\alpha$、signed $p_\alpha$、绝对误差 $|e_\alpha-p_\alpha|$。相对误差定义为 $|e_\alpha-p_\alpha|/|e_\alpha|$；真实效应精确为零时记 NA，不加 $\varepsilon$。
- 图内先对 components 取中位数；排序相关在每个图像、block 内比较 $|p_\alpha|$ 与 $|e_\alpha|$ 的 Spearman，再平均 12 blocks。图像是唯一推断单位。
- 只有 cohort 图像级绝对误差中位数随五个幅度单调不减，且多数图像满足相同方向时，才允许讨论“一阶近似误差随幅度增长”；否则保留第一步已收窄的 RQ4。

## 3. Q/K/V 总体统计

- 使用 ENDPOINT-M1 的每模型 400 图、冻结 GT logit、全部 12 blocks，分别计算 Q、K、V 类别目标路径图。
- 每条路径报告 absolute mass、normalized spatial entropy、cancellation。相对尺度为同一图像和 block 内该路径 absolute mass 除以 Q/K/V 三者 absolute mass 之和。
- 类别目标路径没有可定义的“目标 patch”。因此 normalized distance 固定为从 $14\times14$ absolute-mass 概率分布中独立抽取两点的期望欧氏距离，并除以最大网格距离 $13\sqrt2$：

$$
D=\sum_{i,j}p_i p_j\frac{\lVert r_i-r_j\rVert_2}{13\sqrt2}.
$$

  该量测量分布的空间扩散，不把图像中心或任一 patch 人为指定为原点。
- 每个 model–block–path–metric 在图内得到一个值，再跨图像报告中位数和 95% image bootstrap 区间。以 block 11 减 block 0 的图像级差为主要方向检查，两个模型同号才记为方向一致。

## 4. 五组独立 channel/token 抽样复现

- 使用 ENDPOINT-M3 的同一共享 100 图像/模型 cohort；每组重新、独立且 outcome-blind 地抽取 token 和 channel。
- 每组 token 为 CLS 加固定 $3\times5$ 空间 strata 中各一个 hash 抽样 patch，共 16 tokens；每个 model/block 独立 hash 抽取 32 channels。五个 namespace 均在运行前冻结。
- 每组重复 normalized entropy、own-token locality（减均匀面积基线）和 normalized target-patch distance。
- 每图先聚合目标单元，分别计算 late (blocks 8–11) 减 early (0–3)，以及 block 11 减 block 0。跨图像给出中位数和 95% bootstrap 区间；另外报告五组中位数的标准差、范围和预期方向一致率。
- 结论只能写为“在两个固定 checkpoint 的五组独立抽样目标中复现”，不因五组一致就改写为全部内部单元的普遍定律。
