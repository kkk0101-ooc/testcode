# R8：在一张图里看清正负贡献

Figure 2 改成“原图 → 指定 head → signed learning image → 同一区域放大”。
保持完整 Figure 1–14，另十三张和 50 张原图库 PNG 继承 R7。

采用 order 44 的 B0/H10，来源为 F3H 已保存的 float32 56×56 map。
这是在查看全部 144 个坐标并讨论正负重叠后作出的事后展示选择；不称为预注册、代表性或效果最好的 head。
该样本的 median-effect 身份仍来自主实验 B0/H9，与本图 H10 的选择无关。

红色表示相对灰色参考、沿积分路径累计的正贡献，蓝色表示负贡献，白色表示零。
全部区域和局部放大共用 sign(R)·log1p(9·abs(R)/L)/log(10)，L=max(abs(R))。
这个单调色彩变换只用于显示；源地图、符号和 cell 位置不变，不作双线性插值或平滑。
放大框固定为源 56×56 网格的行 4–19、列 0–15，右侧红/蓝分图也是这个框的同一组 cells。
两种符号使用同一色阶上限，正负分图用白色表示不属于该符号的 cell。
源图正负拆分必须满足：逐 cell 无重合，正部减负部精确恢复源图。

这里的符号是路径归因，不能直接替代“删掉这个区域后最终类别分数一定怎么变”的测量。
后续干预与总体结果仍使用各自正式实验的目标和地图。
