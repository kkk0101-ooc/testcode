# NNS_VIT_PATCH_DEPTH_SEMANTICS S4 prospective execution protocol

This protocol, including the S4-R1 and S4-R2 prospective initialization amendments, is frozen before any formal S4 JPEG or mask member is read. S4 executes only the 1,744 candidate_m4 records whose `S4_NNS`, `S4_occlusion`, `P1`, `P2`, `D1`, and `D2` flags are all true. It produces per-source NNS decomposition, P1 raw position-stratified permutation material, one shared P2 matched coordinate plan, and separately sealed primary and sensitivity occlusion outputs. It does not read S3 D2 prediction/error values and does not perform cohort-level estimation, confidence intervals, p-values, Holm correction, gatekeeping, or scientific decisions.

The immutable dependency topology is one `NNS_IMAGE`, one `OCCLUSION_PRIMARY`, and one `OCCLUSION_SENSITIVITY` unit per source. All workers share a source-major, dependency-aware ready queue. Claims are launch-scoped `O_CREAT|O_EXCL` files with file and directory fsync. Global terminals use same-filesystem temporary files and no-overwrite hard-link publication. A prior terminal is always skipped; a stale prior-launch claim never blocks recovery. Workers are long-lived and load the frozen model once.

At each fresh launch, GPUs are scanned once. Every eligible H20 (free memory at least 21,504 MiB and utilization at most 10 percent) is selected up to eight; if at least eight are eligible, exactly eight workers are required. Existing compute PIDs are recorded but do not disqualify a device. The selected UUID set is locked and fixed for the launch. `CUBLAS_WORKSPACE_CONFIG=:4096:8` is set before any Torch/CUDA import, and each worker verifies it before a matmul-plus-backward startup probe.

Formal archive access remains prohibited until the implementation tree is pushed, a second commit seals that tree, and the live remote branch is verified to contain the seal commit. After that gate, only the 1,744 selected JPEG and mask members may be materialized into the ignored S4 cache. Every member is checked for hash, byte count where frozen, and original geometry. No full archive extraction is allowed.

The numerical, preprocessing, target, P1/P2, typed-NA, retention, resource-accounting, and next-authorization details are closed in `config/nns_vit_patch_depth/s4_run_spec.json`. Time, cost, and resource estimates guide scheduling and reservation only; they cannot shrink the cohort or create a scientific failure. A PASS stops at S4 and proposes only `S5_D2_MISSING_CLASS_RECONCILIATION_GATE_ONLY`.
