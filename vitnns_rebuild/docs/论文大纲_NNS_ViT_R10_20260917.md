## 摘要口径

本文把 NNS 的 learning image 视角扩展到 Vision Transformer。方法将指定内部响应或类别 logit 相对参考输入的变化分配回原始输入坐标，并区分模块自身响应图与面向最终类别的成分图。固定 ViT-B/16 和冻结样本的真实计算展示 patch embedding、B0 attention、第一次 residual、B0 MLP、第二次 residual 和完整 class-logit learning image；并比较正确类别、最高竞争类别、两者 margin 与最低分输出单元。数值 completeness 与 residual additivity 用于检查计算。总体实验结论继续来自既有 D/E/F/X/Y/S 队列，而新增 Figure 32–35 仅是同一冻结图像上的方法展示。

## 1. 引言

ViT 内部包含 token、channel、head、branch、residual stream 和最终类别输出。普通 feature map 告诉我们内部值多大，但不直接保留每个值来自哪些输入位置。本文使用 learning image 把指定目标的变化分配回 224×224 输入坐标，并把可视化与干预、完整切分重构和分支统计联系起来。

贡献口径：

1. 定义适用于 ViT 内部标量和类别标量的输入坐标 learning image，并明确完整 attention 导数、reference、路径和显示规则。
2. 在真实冻结 ViT-B/16 上展示从 patch embedding 到 classifier logit 的前向链，而不是停在 B0 第一次 residual。
3. 对两处 residual add 分别执行逐像素加法检查；对所有展示目标执行 completeness 与积分阶数收敛检查。
4. 用既有干预、解释器比较、完整切分和深度分析说明 learning image 的评价用途，同时保留负结果、无效端点和探索性边界。
5. 用一个冻结样本比较正确类别、最高竞争类别、判别 margin 与按 clean logit 全局 `argmin` 选出的低分输出，避免把单一类别图误读为 classifier 的共同空间模板。

## 3. 所提方法

### 3.1 Learning image

对输入 $x$、参考 $x_0$ 和标量目标 $s$：

$$
L_s[i]=(x_i-x_{0i})\int_0^1
\frac{\partial s(x_0+\alpha(x-x_0))}{\partial x_i}\,d\alpha,
\qquad \sum_i L_s[i]\approx s(x)-s(x_0).
$$

RGB 带符号求和得到二维图。原始 signed 图用于对账；正部、signed-log、P99 和颜色映射仅是显示规则。

Figure 2 使用 Figure 30 的 B0 attention channel 255 原始数组，只显示正贡献 `max(L_s,0)` 的蓝底图，并复用 Figure 30 的逐面板 P99 规则。公式、响应变化和完整性仍针对未裁剪 signed 数组；当前目标的负贡献与完整 signed 视图可在 supplement/figure_30_signed 的 channel 255 中查看。

### 3.2 真实 ViT-B/16 前向链

$$
\text{image}\to\text{patch embedding + CLS + position embedding}\to
\text{Blocks }0\ldots11\to\text{final norm}\to\text{CLS}\to\text{classifier}\to\text{logits}.
$$

每个 block 为

$$
a_b=\operatorname{Attention}(\operatorname{LN}_1(h_b)),\qquad
r_b^{(1)}=h_b+a_b,
$$

$$
m_b=\operatorname{MLP}(\operatorname{LN}_2(r_b^{(1)})),\qquad
h_{b+1}=r_b^{(2)}=r_b^{(1)}+m_b.
$$

12 个 blocks 后：

$$
u=\operatorname{FinalNorm}(h_{12}),\qquad
\ell=W_{\mathrm{cls}}u_{\mathrm{CLS}}+b_{\mathrm{cls}}.
$$

当前冻结模型的 B0 MLP 为

$$
768\xrightarrow{\mathrm{fc1}}3072\xrightarrow{\mathrm{GELU}}3072
\xrightarrow{\mathrm{fc2}}768,
$$

最终 classifier 为 `Linear(768,1000)`，采用 CLS token。实现中保留 layer scale、drop path 和 dropout 节点；eval 模式关闭随机丢弃。

### 3.3 Patch embedding、attention 与第一次 residual

沿用 R9 的定义和真实图：Figure 25–27 给出解析对照；Figure 28–31 给出固定图像和通道的真实响应。B0 第一次 residual 位于 attention 后、MLP 前：

$$
L(r_0^{(1)})=L(h_0)+L(a_0).
$$

### 3.4 B0 MLP branch

Figure 32 固定通道 0、255、511、767，以该通道在 196 个 patch-token MLP 输出上的总和为目标：

$$
s_{m,c}(x)=\sum_{t=1}^{196}m_0(x)_{t,c}.
$$

上排为 224×224 输入坐标贡献图，下排为 14×14 signed MLP 输出值。LayerNorm、fc1、GELU、fc2、layer scale 和 drop-path 节点均在真实前向中。它解释 MLP branch 自身响应，不乘最终类别导数。

### 3.5 第二次 residual 与 B0 block output

Figure 33 使用相同通道和 token 聚合：

$$
s_{r^{(2)},c}(x)=\sum_{t=1}^{196}r_0^{(2)}(x)_{t,c},
$$

并在相同 reference、输入路径和数值积分下检查

$$
L_{s_{r_0^{(2)},c}}[i]
=L_{s_{r_0^{(1)},c}}[i]+L_{s_{m_0,c}}[i]
$$

对每个 RGB 输入坐标成立。这样真实模块展示覆盖完整 Block 0。

### 3.6 Final norm、CLS 与 classifier head

Figure 34 的目标不是一个 token/channel 网格，而是原图真实预测类别 235 的完整 logit：

$$
L_{\ell_{235}}[i]=(x_i-x_{0i})\int_0^1
\frac{\partial \ell_{235}(x_0+\alpha(x-x_0))}{\partial x_i}\,d\alpha.
$$

梯度经过全部 12 个 blocks、final norm、CLS 选择与 `Linear(768,1000)`。因此图版为“原图 → 完整 ViT/CLS/class logit → 一张 signed 224×224 learning image”，不画不存在的 14×14 classifier token 输出。

Figure 35 在同一路径下增加三个对照目标：最高竞争类别 174（Norwegian elkhound）、判别 margin $\ell_{235}-\ell_{174}$，以及 1000 个 clean logits 中全局最低的类别 171（Italian greyhound）。低分类别在查看 attribution 地图前按 `argmin` 冻结。四张 signed 图使用共同色标。

### 3.7 完整类别贡献的内部成分分解

沿用 R9 Figure 19–21 与 Stage X/Y 定义。内部 class-component map 使用下游类别导数；Figure 28–33 的 module-own-response map 不使用下游类别权重；Figure 34 则直接解释完整类别标量。三者在文中分别命名。

## 4. 实验与论文小结论

### 4.1 模型与样本设置

共同模型为冻结 ViT-B/16：224×224 RGB、16×16 patches、196 图像 tokens、768 channels、12 blocks、每 block 12 heads。新增展示仍使用冻结队列首图和灰色参考。

### 4.2 真实前向 learning image

**问题：** 同一输入能否从 B0 前半段继续追踪到完整 block，并最终解释真实类别 logit？

固定图像 `ILSVRC2012_val_00007922.JPEG`。B0 模块目标使用通道 0、255、511、767 和 196 patch-token 求和；classifier 目标固定为 clean argmax 类别 235。

**实现结果 M1-R10：** B0 新模块使用 128 点 Gauss–Legendre 积分。所有 MLP 与 block-output 目标满足 completeness；第二次 residual 的最大逐像素 RGB 加法误差为 $3.33\times10^{-16}$。R10 重新计算的第一次 residual 图与 R9 保存图逐元素完全一致。

完整类别路径更非线性，按固定阈值从 64/128/256/512/1024/2048 递增到 4096 点。4096 点相对 2048 点的地图 L1 变化为 $8.293\times10^{-4}$，completeness 绝对误差为 0.004874；clean logit 为 8.082624，灰色参考 logit 为 −0.384007，目标变化为 8.466630。原图预测类别仍为 235。

**配图：** Figure 28–31 为已有 patch/attention/第一次 residual；Figure 32 为 B0 MLP；Figure 33 为第二 residual / B0 output；Figure 34 为完整 classifier logit。它们共同把展示链延伸到真实 ViT 输出。

**分类输出对照 M3：** Figure 35 对比 class 235（German shepherd，正确类与 clean argmax）、class 174（Norwegian elkhound，runner-up）、margin $235-174$ 和 class 171（Italian greyhound，clean logits 全局最低）。clean logits 分别为 8.0826、7.6327、margin 0.4499 和 −2.9210。4096 阶相对 2048 阶的地图 L1 变化依次为 0.000829、0.000489、0.000393、0.001085，四个目标均通过 completeness。

**数据：** [R10-R1 模块计算记录](../reports/nns_vit_unified_paper_figures_r10_r1_20260917/module_compute_receipt.json) · [R10-R2 classifier 对照记录](../reports/nns_vit_unified_paper_figures_r10_r2_20260917/classifier_comparison_receipt.json) · [R10-R2 原始数组](../reports/nns_vit_unified_paper_figures_r10_r2_20260917/source_arrays)。

## 5. 讨论

### 5.1 从局部模块到完整模型

R9 的真实图回答到 B0 attention 与第一次 residual。R10 增加 MLP 和第二 residual，使 Block 0 闭合；class-235 图再把目标延伸到整个主干、final norm、CLS 和 classifier。模块图回答“该内部响应来自输入哪里”，classifier 图回答“最终类别 logit 的变化来自输入哪里”。Figure 35 进一步说明不同 classifier 输出不能共用一张类别图，真正贴近判别边界的是正确类相对最强竞争类的 margin 图。

### 5.2 Residual 是可核对的计算关系

第一次 residual 和第二次 residual 都在未着色原始贡献上逐位置相加。显示缩放不能用于验证加法；验证使用保存的 RGB float64 数组。

### 5.3 单图边界

Figure 28–35 固定同一输入。它们验证方法、坐标对应和数值重构，不代表总体通道语义、总体层趋势或总体类别机制。即使 Figure 35 包含正确类、相近犬种竞争类和低分类别，也不能从单图推断类别间的总体差异。总体结论只引用预先定义队列及其有效分母。

## 6. 结论

建议结论段：

> 本文将 NNS 的 learning image 视角用于 ViT，在统一输入坐标下描述内部响应和类别贡献。真实计算从 patch embedding、attention 和第一次 residual 延伸到 block 内 MLP、第二次 residual，并通过全部 blocks、final norm、CLS 与 classifier 到达类别 logit；正确类、竞争类、margin 与低分输出的对照进一步区分了类别目标。两处 residual 的逐像素重构和各目标的 completeness 检查建立了数值对应；既有干预与成分统计则限定了这些解释在冻结实验条件下能够支持的结论。
