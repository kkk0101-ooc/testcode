## 0. 题目、摘要与论文主结论

### 0.1 拟题

中文：**通过学习图像理解视觉 Transformer 的内部响应与贡献分配**。

英文：**Understanding Vision Transformers through Learning Images of Internal Responses and Contributions**。

关键词：Vision Transformer；Neural Network Scanner；learning image；内部归因；输入干预；贡献分解。

### 0.2 摘要结构

1. **研究问题。** ViT 的 token、head 和 residual 分支提供不同的内部计算视角，需要在统一坐标下描述内部响应与输入位置的关系。
2. **所提方法。** 继承 NNS 的 learning image 思想，以输入路径积分构造 ViT 内部响应图，并按完整计算切分描述最终类别贡献经过的内部成分。给出 patch embedding、attention 和 residual 的计算规则及真实输出。
3. **主要实验。** 对预定内部 head 进行 500 图细粒度干预，比较输入归因与同目标 patch-token 基线；研究尺度、层头和预测分层；独立比较类别解释器，并测量完整模型的分支贡献份额。
4. **主要结果。** 主实验 500/500 图像的配对忠实度差值为正，中位数 2.3082，95% CI [2.1111, 2.4452]；原生 patch 尺度的中位差值为零。完整类别分解显示 attention 和 MLP 的深浅分支份额分别变化 +0.1391 和 −0.2492。
5. **结论。** Learning image 将内部响应、输入位置和干预测量联系起来；观察结果依赖目标、尺度和内部坐标。

摘要优先保留正式干预和分支结果。多尺度稳定性解释与语义解码放在实验延伸节，并标明 post-hoc exploratory。

### 0.3 总论点与贡献

**总论点：** NNS-ViT 用输入坐标下的 learning image 查看内部响应和类别贡献的组织。它既支持逐模块观察，也能把空间图像转化为区域排序、分支重构和深度分配的可检验问题。

- **ViT 内部 learning image 的目标与计算。** 区分单元自身响应、固定 attention 的条件响应和完整类别成分，给出三个核心模块的对应关系。
- **计算关系的真实展示与验证。** 同一真实输入在 patch embedding、attention、residual 处均产生保留输入坐标的图，原始图值与响应变化对账；完整切分按成分重构总输入 IG。
- **内部解释的实证研究。** 通过 500 图干预、尺度和层头对照、50 图解释器比较，以及 100 图分支分析，报告不同问题的结果。

NNS、learning image、神经元图聚合与 residual 模型可视化来自 Dou 等人的原论文；路径积分和链式法则分解采用 IG、conductance/path attribution 的数学基础。贡献声明围绕 ViT 对象定义、实现对应和实证展开。

## 3. 所提方法

### 3.1 输入、输出与 learning image 定义

输入为冻结的已训练 ViT、图像 x、参考 x₀ 和目标 s；输出为保持输入坐标的 learning image。目标可以是单个 (token, channel) 响应，也可以是事先声明的通道或 head 聚合。

$$
L_s[i]=(x_i-x_{0i})\int_0^1
\frac{\partial s(x_0+\alpha(x-x_0))}{\partial x_i}\,d\alpha,
\qquad \sum_i L_s[i]\approx s(x)-s(x_0).
$$

RGB 带符号求和得到二维图。完整地图用于对账；正部、signed-log 与缩放属于显示规则。正部图的总量不等于完整响应变化。

**配图：Figure 2、15–17。** Figure 2 用真实输入，15–17 用手算例子解释一个数如何展开为位置图。

### 3.2 初始化与正常前向的对应

$$
S_i=(x_i-x_{0i})e_i,\qquad \sum_i S_i=x-x_0.
$$

线性目标使用权重组合输入位置种子；非线性 ViT 的系数沿完整输入路径变化。自动微分在完整输入上求导，无需把每张稀疏种子作为独立样本。

**配图：Figure 24（总览）、16（初始化）、17（线性生成）。** 上排正常响应和下排 learning image 使用同一组单元，虚线逐一对应。

### 3.3 Patch embedding

$$
h_{t,d}=\sum_{i\in P_t}W_{d,i}x_i+b_d+p_{t,d},
\qquad L_{h_{t,d}}[i]=\mathbf1[i\in P_t]W_{d,i}(x_i-x_{0i}).
$$

每个 token/channel 的直接线性贡献限制在对应 patch。偏置、位置编码保留在前向中；沿输入路径其直接变化为零。

**配图：Figure 25（计算）、29（真实输出）。** 真实图聚合一个通道的 196 个 patch-token 响应，因此覆盖全图；单个 token 的连接仍局部。

### 3.4 Attention

$$
Q=HW_Q,\ K=HW_K,\ V=HW_V,\quad
A=\operatorname{softmax}(QK^\top/\sqrt{d_h}),\quad O=AV,
$$

$$
dO=(dA)V+A(dV).
$$

完整响应图包含 Q/K 改变路由权重的影响及 Value 的影响，并计算 LayerNorm、输出投影。固定 clean attention 的 Value-path 是另一个明确的条件目标。

**配图：Figure 26（上下对应）、30（真实输出）、22（导数路线）。** Figure 26 的平均 Jacobian C 能组合终点输入图，是因为其上游 patch 映射为线性；非线性上游必须逐路径点组合导数后再积分。

### 3.5 Residual

$$
z=h+o,\qquad L_z=L_h+L_o.
$$

同一参考、同一路径、同一响应聚合下，先逐位置相加原始值，再着色。B0 第一次 residual add 位于 attention 后、MLP 前。

**配图：Figure 27（逐步相加）、31（真实输出）、28（三模块 progression）。** Figure 23 另解释带最终目标下游导数的成分图。

### 3.6 完整类别贡献的内部成分分解

对截住所有输入到目标路线的完整切分 C：

$$
K^C_{ij}=(x_i-x_{0i})\int_0^1
\frac{\partial F_y}{\partial h_j}\frac{\partial h_j}{\partial x_i}\,d\alpha,
\qquad \sum_{j\in C}K^C_{ij}=\operatorname{IG}_i(F_y).
$$

head 成分由该 head 的坐标求和。“identity + 全部 heads”和“residual + MLP”是两处切分，各自重构总图。不同层在不同位置拆解同一总贡献，不跨层重复相加。

**配图：Figure 20–21；分支总体结果见 Figure 13。**

### 3.8 干预与统计

同目标 patch-token 基线：

$$
c_j=A_{\rm clean}[\mathrm{CLS},j]u^\top(V_{{\rm clean},j}-V_{{\rm baseline},j}),
\qquad c_{j,k}^{\rm uniform}=c_j/16.
$$

英文首次写 **target-matched patch-token baseline with uniform within-patch allocation**。基线按 token 索引展开贡献；NNS 直接计算输入贡献。两者目标相同、坐标不同，逐 patch 总量不作通用相等假设。

主实验使用 4×4 像素 cell，原生 patch 为 16×16。相同面积预算、配对并列排序下计算：

$$
F=\tfrac12(\mathrm{AUC}_{\rm ins}-\mathrm{AUC}_{\rm del}),\quad
\Delta\mathrm{FID}=F_{\rm NNS}-F_{\rm token}.
$$

21 个干预比例、5 次配对 tie repeats；先图像内平均，再对图像级统计量算区间。归一化目标响应不裁剪，允许超过 [0,1]。D 使用图像级中位数 bootstrap，其他实验遵循各自统计定义。

**配图：Figure 3。** Scale comparison 回答尺度依赖；本基线不称为 NNS 自身空间平滑的纯消融。

### 4.2 真实 learning image 与模块正常输出

**问题：** 同一输入在三个模块的响应能否对应到真实可计算的输入位置图？

固定图像 ILSVRC2012_val_00007922.JPEG，通道 0、255、511、767。每个通道在 196 个 patch-token 输出求和作为 s。CPU float64 完整 attention 积分，比较 64/128 个 Gauss–Legendre 节点，并核对原图 logit。

**小结论 M1：** 对这张图和这些目标，学习图总和重构模块响应变化。最大完整性误差约 4.55×10⁻¹³；residual RGB 图与 patch、attention 图之和的最大误差约 2.22×10⁻¹⁶。Patch 图另通过权重乘输入差的解析核对。

## 5. 讨论

### 5.1 Learning image 提供了什么

内部响应描述“多大”，learning image 展开输入位置贡献；类别成分图进一步说明这些贡献经过哪些内部路径。正常响应、输入贡献、类别成分分别定义。

### 5.2 从三模块对应到实验

Patch 的局部映射、attention 的输入相关混合和 residual 相加构成逐模块理解路径。数值重构检查计算对应，500 图干预检查排序用途，100 图统计检查分支分配。

### 5.3 适用条件

主干预结论限定于模型、head 和 fine-cell；四坐标比较未穷尽全模型。完整模型稳定性未达到原要求；部分机制端点无有效样本。新增真实图为单输入、B0、四个通道。Stage S 的端点与阈值形成过程决定其探索性推断性质。

### 5.4 后续研究

研究其他模型和 patch 尺度、逐 token/神经元图、语义标签与 head 分工、参考路径与计算成本。可视化用于提出问题；新结论需要对应实验。

## 6. 结论与未来工作

建议结论段：

> 本文将 NNS 的 learning image 视角用于 ViT，在统一输入坐标下描述内部响应和类别贡献。Patch embedding、attention、residual 的逐步计算与真实输出展示了数值响应和输入贡献图的对应关系。干预实验显示，指定内部目标的细粒度排序优于同目标 token 空间基线，差异随尺度和层头变化。完整类别分析显示 attention 与 MLP 的分支贡献份额具有深浅差异。后续工作将研究更广的模型与目标，以及贡献图、表示和语义之间的联系。
