# Stage F F3H1 implementation addendum

Date: 2026-09-07. Status: prospective, before F3H pilot or formal outcome access. This addendum implements the frozen F3H0 protocol without changing its sample, model, methods, coordinates, numerical schedule, display transform, budget, or claims.

1. Map-only execution calls the existing recovery-v2 head-direction resolver, the E3 full IG schedule wrapper, the existing matched token-contribution method, and the existing Grad-CAM adapter. It does not run fidelity curves, perturbations, stability, sanity, bootstrap, statistics, or selection.
2. Every new Value-path unit is atomic and terminal as `VALID`, `FAILED`, or `NA`. Unknown implementation/infrastructure exceptions stop the shard and remain incomplete; they may not be converted into scientific failures.
3. For a valid NNS/matched pair, the display scale is exactly `M=max(max_abs_nns,max_abs_matched)`. If exactly one pair member is `FAILED/NA`, the failed cell remains a status panel and the valid member uses its own maximum only to remain visible, with `scale_basis=AVAILABLE_VALID_MEMBER_ONLY` and `paired_magnitude_comparison_allowed=false`. A failed member is never treated as a zero map. If both fail, no display scale is created.
4. Formal pilot coordinates remain `(0,0)`, `(4,0)`, `(8,0)`, `(11,0)`. The bulk decision may read only terminal status, integrity and resource fields; it may not decode the JPEG, load map arrays for visualization, render panels, or inspect hotspot locations.
5. F3H post-run aggregation-sufficiency assessment is frozen before outcome access. A concrete class-conditioned head weighting is considered justified only if an independently defined signed per-head coupling to the same frozen class logit exists for all 144 heads, has a validated path accounting rule that prevents omissions/double counting, and passes a predeclared conservation test. Atlas appearance, Grad-CAM overlap, peak brightness, map entropy or visual object alignment cannot define or select weights. Because F3H computes no such coupling coefficients, its atlas can diagnose head diversity but cannot by itself authorize numerical class-conditioned weights.
6. After F3H, F3C may therefore freeze a prospective method-development study that measures or derives class-logit coupling under an explicit conservation contract. Its comparison set must include class-targeted NNS, ViT Grad-CAM, full-model class-logit IG, attention rollout, and block-11 raw CLS attention head mean. The latter two are class-agnostic maps evaluated against the frozen class logit and must remain labeled as such. No F3C empirical computation begins merely by freezing that later protocol.
7. The owner's later instruction, issued before any F3H pilot or formal outcome access, supersedes only the sequencing field of F3H0: F3H terminal PASS authorizes `F3C0_PROTOCOL_FREEZE_ONLY`, not direct F4. F4 remains `PAUSED_PENDING_F3H_AND_F3C`; neither the sealed F3H0 receipt nor any earlier receipt is rewritten.
8. The owner's request to inspect all coordinates together adds three fixed consensus render instances before outcome access: one 4x12 per-layer consensus matrix, one 4x4 frozen depth-band consensus matrix for blocks 0-2/3-5/6-8/9-11, and one all-144-head consensus panel. For method `m` and sign `s`, consensus is the arithmetic mean of the already pair-shared-log display arrays `D_(l,h,m,s)`, with equal head weights and no selection. A layer/band/global consensus is rendered only when every required coordinate has both NNS and matched valid; otherwise that consensus cell is `FAILED/NA` with its missing count. The result is named `equal-head-weighted spatial-support consensus`, not an attribution sum, network-level attribution, or class-conditioned attribution. The total frozen render/review count is therefore 20, superseding only F3H0's earlier count of 17.
9. The post-run sufficiency report computes only descriptive head-diversity diagnostics from all valid display arrays: mean pairwise cosine similarity among 12 heads per block for each method/sign, and the corresponding consensus-map normalized spatial entropy. These values may describe similarity or dispersion but may not select heads or define class weights. The pass criterion for a concrete class-conditioned aggregation remains independent of visual appearance: all 144 signed class-logit coupling coefficients plus a no-omission/no-double-count path accounting identity and a predeclared conservation test must exist. F3H deliberately computes none of those coefficients, so the expected assessment is `INSUFFICIENT_BASIS_FOR_NUMERICAL_CLASS_CONDITIONED_WEIGHTS`; this result triggers F3C0 method/protocol design rather than a guessed aggregation.
