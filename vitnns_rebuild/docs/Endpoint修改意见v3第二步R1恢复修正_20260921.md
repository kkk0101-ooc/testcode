# Endpoint 修改意见 v3 第二步 R1 恢复修正

## 失败事实

原根 `reports/nns_vit_endpoint_revision_v3_step2_20260921/` 在完成 403 个主任务后 fail-closed。失败任务为 `primary__vit_b16__000`；其 $\alpha=1$ 结果中，唯一超出新增固定绝对阈值 $2\times10^{-5}$ 的项是 block 4 head 11、blur reference，重算效应与 E4 封存效应相差 $5.14984130859375\times10^{-5}$。该差异仍低于 E4 原始源比较合同 $10^{-4}+10^{-4}|e|$；任务内其余 143 个 head 的差异更小。

失败根及其 `acquisition_receipt.json`、`failure_primary__vit_b16__000.json` 保持不改。失败不改变科学估计量、样本、幅度、模型、目标、层、head、reference 或分析规则。

## 原因与修正

新批量扫描一次计算 64 个替换，历史 E4 一次计算 8 个替换；float32 GPU batch reduction 的微小差异使一个结果超过新增的 $2\times10^{-5}$ 固定绝对阈值。该阈值比历史 E4 已验证的源比较合同更严，且没有按效应尺度缩放。

R1 恢复仅把 $\alpha=1$ 回放门恢复为历史 E4 合同：

$$
|e_{\mathrm{new}}-e_{\mathrm{E4}}|\le 10^{-4}+10^{-4}|e_{\mathrm{E4}}|.
$$

验证器记录最大绝对差和最大 tolerance ratio，并要求 ratio 不超过 1。Q/K/V 源回放门、所有科学估计量和分析规则不变。

## 继承与执行

新根为 `reports/nns_vit_endpoint_revision_v3_step2_r1_20260921/`。它逐项核验父根 task manifest、freeze、FAIL receipt 和 failure record 的 SHA-256；复制 403 个已完成结果及其 payload，重写新根内路径并重算 canonical digest；其余 597 个任务从新队列执行。继承记录不重新计算科学结果，最终验证器对 1000 个任务统一执行文件 SHA、公式、覆盖和源回放检查。
