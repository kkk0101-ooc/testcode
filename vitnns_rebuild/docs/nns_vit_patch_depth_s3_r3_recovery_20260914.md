# S3-R3 prospective recovery amendment

S3-R2 used an escaped backslash-n instead of a real newline in its LFS pointer signature and therefore did not enter the pointer verification branch. The S3, S3-R1, and S3-R2 roots are preserved empty and immutable. Formal image, mask, feature, prediction, and outcome access counts remain zero.

S3-R3 uses fresh evidence, payload, and schedule paths and changes only the pointer signature to its real newline byte sequence. No scientific or execution contract changes.
