# Stage X acceptance contract

This contract is fail-closed. `PASS` means every required item is proven from
source; a missing record, placeholder, dropped row, changed denominator, or
untyped error is not a PASS.

## X0: protocol and literature freeze

1. Startup recomputes the two planning-file SHA-256 values; local, tracking,
   and remote branch; worktree/index and LFS state; ten archive refs; and the
   absence of pre-existing Stage X roots. Drift produces terminal `BLOCKED`
   without reset, checkout, stash, deletion, or overwrite.
2. C10, D10, E4, and F3C machine-readable files and archive refs are rebound
   by path, bytes, SHA-256, canonical digest where present, and immutable
   status. F3C primary mean, CI, and sign-flip p-value are recomputed from the
   50 per-image rows using the frozen NumPy PCG64 namespaces.
3. Every one of the eight research goals has a claim ID, population, target,
   estimand, PASS, NO-GO, INCONCLUSIVE, invalidity, and permitted wording. The
   strongest allowlisted outcome is `GO_BROAD_BENCHMARK_SCOPE`; no universal
   claim is allowlisted.
4. NNS-v2 defines the raw-logit target, full unmodified graph, signed
   `[3,224,224]` output, RGB reduction, path/baseline/quadrature, complete-cut
   `K^C[i,j]`, neuron/head/branch/layer views, native concat/output-projection
   accounting, residual accounting, numerical tolerances, convergence, and
   failure semantics. Ordinary input IG cannot satisfy the NNS-v2 name.
5. The literature search records cutoff, databases/platforms, exact queries,
   papers, publication state, official source and repository, commit/version,
   license, model/target/output/layer/cost semantics, status, and rationale. A
   comparator with an unverified source, version, license, or target cannot be
   `INCLUDED_PRIMARY`. Class-agnostic methods cannot enter that family.
6. Five required ViT/DeiT models and four datasets form a fixed 20-cell matrix.
   Only sealed recovery-v2 ViT-B/16 is materialized; all other checkpoint
   identities are planned and gated. Swin-T is deferred. Oxford-IIIT Pet is the
   independent task and ImageNet-S is not relabelled cross-dataset
   classification replication.
7. X1/X2/development/formal namespaces, counts, hash-sort algorithm, exclusion
   set, materialization gate, and prior-access ledger are frozen. X2 and all
   C10/Stage D/F3/F3H/F3C samples are excluded from confirmatory cohorts.
8. Faithfulness, stability, pixel resolution, class specificity/completeness,
   localization, and cross-cell replication have separate computable
   contracts. Real masks/bboxes are mandatory for localization.
9. Image/class/cell/benchmark estimands, bootstrap seeds/draws/quantiles,
   primary and secondary multiplicity, superiority, noninferiority, futility,
   invalidity priority, failure/NA/retry, deterministic X2 margin sealing, and
   the broad-claim truth table are complete. Nonsignificance is never
   equivalence and required failures cannot be handled as complete cases.
10. X1/X2 hard resource caps and the X2-to-formal p99 budget formula are
    frozen. Budget, OOM, numerical invalidity, and infrastructure failure have
    distinct typed handling. No post-hoc workload shrinkage is permitted.
11. Strict JSON rejects duplicate keys, NaN/Infinity, unknown/missing fields,
    bool-as-int, bad enum/range/count/digest, unsigned self-digest, and
    cross-document drift. JSON schemas are closed and round-trip.
12. Focused tests and false-pass mutations cover all 22 required attack
    classes. Validation recomputes source values; it does not trust report
    copies. Inventory and completion are atomically published after all other
    payloads.
13. Access audit is exactly: `new_empirical_outcome_access=false`,
    `formal_image_bytes_accessed=false`,
    `model_or_checkpoint_bytes_accessed=false`, `model_loaded=false`,
    `torch_or_timm_imported=false`, `cuda_or_gpu_accessed=false`,
    `dataset_or_checkpoint_downloaded=false`, `x1_started=false`,
    `x2_started=false`, `x3_started=false`, `f3_final_started=false`, and
    `stage_g_started=false`.
14. Terminal completion uses `SELF` to bind the containing clean commit and
    `refs/archive/stage-x-nns-v2-x0-completion`; post-publication validation
    must resolve SELF to local/tracking/remote/archive equality and clean
    Git/LFS. The only next authorization is
    `X1_NNS_V2_IMPLEMENTATION_ONLY`.

Any failed X0 item produces structured `BLOCKED`; X1 is not authorized.

## X1: implementation only

X1 may implement the frozen graph and complete-cut decomposition using
synthetic fixtures and listed prior-access audit images. It must prove native
forward/target parity, input completeness, every cut identity, head projection
accounting, branch accounting, pixel provenance, target swaps, randomization,
strict typed terminals, retention, and resource instrumentation. It may not
change the mathematics or comparator family. X1 PASS authorizes only X2.

## X2: development and futility

X2 uses exactly 40 development images per required model and no formal image.
It validates adapters, convergence, stability, memory/cost, and seals exact
margins and formal budgets using the X0 algorithms. Any method-validity gate or
negative Grad-CAM futility gate produces immutable
`NO_GO_BROAD_CLAIM_DEVELOPMENT`; X3-X5 remain forbidden.

## X3-X6: formal and decision

X3-X5 require the preceding terminal PASS and frozen caps. Every required cell
retains expected/valid/failed/NA and resources. X6 uses only sealed numeric
evidence, no JPEG/model/GPU, and applies the exact hierarchical estimands, Holm
families, margins, and truth table. Individual evidence-line states cannot
substitute for one another.
