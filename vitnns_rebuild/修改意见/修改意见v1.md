# 总体判断

这篇初稿在**理论忠实性、数学严谨性和实验审计强度**上已经明显超过原始 NNS 论文。核心路线是成立的：

> 原始 NNS 通过输入值初始化 learning image，并按当前前向状态传播；你的 Endpoint 将这一过程形式化为局部 Jacobian propagation，再推广到 LayerNorm、GELU、softmax attention 和 residual connection。

因此，它可以合理定位为：

> **原始 NNS 的 Jacobian-form ViT generalization。**

但需要区分两层“忠实”：

1. **数学思想上忠实**：是；
2. **实验上穷举每个神经元**：不是。

你现在做的是：

> 对冻结 registry 中的异构标量目标进行完整执行，并对一组分层抽样的 token-channel 单元进行神经元级审计。

它不是原论文意义上的“扫描网络中全部神经元”。稿件已经多次限定 `registry-complete`，这是正确的。

论文目前也不是“结论单薄”，而是相反：**结果很多，但中心叙事略显拥挤，主结果没有被充分突出**。最强主线应当是：

1. 原始 NNS 与 Endpoint 的理论和数值等价；
2. Endpoint 可统一表示 ViT 异构内部目标；
3. Attention/residual 的局部 Jacobian 记账可以严格闭合；
4. Endpoint atlas 揭示了随层深发生的输入依赖空间扩展；
5. 深层 attention 越来越偏离 Value-only fixed-attention approximation；
6. Attention 与 MLP residual 呈现不同的局部路径和空间变化趋势；
7. 有限干预实验明确限定了 Endpoint 的行为解释边界。

# 一、是否忠实延续原始 NNS？

## 1.1 核心数学思想是忠实的

原始 NNS 将输入拆成坐标 learning images。若输入为：

\[
x=(x_1,\ldots,x_d)^\top,
\]

那么输入 learning-image 矩阵就是：

\[
\mathcal L(x;x)=\operatorname{diag}(x).
\]

原始 NNS 对 ReLU 网络使用：

\[
c_{pq}^{(l-1,l)}
=
S(x_q^l)w_{pq}^l.
\]

在当前前向状态下，这正是局部 Jacobian 元素：

\[
\frac{\partial x_q^l}{\partial x_p^{l-1}}
=
S(x_q^l)w_{pq}^l.
\]

若统一定义：

\[
\mathcal L(u;x)
=
J_{u,x}(x)\operatorname{diag}(x),
\]

对：

\[
v=f(u_1,\ldots,u_r)
\]

有：

\[
\mathcal L(v;x)
=
\sum_a J_{f,u_a}(x)\mathcal L(u_a;x),
\]

由链式法则得到：

\[
\mathcal L(v;x)
=
J_{v,x}(x)\operatorname{diag}(x).
\]

因此，对标量目标 \(s\)：

\[
\mathcal L(s;x)
=
\nabla_xs(x)^\top\operatorname{diag}(x),
\]

向量形式就是：

\[
E_s(x)=x\odot\nabla_xs(x).
\]

你用五类兼容网络、两种精度和 5,000 项直接比较验证这一点，是非常强的忠实性证据。

## 1.2 与原始 NNS 的关系应定义为“形式化和推广”

最准确的表述是：

> 原始 NNS 在 ReLU、线性、卷积和当前 MaxPool winner 条件下，是输入值初始化的局部 Jacobian propagation；NNS-ViT 将这一形式推广到 ViT 的平滑和输入依赖算子。

不要写成：

> 原始 NNS 本身已经包含 LayerNorm、GELU 和 attention。

这些是你的新推广。

## 1.3 对 CNN 中 filter aggregation 的连接也是合理的

原论文对 filter 的聚合类似：

\[
I^{k,l}
=
\sum_{x,y}I^{k,l}_{x,y}f^{k,l}_{x,y}.
\]

你定义：

\[
s_{\mathrm{energy}}
=
\frac12\sum_jh_j^2,
\]

则：

\[
\nabla_hs_{\mathrm{energy}}=h.
\]

因此：

\[
E_{\mathrm{energy}}
=
\sum_jh_jE_{h_j}.
\]

它确实对应原始 NNS 中 activation-weighted filter aggregation 的 Jacobian 表达。建议在方法中把这一步正式推导出来，而不只在一句话中说明。

## 1.4 实验扫描范式只是部分忠实

原论文的理想主张是：

> 为网络中的每个神经元生成 learning image。

你的主 registry 只覆盖非常少的一部分候选对象。例如 post-block token-channel 覆盖率为：

- ViT-B/16：0.01058%；
- DeiT-S：0.02115%。

补充 M3 提高到：

- ViT-B/16：0.338%；
- DeiT-S：0.677%。

因此，以下表述是合适的：

- registry-complete scan；
- registered scalar endpoint scan；
- stratified token-channel neuron audit；
- 对冻结目标目录无缺失执行。

以下表述应避免：

- 完整 ViT 神经元扫描；
- 扫描了 ViT 中每个神经元；
- atlas 代表全部 ViT 神经元；
- 所有神经元均表现出相同规律。

## 1.5 “NNS 学到的特征”需要更现代、更谨慎的解释

原论文把 learning image 描述为：

- 神经元学到的知识；
- 模型从样本中学到的特征；
- 恢复输入样本的能力。

你的数学形式已经明确表明：

\[
E_s(x)=x\odot\nabla_xs(x)
\]

最可靠的含义是：

> 当前输入点上，目标标量关于输入坐标缩放方向的局部一阶依赖。

因此，你没有直接沿用原论文较强的“知识量”措辞，这是正确的。建议继续避免：

- “神经元真正学到的语义”；
- “Endpoint 是因果证据”；
- “absolute mass 是知识量”；
- “图中正部就是支持预测的证据”。

# 二、数学分析是否正确？

总体上正确，但有若干条件需要在正文中正式化。

## 2.1 Endpoint 身份正确

你当前的定义：

\[
\mathcal L(x;x)=\operatorname{diag}(x)
\]

以及：

\[
\mathcal L(v;x)
=
\sum_aJ_{f,u_a}(x)\mathcal L(u_a;x)
\]

正确导出：

\[
E_s(x)=x\odot\nabla_xs(x).
\]

建议统一行向量和列向量约定。例如明确：

\[
\nabla_xs(x)\in\mathbb R^d
\]

按列向量记，则：

\[
E_s(x)
=
\operatorname{diag}(x)\nabla_xs(x).
\]

或者按 learning-image 行向量记：

\[
\mathcal L(s;x)
=
\nabla_xs(x)^\top\operatorname{diag}(x).
\]

目前两种写法都有出现，数学上相同，但最好统一。

## 2.2 必须明确它不是输出值分解

一般情况下：

\[
\sum_i x_i\frac{\partial s}{\partial x_i}
\neq s(x).
\]

只有在满足特定齐次条件时，Euler 定理才可能给出类似关系。ViT 中存在：

- bias；
- position embedding；
- CLS token；
- LayerNorm；
- softmax；
- GELU；
- affine parameters；

因此不存在一般的 function-value completeness。

建议在命题后直接增加：

> Endpoint 重构的是目标的局部输入 Jacobian 记账，而不是目标函数值。除非模型满足额外的齐次条件，否则 Endpoint 坐标之和不等于目标值。

## 2.3 normalized RGB 转换正确

若：

\[
x=\frac{r-\mu}{\sigma},
\]

则：

\[
x_i\frac{\partial s}{\partial x_i}
=
(r_i-\mu_i)\frac{\partial s}{\partial r_i}.
\]

这部分正确。

你的“reference-independent but not coordinate-origin free”定位也正确。推荐稳定使用：

> Endpoint 不需要外部选择的 intervention reference，但仍依赖模型输入坐标系及其 normalization origin。

不要简写成“完全 baseline-free”。

## 2.4 Bias、CLS token 和位置编码的限定正确，但应更突出

因为 Endpoint 只对图像输入坐标归因，以下量没有独立坐标贡献：

- class token；
- positional embedding；
- patch embedding bias；
- LayerNorm affine bias；
- Q/K/V bias；
- MLP bias；
- classifier bias。

它们仍然会影响：

\[
\nabla_xs(x),
\]

但不会作为单独归因项出现。

建议明确写：

> Endpoint 描述目标对图像输入坐标的局部依赖，不是目标全部来源的分解；固定 token、位置编码和偏置只通过改变当前函数和 Jacobian 间接影响 Endpoint。

## 2.5 Attention differential 分解正确

对：

\[
O=AV,\qquad
A=\operatorname{softmax}(QK^\top/\sqrt{d_h}),
\]

有：

\[
\mathrm dO=(\mathrm dA)V+A(\mathrm dV),
\]

并可继续得到：

\[
\mathrm dO
=
\underbrace{
\frac{\partial A}{\partial Q}\mathrm dQ\,V
}_{Q}
+
\underbrace{
\frac{\partial A}{\partial K}\mathrm dK\,V
}_{K}
+
\underbrace{
A\,\mathrm dV
}_{V}.
\]

因此：

\[
E^{\mathrm{attn}}
=
E^Q+E^K+E^V
=
E^{\mathrm{routing}}+E^{\mathrm{value}}
\]

是正确的局部 differential bookkeeping。

但必须继续保持这些限定：

- 它是局部 Jacobian 路径分解；
- Q、K、V 在输入空间可能重叠；
- 它不是唯一的函数值归因；
- 它不是三个互斥因果效应；
- 路径 norm 比例不是最终贡献百分比。

## 2.6 Structured cut 公式正确，但需要给出正式条件

你写：

\[
E^C_{k,i}
=
x_i
\left\langle
\nabla_{z_k}F,
\frac{\partial z_k}{\partial x_i}
\right\rangle.
\]

若 \(\{z_k\}\) 是一个合法 edge cut，且：

1. 每条相关 input-to-target differential path 都经过该 cut；
2. 每条路径只计数一次；
3. 所有成分使用同一当前前向状态；
4. cotangent 位于正确 edge；
5. 不存在遗漏或重复路径；

则：

\[
\sum_kE^C_{k,i}
=
x_i\frac{\partial F}{\partial x_i}.
\]

建议把它写成“命题 2：合法 edge cut 的 Endpoint closure”，并给出简短证明。这会让结构闭合不只像工程合同，而是正式理论结果。

## 2.7 Residual 分解正确

对：

\[
y=u+f(u),
\]

有：

\[
J_{y,u}=I+J_{f,u}.
\]

你已经注意到 identity 必须使用 residual 输出处的 cotangent：

\[
g_y=\nabla_yF,
\]

而不是错误地直接使用包含 branch 影响的 \(\nabla_uF\)。这是非常重要且正确的。

同样要避免把：

\[
E^{\mathrm{output}}
=
E^{\mathrm{identity}}
+
E^{\mathrm{branch}}
\]

解释成：

\[
F=F_{\mathrm{identity}}+F_{\mathrm{branch}}.
\]

## 2.8 Frozen-attention 解释基本正确

Frozen-attention approximation：

\[
\mathrm dO_{\mathrm{FA}}=A\,\mathrm dV
\]

忽略：

\[
(\mathrm dA)V.
\]

因此 Full–Value 差异就是 routing differential。你的 JVP 约 0.95 的解释现在也是正确的：

> 近似误差与完整响应处于相同 norm 尺度。

不能解释为：

- 遗漏 95% 的贡献；
- routing 占 95%；
- Q/K 具有 95% 的因果重要性。

## 2.9 Cancellation 指标使用正确

你区分了：

### Map cancellation

\[
C^{\mathrm{map}}
=
1-
\frac{|\sum_iE_i|}{\sum_i|E_i|}.
\]

### Path cancellation

\[
C^{\mathrm{path}}
=
1-
\frac{
\|E^{(1)}+E^{(2)}\|_1
}{
\|E^{(1)}\|_1+\|E^{(2)}\|_1
}.
\]

这是正确且必要的。

接近 1 的 map cancellation 也揭示了一个重要限制：

> Endpoint absolute mass 表示局部一阶项的总幅值，不表示净 directional effect。

这应成为讨论中的核心解释，而不仅是附带数值。

# 五、目前最有价值的科学结论

你的结论并不单薄，真正的问题是主结论还没有被充分提炼。

## 5.1 第一项主发现：层深相关空间扩展

两个模型中均出现：

- entropy 上升；
- own-token locality 下降；
- normalized distance 上升；
- 100/100 图方向一致。

这是很强的结果。建议定义为：

> **spatial broadening of local input dependence**

而不是简单说“从局部到全局语义”。

准确版本：

> 在冻结抽样的 post-block token-channel 单元中，Endpoint absolute mass 随层深从自身邻域集中转向更分散、更远距离的输入区域。

## 5.2 第二项主发现：深层 attention 越来越不能由 Value-only 近似

M4 同时显示：

- routing-relative path scale 上升；
- Endpoint approximation error 上升；
- JVP discrepancy 上升；
- late block discrepancy 与 full response 同量级。

这可以形成一个很清楚的结论：

> 随着层深增加，固定 attention weights、只传播 Value differential 的近似越来越不能表示完整的目标条件化 attention Jacobian。

这比“routing 更重要”更准确，也更有方法学价值。

## 5.3 第三项主发现：Attention 与 MLP residual 具有不同趋势

你观察到：

- attention residual identity share 下降；
- attention output–identity spatial TV 上升；
- MLP residual identity share 上升；
- MLP output–identity spatial TV 下降。

这支持：

> Attention 和 MLP residual 对局部输入依赖的传递不能由统一的“深层更依赖 skip”叙事描述。

这是论文中很有价值的结构发现。

## 5.4 第四项主发现：Attention sharpness 不是 routing dependence 的代理

层内 head 比较显示 saturation 与 routing share/error 负相关，而且 mean-query 结果在控制主要 norm 后仍存在。

可提炼为：

> 更尖锐的 attention 并不意味着更强的 Q/K-mediated differential dependence；raw attention sharpness 不能替代完整 Jacobian 路径分析。

这个结论与 Transformer 解释文献有直接联系，值得放在摘要或讨论中。

## 5.5 行为结果是边界，不是主失败

M1/M2 得到：

- Endpoint mass 对 component effect 有稳定但有限的关联；
- all-family omnibus 未通过；
- Taylor 在 reference-specific replacement 中更强；
- 高分辨率 Endpoint 不自动带来更强区域干预能力。

这可以提炼成：

> 数学闭合、成分级行为关联和空间干预选择是三种不同能力。

这是论文很好的方法学结论。

# 六、还欠缺哪些关键实验？

现在不建议继续扩大 Endpoint–Taylor 排行榜。更值得补的是能够检验机制结论是否来自训练、目标或架构先验的实验。

## 第一优先级：随机初始化或未训练模型控制

这是当前最重要的缺口。

ViT 从第一层开始就具有全局 self-attention。因此 M3 的空间扩展和 M4 的 routing 趋势可能来自：

- 架构本身；
- 初始化尺度；
- residual 结构；
- 训练后形成的表征；
- 预训练方式。

仅使用两个训练模型不能区分这些来源。

建议对同架构随机初始化模型运行缩小版审计：

- 100 图可降至 32 或 64 图；
- blocks 0–11；
- 相同 token/channel 采样；
- 相同 entropy/locality/distance；
- 相同 routing/value；
- 相同 residual share；
- 不需要重复大规模有限干预。

主要比较：

\[
\Delta_{\mathrm{trained-random}}
\]

回答：

- 空间扩展在随机模型中是否也存在；
- routing 随深度上升是否是架构先验；
- attention/MLP residual 相反趋势是否由训练强化；
- CLS 更分散是否主要来自架构。

如果随机模型也出现相同趋势，结论应改为：

> 这是 ViT 架构及其参数化下的局部 Jacobian 属性，训练可能调节其幅度。

如果只在训练模型中明显出现，才能更有力地讨论“学习形成的机制”。

## 第二优先级：目标稳健性

M4 主要使用 ground-truth logit。对错误分类图像，ground-truth logit 并不是模型当前决策目标。

建议至少比较：

- ground-truth logit；
- clean-top1 logit；
- 正确分类样本；
- 错误分类样本。

主要复核：

- routing share 深度趋势；
- frozen-attention error；
- attention/MLP identity share；
- spatial TV。

这可以用已有注册的 clean-top1 map，计算成本可能有限。

## 第三优先级：匹配 M3 与 M4 的目标

当前 M3 使用 token-channel targets，M4 使用 class-logit cotangent，因此两者只能描述性桥接。

建议选择一个较小的匹配子集，例如：

- 16–32 张图；
- blocks 0、5、11；
- 一组冻结 token-channel targets；
- 对同一 token-channel target 分解其 routing/value 或 residual paths。

然后直接比较：

\[
H(E^{\mathrm{full}})
-
H(E^{\mathrm{value}}),
\]

\[
L(E^{\mathrm{full}})
-
L(E^{\mathrm{value}}),
\]

以及 full–value patch TV。

这样可以回答：

> 对同一内部目标，加入 routing differential 是否改变其空间分布？

仍不能直接证明因果，但会明显加强 M3–M4 的机制连接。

## 第四优先级：复现一个原论文风格的 CNN 实验

你已经有 5,000 项等价验证，数学忠实性足够强。但如果希望更直接承接原论文，可以在附录增加一个小实验：

## 第五优先级：替代 checkpoint 或同架构不同训练方式

如果资源允许，增加一个同架构不同 checkpoint 比增加完全不同模型更有解释力，例如：

# 九、结论是否单薄？

不单薄。当前结论的问题是**太像结果清单**，没有把科学信息分层。

建议最终结论围绕四句话组织：

1. **忠实性**  
   原始 NNS learning image 可以严格形式化为输入值初始化的局部 Jacobian propagation，Endpoint 是其面向 ViT 的推广。

2. **结构正确性**  
   ViT 中异构内部标量目标可以被映射到统一输入坐标，attention 和 residual 的合法 edge cuts 能够闭合对应 Endpoint。

3. **机制发现**  
   两个模型的 token-channel Endpoint 随层深发生空间扩展；深层 attention 越来越不能由 Value-only approximation 表示，attention 和 MLP residual 呈现不同的局部传递模式。

4. **行为边界**  
   Endpoint 包含有限但稳定的成分级行为信息，但不是通用 finite-intervention estimator；具体 reference 下的 replacement 更适合使用 displacement-matched Taylor。

这已经是一组相当完整的结论。
