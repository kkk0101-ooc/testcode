# 一、最需要优先解决的问题

## 1. NNS-ViT 与原始 NNS 的数学关系没有建立清楚

原始 NNS 的核心是：

- 将输入值及其位置保留下来；
- 通过权重和激活门逐层传播；
- 对 ReLU 网络而言，本质上接近输入值乘以当前激活路径上的有效权重。

你的 NNS-ViT 则定义为：

\[
L_s[i]=(x_i-x_{0i})\int_0^1
\frac{\partial s(x_0+\alpha(x-x_0))}{\partial x_i}\,d\alpha,
\]

这在数学上就是针对内部标量目标的 Integrated Gradients。当前文本虽然承认使用 IG，但仍容易让审稿人产生如下疑问：

> 这是 NNS 在 ViT 上的扩展，还是将 IG 应用于 ViT 内部响应并沿用“learning image”的名称？

这是全文最关键的创新性风险。

### 建议

在方法部分单独增加“**NNS 与 NNS-ViT 的关系**”小节，并给出一个命题：

> 对零参考、忽略偏置且参考点到输入之间激活模式不变的 ReLU 网络，原始 NNS 的学习图像等价于 input × effective Jacobian；此时路径积分形式退化为原始 NNS。对于 GELU、LayerNorm 和输入相关 attention，激活路径不再固定，因此采用路径积分对 NNS 的局部有效权重传播进行推广。

可写为：

\[
L_s^{\mathrm{NNS}}(x)
=x\odot \frac{\partial s(x)}{\partial x},
\]

而当路径上的 Jacobian 不恒定时：

\[
L_s^{\mathrm{NNS-ViT}}(x;x_0)
=(x-x_0)\odot
\int_0^1J_s(x_0+\alpha(x-x_0))\,d\alpha.
\]

同时明确限制条件：

- 二者一般情况下并不严格相同；
- NNS-ViT 是“受 NNS 启发的路径积分推广”；
- 路径积分、completeness 和 conductance 不是本文原创。

如果无法建立上述退化关系，建议弱化命名为：

- **NNS-inspired ViT Scanner**
- **基于学习图像的 ViT 输入空间路径归因**
- **NNS-ViT：视觉 Transformer 的输入空间路径归因与内部贡献分解**

---

## 2. “learning image”容易被误解为模型学到的特征

你现在多次使用“该模块从输入中学到了什么”“学习图像对应模块响应”等表述。但按照定义，learning image 实际表示：

> 标量目标相对于参考输入的变化，被分配到各输入维度后的路径归因。

它不是：

- 神经元的完整语义；
- 模型无条件学到的特征；
- 内部响应本身；
- 因果效应；
- 唯一解释。

例如：

\[
\sum_iL_s[i]\approx s(x)-s(x_0),
\]

恢复的是**相对参考的响应差值**，而不是 \(s(x)\)。

### 建议统一表述

第一次定义时写：

> 本文将内部标量响应相对于参考输入的输入空间路径归因图称为学习图像。

后文尽量把：

- “该神经元学到了什么”

改为：

- “哪些输入位置对该目标相对参考的响应变化作出了贡献”。

把：

- “真实模块响应与学习图像对应”

改为：

- “学习图像满足目标响应差值的完整性关系”。

建议始终保留“学习图像（input-space path-attribution map）”这一限定，避免把归因图等同于特征本身。

## 3. 当前观察对象并不总是“神经元”

例如：

\[
s_{q,c}(x)=\sum_{t=1}^{196}q(x)_{t,c}
\]

是一个跨 196 个 token 的通道聚合响应，不是单个神经元。CLS head-direction 也是一个数据依赖方向上的投影，而不是原生网络单元。

### 建议建立观察对象层级

明确区分：

1. **标量神经元/单元**：某个 token-channel；
2. **聚合内部响应**：跨 token 的通道和；
3. **注意力头方向响应**：head output 在给定方向上的投影；
4. **分支成分**：attention、MLP、residual；
5. **输出目标**：class logit 或 margin。

全文最好使用“内部目标”或“内部响应”作为上位概念，不要把所有对象都称作“神经元”。

## 4. 主实验目标具有较强的数据依赖性

你定义：

\[
d=g(x)-g(x_0),\qquad u=\frac{d}{\|d\|_2},\qquad f(z)=u^\top g(z).
\]

这里每张图像都有自己的方向 \(u\)。因此，500 张图像评价的不是同一个固定标量函数，而是同一个“目标构造程序”。这并非错误，但必须明确，否则“跨样本重复验证同一目标”的说法不够准确。

此外，\(u\) 由 clean-reference 差值构造，相当于选择最对齐当前响应变化的方向，可能放大目标信号。

### 建议

至少增加以下对照之一：

- 固定输出通道；
- 数据集级固定方向；
- 分类器下游梯度方向；
- 随机但预先冻结的方向；
- 使用 head-output norm，但需说明其非线性含义。

并在正文明确：

> 统计推断针对的是固定的目标构造规则，而不是所有图像共享的同一标量输出。

## 5. 主基线偏弱，容易产生“优势由定义导致”的质疑

主比较是：

- NNS：在 \(4\times4\) cells 上有细粒度差异；
- token baseline：每个 \(16\times16\) patch 内均匀分配，因此 patch 内完全同分。

随后又发现：

- 在 \(4\times4\) cell 尺度上 NNS 大幅占优；
- 到 native patch 尺度后差异几乎消失。

这说明主要结果实际是：

> 输入梯度在 patch 内提供了额外排序，而均匀 token 基线没有这种能力。

这个结果有意义，但某种程度上是基线定义直接决定的，不能写成 NNS 对 ViT 解释的普遍优势。

### 建议增加更强基线

至少考虑：

1. 同一内部目标的 pixel-level Gradient × Input；
2. SmoothGrad-IG；
3. Expected Gradients 或多参考 IG；
4. token contribution 的双线性/学习式细化；
5. patch 内随机排序基线；
6. patch embedding 局部权重展开；
7. 完整 attention 路径 IG，而不仅是 fixed-attention Value path。

主结论应改成：

> 对指定 B0/H9 条件 Value-path 目标，输入空间路径归因能够在原生 patch 内提供均匀 token 展开不具备的细粒度干预排序。

而不宜写成：

> NNS-ViT 整体上优于 patch-token 解释。

# 二、方法部分需要补强的内容

## 1. 完整切分目前公式不足

你写道：

\[
\sum_kK_k[i]\approx L_{\ell_y}[i],
\]

但没有完整给出 \(K_k\) 如何计算。建议明确写出：

\[
K_k[i]
=
(x_i-x_{0i})
\int_0^1
\frac{\partial s}{\partial z_k}
\frac{\partial z_k}{\partial x_i}
\,d\alpha,
\]

其中 \(\{z_k\}\) 必须构成同一计算 cut 上不重叠且完备的变量集合，于是：

\[
\frac{\partial s}{\partial x_i}
=
\sum_k
\frac{\partial s}{\partial z_k}
\frac{\partial z_k}{\partial x_i}.
\]

还要说明：

- head cut 在 concat 前还是 output projection 后；
- residual identity 与 branch 如何定义；
- bias、LayerNorm、position embedding 归到哪里；
- 不同 cut 是不同记账方式，不能跨 cut 相加；
- absolute-mass share 是描述性归因份额，不是因果贡献比例。

这是论文真正可能形成方法贡献的部分，应该比图件流程描述更详细。

## 2. 区分三种 attention 解释

建议用一个表格明确：

| 对象 | attention 是否变化 | Q/K routing | V path | 下游分类器 |
|---|---:|---:|---:|---:|
| Raw attention | clean 固定 | 否 | 否 | 否 |
| Conditional Value-path | clean 固定 | 否 | 是 | 视目标而定 |
| Full attention IG | 随路径变化 | 是 | 是 | 视目标而定 |
| Full class IG | 随路径变化 | 是 | 是 | 是 |

当前正文虽有说明，但分散在多个段落和图注中，不利于审稿人理解。

## 3. 增加 reference sensitivity

灰色参考是方法定义的一部分，不只是显示设置。建议至少比较：

- 灰色参考；
- 黑色参考；
- 模糊图参考；
- 数据均值参考；
- 多参考平均。

否则难以判断空间结构是否依赖特定 baseline。

## 4. 报告计算成本

最高使用 8192 阶或 4096 阶积分，计算代价极高。应报告：

- 单图、单目标运行时间；
- GPU/CPU 型号；
- 峰值显存；
- 不同积分阶数的误差—成本曲线；
- 推荐默认阶数。

否则“无需改变模型”可能被误读为“使用成本低”。

# 三、实验结论需要明显收窄

## 1. B0/H9 不能代表整个 ViT

你的 secondary analysis 已经显示：

- B0/H9 median = 2.3082；
- 其他三个层头仅约 0.04–0.07。

因此不能把主结果表述为 NNS-ViT 在 ViT 上普遍有效。建议：

- 要么把 B0/H9 明确定位为预注册案例研究；
- 要么扩大到随机或分层抽取的多层多头确认性实验；
- 要么把总体结论改为“效果对目标和内部坐标高度异质”。

摘要中最好直接体现这一点。

## 2. 插入/删除可能存在分母放大问题

你定义：

\[
S(z)=\sigma\frac{t(z)-t(x_0)}{|\Delta|}.
\]

如果 \(|\Delta|\) 很小，归一化响应和 AUC 会非常大。你的 \(\Delta_{\mathrm{fid}}\) 中位数超过 2，并非错误，但审稿人会质疑尺度稳定性。

建议同时报告：

- \(|\Delta|\) 的分布；
- 最小 target delta；
- 未归一化 AUC；
- 对小 \(|\Delta|\) 样本的敏感性分析；
- clipped 与 unclipped 结果；
- reference 替换造成的 OOD 风险。

## 3. 删除/插入不是充分的解释有效性证明

灰色区域替换可能制造 OOD 样本。建议增加：

- blur/inpainting deletion；
- ROAR/KAR 式重训练评价，若成本允许；
- sensitivity-n；
- infidelity；
- parameter randomization/sanity checks。

尤其你已有稳定性负结果，更应避免将 fidelity 写成“验证解释正确”。

## 4. 分支份额不应被称为机制证明

“深层 attention share 增加、MLP share 减少”是有价值的结果，但它依赖：

- 特定 cut；
- absolute mass；
- 特定 baseline；
- 特定类别目标；
- 单一 ViT-B/16。

建议称为：

> 基于指定完整切分的归因记账结果。

不要称为：

- 网络真实信息流量；
- 分支因果重要性；
- 深层统一语义机制。

最好增加 branch ablation、activation patching 或 causal intervention 作为外部验证。
