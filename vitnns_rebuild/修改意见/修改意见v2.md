# 论文整体修改方案

## 一、总体修改思路

论文可以继续以 NNS 为理论起点，而且可以把结论写得更有整体性，但“大”应体现在以下方面：

1. **把 NNS 从面向 CNN 的逐层尺度传播，提升为面向一般计算图的局部微分分析语言；**
2. **说明 NNS 标量学习图像与 Input × Gradient 的数学关系，而不是回避该关系；**
3. **将 ViT 中 attention、Q/K/V、multi-head 和 residual 等结构纳入统一的 NNS 计算图分解；**
4. **通过闭合性、层深统计和有限干预，明确该框架能够回答什么、不能回答什么；**
5. **把研究意义表述为“NNS 理论边界和适用对象的扩展”，而不是“重新发明一种新的输入归因量”。**

建议将论文的总论点改为：

> NNS 不应仅被理解为一种面向 CNN 的学习图像生成方法。其逐层尺度传播在数学上可统一解释为目标对输入的局部 Jacobian 作用；在标量目标下，其输入学习图像与 Input × Gradient 等价。基于这一认识，本文将 NNS 从顺序式 CNN 单元分析推广到视觉 Transformer 的一般计算图，进一步建立面向 attention、Q/K/V、multi-head 和 residual 等结构的可加局部微分分解，并分析这些结构路径在两个预训练 ViT 模型中的层深规律及其对有限内部干预的适用边界。

这个定位既保留了 NNS 的理论主线，也避免把已经存在的 Gradient × Input 包装成新方法。

# 三、重新明确研究问题

建议将论文压缩为一个总问题和四个子问题。

## 3.1 总体研究问题

> 如何在 NNS 框架下，将视觉 Transformer 内部目标对输入的局部依赖表示为可计算、可分解和可验证的结构路径图，并分析其层深规律及有限干预边界？

## 3.2 子问题

### RQ1：NNS 学习图像的数学本质是什么？

研究：

- 原始 NNS 的逐层尺度传播与 Jacobian 链式法则有什么关系；
- 标量目标下是否等价于 Input × Gradient；
- 偏置、位置编码、CLS token、LayerNorm 和非齐次运算如何影响解释；
- NNS 学习图像到底表示敏感性、贡献还是局部坐标响应。

### RQ2：NNS 如何推广到 ViT 的结构化计算图？

研究：

- 如何定义 ViT 内部 token-channel、通道聚合量和类别目标；
- 如何将 attention 微分分解为 routing 与 value；
- 如何进一步将 routing 分为 Q-induced 与 K-induced；
- 如何将 residual 分解为 identity 和 branch；
- 在什么条件下各路径项能够加和恢复完整局部输入依赖。

### RQ3：两个预训练 ViT 模型中的结构路径如何随深度变化？

研究：

- 内部目标的输入依赖是否由局部向分散变化；
- routing/value 和 identity/branch 的相对局部尺度如何变化；
- Q、K、V 路径是否具有不同的空间分布；
- 不同目标类型和模型之间是否存在一致或不一致的趋势。

### RQ4：局部 NNS 路径图在多大程度上能够预测有限干预？

研究：

- 一阶分解能否预测小幅激活替换；
- 预测误差是否随干预幅度增大而增加；
- clean-only 的 Endpoint 与 reference-aware Taylor 估计有何差异；
- 局部归因图与有限因果效应之间的边界在哪里。

# 四、重新组织论文的核心结论

你希望“主要结论参考 NNS 并写得大一点”，建议分成三个层级来写。

## 4.1 理论层面的总体结论

这是可以写得相对大的部分：

> 原始 NNS 的逐层尺度传播可以统一表示为计算图上的局部 Jacobian 传播。对于标量内部目标，其输入学习图像等价于 Input × Gradient；对于具有多分支、多输入算子和残差连接的模型，NNS 可以进一步扩展为面向真实计算边的结构化局部微分分解。

这个结论不是说 NNS 发明了 Gradient × Input，而是说：

- NNS 的逐层尺度思想具有一般计算图解释；
- CNN 版本只是其中一种具体实现；
- ViT 的复杂结构需要从单一路径递推推广到多边、多分支的结构分解。

## 4.2 方法层面的总体结论

> 在满足合法计算切面条件时，ViT 内部目标的完整局部输入依赖可以分解为若干真实计算边对应的路径项；attention 可以分解为 Q-induced、K-induced 和 V-induced differential，residual 可以分解为 identity 与 branch differential，各项在一阶微分意义下具有可加闭合性。

这里的关键词必须是：

- 局部；
- 微分；
- 计算边；
- 可加；
- 闭合。

不能改写成：

- Q、K、V 对预测值的完整贡献；
- routing 和 value 的因果贡献比例；
- residual 两个分支的实际预测占比。

## 4.3 经验层面的总体结论

建议写成：

> 在本文研究的 ViT-B/16 和 DeiT-S/16 固定预训练 checkpoint 中，抽样内部目标的局部输入依赖随深度总体呈现由本 token 邻域向更广空间范围扩展的趋势；与此同时，attention 中 routing differential 相对于 value differential 的局部范数占比在较深层有所提高，说明仅保留当前注意力权重下的 value differential，越来越难以近似完整 attention 局部响应。

这已经比单纯写“热图越来越全局”更有理论意义，但仍然没有超出证据。

## 4.4 有限干预层面的结论

> NNS 路径图首先描述当前输入点的局部一阶依赖，而不是有限替换的完整因果效应。在较小干预幅度下，一阶预测与真实效应具有较好对应；随着替换幅度增大，非线性和路径交互使预测误差上升。对于给定参考输入的区域替换，显式使用实际位移的 Taylor 估计通常优于仅依赖 clean 输入的 Endpoint 排序。

这个结论实际上能提升论文质量，因为它不只是宣称方法有效，还解释其适用边界。

# 五、建议重写论文的创新点

建议将创新点改成以下四项。

## 创新点一：NNS 的统一 Jacobian 解释

> 从计算图微分角度统一原始 NNS 的逐层尺度传播，证明在使用精确局部导数且无额外归一化或重分配规则时，标量目标的 NNS 学习图像可写为 \(x\odot\nabla_xs(x)\)。该结果明确了 NNS 与 Input × Gradient 的关系，并将 NNS 从特定 CNN 算子递推提升为一般计算图上的局部尺度表示。

这里的创新属于“理论澄清和统一”，不要写成“提出新的归因量”。

## 创新点二：面向 ViT 的结构化 NNS 扩展

> 针对 ViT 的多输入、多分支结构，将 NNS 从单个内部目标的总输入图扩展为真实计算边上的结构化局部微分表示，覆盖 token-channel、通道聚合目标、multi-head attention 和 residual 等内部对象。

## 创新点三：Attention 与 residual 的路径分解

> 针对 attention 的输入依赖性，建立 Q-induced、K-induced 和 V-induced differential 分解；针对 residual，使用输出处共享 cotangent 建立 identity/branch 分解，并给出分解闭合的条件和数值验证方法。

## 创新点四：局部分解的经验规律和干预边界

> 在两个固定预训练模型上系统研究结构路径的层深变化，并通过与真实前向变量对齐的激活替换，检验局部路径图对有限效应的预测能力及其随干预幅度变化的适用边界。

如果文献检索发现已有工作已经给出非常相似的 Q/K/V 或 residual 分解，应把“建立”改成“系统化”或“在 NNS 框架下统一实现”。

# 六、建议重构理论章节

## 6.1 从 NNS 的一般定义开始

设网络为计算图：

\[
G=(V,E),
\]

输入为 \(x\)，目标为标量 \(s(x)\)。定义 NNS 局部输入图：

\[
E_s(x)=x\odot\nabla_xs(x).
\]

随后明确说明：

> 该式在数学上与 Input × Gradient 相同。本文沿用“学习图像”一词，是为了保持与 NNS 文献的概念连续性；在理论讨论中，更准确地称其为“局部输入依赖图”。

建议全文采用双层术语：

- 历史名称：NNS 学习图像；
- 数学名称：局部输入依赖图。

第一次出现后可写为“NNS 局部输入图”。

---

## 6.2 重新写 NNS 等价命题

### 命题 1：标量目标等价性

若 NNS 在各层使用实际前向状态下的精确局部导数，且未引入归一化、截断或相关性重分配，则：

\[
E_s(x)=x\odot\nabla_xs(x).
\]

### 证明内容

- 从计算路径展开梯度；
- 说明多路径求和；
- 说明卷积、线性层和激活层只是 Jacobian 的特殊形式；
- 说明非光滑点采用自动微分框架的导数约定；
- 说明该等价关系不依赖 CNN 架构。

### 紧接着加入限制

\[
\sum_i E_{s,i}(x)
=
x^\top\nabla_xs(x)
\]

一般不等于：

\[
s(x).
\]

只有在特定的一阶正齐次条件下，结合 Euler 定理才可能成立。ViT 中的 softmax、LayerNorm 偏移、bias、位置编码和 CLS token 都会破坏简单的输出值完整性。

---

## 6.3 定义计算边归因

对于计算图中的某一切面，设中间变量为：

\[
z=(z_1,\ldots,z_m),
\]

目标可写成：

\[
F(x)=\Phi(z_1(x),\ldots,z_m(x)).
\]

定义每个边变量的 cotangent：

\[
g_k=\frac{\partial F}{\partial z_k}.
\]

对应的输入微分项为：

\[
D_k(x)
=
J_{z_k}(x)^\top g_k,
\]

结构化 NNS 图为：

\[
E_k(x)
=
x\odot D_k(x).
\]

在合法切面上：

\[
\nabla_xF(x)
=
\sum_{k=1}^{m}D_k(x),
\]

因此：

\[
E_F(x)
=
\sum_{k=1}^{m}E_k(x).
\]

需要说明，这一分解的对象是目标微分，不是目标函数值。

---

## 6.4 给出“合法计算切面”的严格定义

建议至少满足以下条件：

1. 从输入到目标的所有有效计算路径均通过该切面；
2. 每条路径在切面上被计入一次；
3. 不遗漏 bypass；
4. 不重复使用已经包含下游分支效应的梯度；
5. 多输入算子的各输入边分别计入；
6. 共享张量的不同使用边按照计算图边区分，而不是仅按张量名称区分。

加入两个反例。

### 反例一：遗漏 residual identity

如果只分解 \(f(u)\)，则无法恢复：

\[
y=u+f(u)
\]

的完整微分。

### 反例二：重复使用 \(\nabla_uF\)

若将完整的 \(\nabla_uF\) 作为 identity 项，再额外加入 branch 项，会重复计算分支对 \(u\) 的影响。

# 七、重写 Attention 分解

## 7.1 基本分解

对于单个 attention head：

\[
O=AV,
\]

其中：

\[
A=\operatorname{softmax}(S),\qquad
S=\frac{QK^\top}{\sqrt d}.
\]

局部微分：

\[
\mathrm dO=(\mathrm dA)V+A\,\mathrm dV.
\]

定义：

\[
\mathrm dO_{\mathrm{routing}}
=
(\mathrm dA)V,
\]

\[
\mathrm dO_{\mathrm{value}}
=
A\,\mathrm dV.
\]

必须统一称为：

- routing differential；
- value differential。

不建议简称为“routing 成分”和“value 成分”，因为这容易被理解为前向激活的两个组成部分。

---

## 7.2 Q/K/V 分解

由于：

\[
\mathrm dS
=
\frac{\mathrm dQK^\top+Q\mathrm dK^\top}{\sqrt d},
\]

可定义：

\[
\mathrm dA_Q
=
J_{\mathrm{softmax}}(S)
\left(
\frac{\mathrm dQK^\top}{\sqrt d}
\right),
\]

\[
\mathrm dA_K
=
J_{\mathrm{softmax}}(S)
\left(
\frac{Q\mathrm dK^\top}{\sqrt d}
\right).
\]

因此：

\[
\mathrm dO
=
\underbrace{(\mathrm dA_Q)V}_{Q\text{-induced}}
+
\underbrace{(\mathrm dA_K)V}_{K\text{-induced}}
+
\underbrace{A\mathrm dV}_{V\text{-induced}}.
\]

对应的输入图满足：

\[
E_{\mathrm{attention}}
=
E_Q+E_K+E_V.
\]

但要说明：

- \(E_Q\) 不是 Q 激活本身；
- \(E_K\) 不是 K 激活本身；
- \(E_V\) 不是 V 所携带的全部信息；
- 三者是当前输入和目标下的局部微分路径图；
- 分解依赖具体 attention 实现。

---

## 7.3 Multi-head 分解

对于：

\[
O=\operatorname{Concat}(O_1,\ldots,O_H)W_O,
\]

可进一步分解为：

\[
E_{\mathrm{MHA}}
=
\sum_{h=1}^{H}E_h,
\]

以及：

\[
E_h=E_{h,Q}+E_{h,K}+E_{h,V}.
\]

需要明确 output projection 是否包含在 head 路径中。建议把 \(W_O\) 纳入每个 head 的下游线性传播，以保证各 head 项在 output projection 后闭合。

---

# 八、重写 Residual 分解

对于：

\[
y=u+f(u),
\]

在 residual 输出处取得：

\[
g_y=\frac{\partial F}{\partial y}.
\]

则：

\[
\mathrm dF
=
\langle g_y,\mathrm du\rangle
+
\langle g_y,\mathrm df(u)\rangle.
\]

定义：

\[
D_{\mathrm{id}}
=
J_u(x)^\top g_y,
\]

\[
D_{\mathrm{branch}}
=
J_{f(u)}(x)^\top g_y.
\]

于是：

\[
E_{\mathrm{residual}}
=
E_{\mathrm{id}}
+
E_{\mathrm{branch}}.
\]

建议单独强调：

> identity 项必须使用 residual 输出处的共享 cotangent，而不能直接使用完整的 \(\nabla_uF\)，因为后者已经包含 branch 通过 \(u\) 传播的影响。

这部分可以成为论文最有方法辨识度的内容之一。

# 九、重新定义和补全所有统计指标

## 9.1 RGB 聚合规则

应预先固定一种主规则。例如：

\[
M(p)
=
\sum_{c\in\{R,G,B\}}
|E_{p,c}|.
\]

将 \(M(p)\) 作为绝对局部质量。

同时保留：

\[
M^+(p)=\sum_c\max(E_{p,c},0),
\]

\[
M^-(p)=\sum_c\max(-E_{p,c},0),
\]

用于正负符号分析。

主统计建议使用 absolute mass，正部图仅用于辅助显示。

---

## 9.2 Patch 质量

对于第 \(j\) 个 patch：

\[
m_j
=
\sum_{p\in P_j}M(p).
\]

归一化：

\[
p_j
=
\frac{m_j}{\sum_km_k+\varepsilon}.
\]

零质量样本必须说明处理方式，例如：

- 若总质量低于阈值则排除；
- 或定义为均匀分布；
- 更推荐排除并报告比例。

---

## 9.3 空间熵

建议使用归一化熵：

\[
H
=
-\frac{\sum_{j=1}^{N}p_j\log p_j}{\log N}.
\]

这样：

\[
H\in[0,1].
\]

数值越大表示局部质量在更多 patch 上分散，但不能直接等同于“更高级语义”。

---

## 9.4 Own-token locality

对于 patch token \(t\)：

\[
L_{\mathrm{own}}
=
p_t.
\]

对于 CLS token，不存在自然的 own patch，因此：

- 不计算该指标；
- 或单独定义 CLS 的中心区域质量，但不能与 patch token 混合。

---

## 9.5 Normalized distance

设 patch 中心坐标为 \(r_j\)，目标 token 中心为 \(r_t\)，图像最大可能距离为 \(D_{\max}\)，则：

\[
D
=
\sum_jp_j
\frac{\|r_j-r_t\|_2}{D_{\max}}.
\]

CLS 目标可以改为相对图像中心计算，但必须与 patch-token 指标分开报告。

---

## 9.6 Routing scale

建议写为：

\[
R
=
\frac{\|E_{\mathrm{routing}}\|_1}
{\|E_{\mathrm{routing}}\|_1+\|E_{\mathrm{value}}\|_1+\varepsilon}.
\]

同时必须报告：

\[
\|E_{\mathrm{routing}}\|_1,
\qquad
\|E_{\mathrm{value}}\|_1,
\qquad
\|E_{\mathrm{full}}\|_1.
\]

不能只报告 \(R\)，否则无法判断其变化来自 routing 增强还是 value 减弱。

---

## 9.7 Identity scale

同样定义：

\[
I
=
\frac{\|E_{\mathrm{id}}\|_1}
{\|E_{\mathrm{id}}\|_1+\|E_{\mathrm{branch}}\|_1+\varepsilon}.
\]

并同时报告两项的绝对范数。

---

## 9.8 Value-only 近似误差

建议增加：

\[
\operatorname{RelErr}_{V}
=
\frac{
\|E_{\mathrm{full}}-E_V\|_2
}{
\|E_{\mathrm{full}}\|_2+\varepsilon
}.
\]

还可以报告：

\[
\operatorname{CosSim}_V
=
\frac{
\langle E_{\mathrm{full}},E_V\rangle
}{
\|E_{\mathrm{full}}\|_2\|E_V\|_2+\varepsilon
}.
\]

这比单独使用 routing scale 更直接地支持“Value-only 近似在深层变差”的结论。

# 十、重新设计实验体系

建议把实验分为四组，避免所有结果混在一起。

## 实验一：NNS 等价性与数值正确性

### 目的

验证原始 NNS 逐层递推与自动微分 Input × Gradient 是否一致。

### 内容

在 CNN 和 ViT 的若干基础模块上分别计算：

\[
E_{\mathrm{NNS}}
\quad\text{与}\quad
x\odot\nabla_xs.
\]

报告：

- 最大绝对误差；
- 相对 L1/L2 误差；
- cosine similarity；
- float32 和 float64 的差异。

### 意义

这不是比较谁更好，而是验证 NNS 的 Jacobian 解释。

---

## 实验二：结构路径闭合性

### Attention 闭合

\[
E_{\mathrm{full}}
\approx
E_{\mathrm{routing}}+E_{\mathrm{value}},
\]

\[
E_{\mathrm{routing}}
\approx
E_Q+E_K,
\]

\[
E_{\mathrm{full}}
\approx
E_Q+E_K+E_V.
\]

\[
E_{\mathrm{residual}}
\approx
E_{\mathrm{id}}+E_{\mathrm{branch}}.

### Multi-head 闭合

\[
E_{\mathrm{MHA}}
\approx
\sum_hE_h.
\]

- 每个 head 的误差；
- 图像级误差分布；
- 最坏样本；

## 实验四：有限干预与局部近似边界

### 真实变量对齐

只替换实际存在的前向变量：

- Q；
- K；
- V；
- attention weight \(A\)；
- head output；
- residual branch output；
- identity edge 的 bypass 激活。

### 干预强度

定义：

\[
z_\alpha
=
z_{\mathrm{clean}}
+
\alpha
\left(
z_{\mathrm{ref}}-z_{\mathrm{clean}}
\right),
\]

其中：

\[
\alpha\in\{0.05,0.1,0.25,0.5,1.0\}.
\]

真实有限效应为：

\[
\Delta F_{\mathrm{actual}}(\alpha)
=
F(z_\alpha)-F(z_{\mathrm{clean}}).
\]

一阶预测为：

\[
\Delta F_{\mathrm{linear}}(\alpha)
=
\left\langle
\nabla_zF,
z_\alpha-z_{\mathrm{clean}}
\right\rangle.
\]

检验：

- \(\alpha\) 越小，误差是否越低；
- Q/K/V 的一阶预测能力是否不同；
- 不同层和目标是否存在差异；
- Endpoint 排序和 reference-aware Taylor 排序有何差别。

这会把“局部图不是有限因果贡献”的限制变成论文中的一个积极研究结论。

# 十一、修正区域替换和随机基线

## 11.1 区分两类方法

### Clean-only 方法

只使用 clean 输入：

- Endpoint；
- raw gradient；
- attention map 等。

### Reference-aware 方法

使用实际替换方向：

\[
z-z^{\mathrm{ref}}.
\]

例如：

\[
\left\langle
\nabla_zF,
z-z^{\mathrm{ref}}
\right\rangle.
\]

这两类方法的计算预算不同，不能简单进行无条件优劣排序。

---

## 11.2 重算随机基线

每次随机排序都应独立计算：

1. 该次随机排序下的有限效应曲线；
2. 按与其他方法完全相同的规则取绝对值；
3. 计算该次 AUC；
4. 重复 20 次或更多；
5. 对随机 AUC 求均值、中位数和区间。

不能先平均 signed curve 再取绝对值，否则正负抵消会系统性压低随机基线。

---

## 11.3 降低阈值判定的重要性

0.10、0.05 等阈值可以保留为预注册或工程判据，但主结果应报告：

- 配对效应差；
- bootstrap 置信区间；
- 图像级胜率；
- 中位数改善；
- 多阈值敏感性；
- 计算成本。

不要让“通过阈值”成为主要科学结论。

# 十五、摘要修改示例

下面给出一个可以直接据此重写的版本。

> 神经网络尺度（Neural Network Scale，NNS）从逐层局部尺度传播的角度，将网络内部目标映射回输入空间。现有 NNS 研究主要面向卷积神经网络，而视觉 Transformer 中输入依赖的注意力权重、多头结构和残差连接使内部响应具有更复杂的计算路径。本文首先从一般计算图的角度重新表述 NNS，证明在各层采用精确局部导数且不引入额外归一化或重分配规则时，标量目标的 NNS 学习图像可统一写为 \(x\odot\nabla_xs(x)\)，即 Input × Gradient。该等价关系明确了 NNS 学习图像的数学位置，也表明其描述的是当前输入点上的局部一阶依赖，而非目标值的完整贡献分解。
>
> 在此基础上，本文将 NNS 从单一内部目标的输入映射推广为视觉 Transformer 计算图上的结构化局部微分分解。针对多头注意力，本文将完整 attention differential 分解为 Q-induced routing、K-induced routing 和 V-induced differential；针对残差结构，本文在 residual 输出处使用共享 cotangent，将目标微分分解为 identity 和 branch 两条真实计算边的贡献。本文进一步给出合法计算切面的条件，并通过数值实验验证各路径项对完整局部输入依赖的闭合性。
>
> 本文在固定的 ImageNet 预训练 ViT-B/16 和 DeiT-S/16 checkpoint 上开展实验。结果表明，在预定内部目标抽样下，两个模型的局部输入依赖均随深度总体呈现空间扩展趋势；深层 attention 中 routing differential 在 routing/value 局部范数中的相对占比提高，且仅保留 V-induced differential 对完整 attention 局部响应的近似误差增加。有限激活替换实验进一步表明，结构化 NNS 图对小幅内部干预具有一定的一阶预测能力，但该能力随干预幅度增大而下降；对于已知参考输入的区域替换，显式使用实际替换位移的 Taylor 估计通常优于仅依赖 clean 输入的 Endpoint。
>
> 本文的结果表明，NNS 可以被理解为一般计算图上的局部尺度分析框架。其在视觉 Transformer 中的主要价值不在于构造新的基础输入归因量，而在于将内部目标的局部输入依赖组织为与 attention 和 residual 结构对应、可加且可验证的路径分解。相关经验结论限于本文研究的两个固定预训练模型。

# 十六、绪论中建议增加的一段核心表述

> 本文对 NNS 的扩展包含两个层次。第一层是表示层面的统一：原始 NNS 的逐层局部尺度传播可以由一般 Jacobian 链式法则表达，标量学习图像与 Input × Gradient 等价。第二层是结构层面的扩展：对于具有多输入算子、动态权重和旁路连接的视觉 Transformer，仅给出完整输入梯度不足以区分局部响应所经过的内部计算路径。因此，本文进一步研究如何在不遗漏和不重复计算的条件下，将完整局部输入依赖分解到 attention 的 Q/K/V 路径、多头路径以及 residual 的 identity/branch 路径。本文所称的 NNS 推广，主要指第二层结构化扩展，而不是重新定义第一层基础归因量。

# 二十一、修改后的论文应形成的最终逻辑

整篇论文最好形成以下闭环：

### 第一步：从 NNS 出发

原始 NNS 通过逐层尺度传播生成内部目标的学习图像。

### 第二步：澄清其数学位置

在精确局部导数条件下：

\[
E_s(x)=x\odot\nabla_xs(x).
\]

因此 NNS 学习图像是局部一阶输入依赖，而不是新的基础归因函数。

### 第三步：指出 ViT 带来的新问题

普通总梯度图无法区分局部响应经过：

- Q；
- K；
- V；
- 不同 head；
- residual identity；
- residual branch。

### 第四步：提出结构化 NNS

把完整局部依赖分解到真实计算边，并给出合法切面和闭合条件。

### 第五步：进行数学和数值验证

证明并验证：

\[
E_{\mathrm{full}}
\approx
\sum_kE_k.
\]

### 第六步：分析两个模型中的路径规律

研究空间扩展、routing/value、Q/K/V 和 residual 路径的层深变化。

### 第七步：检验适用边界

通过不同幅度的真实变量替换说明：

- 小扰动下局部预测较有效；
- 大扰动下非线性误差增加；
- reference-aware Taylor 更适合特定有限替换；
- NNS 不应被解释为完整因果贡献。

### 第八步：得出总体结论

> NNS 的更一般意义，是为内部目标提供基于局部 Jacobian 的输入坐标表示；本文对 NNS 的主要扩展，是将这种表示从 CNN 的逐层单元传播推广到 ViT 的结构化计算图分解。该扩展使 attention 和 residual 中不同真实路径的局部输入依赖可以被分别表示、加和验证和经验分析。

# 二十二、最终建议

论文的结论可以“写大”，但建议把“大结论”放在**NNS 的理论一般化和方法框架层面**：

> NNS 可以从 CNN 专用的学习图像方法提升为一般神经网络计算图上的局部尺度分析框架。

同时把经验结论写得严格：

> 在两个固定 ViT checkpoint 中观察到若干一致的路径级层深趋势。

不要反过来把有限模型实验扩大成整个 ViT 的普遍机制。

经过上述修改，论文不再是“把 Gradient × Input 换成 NNS 名称并应用于 ViT”，而是形成以下清楚贡献：

> **以 NNS 为概念起点，明确其与 Input × Gradient 的关系，并进一步建立适用于视觉 Transformer 内部 attention、Q/K/V、multi-head 和 residual 结构的计算图局部微分分解框架。**

这既能保留 NNS 作为论文的理论主线，也更符合硕士论文对准确性、系统性和新增工作的要求。
