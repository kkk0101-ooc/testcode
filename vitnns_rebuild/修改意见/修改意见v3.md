## 一、研究问题与科学价值

### 优点

研究问题已经比一般可解释性论文更清楚。四个问题分别处理数学身份、结构分解、层深规律和有限干预，见[主文第25行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:25)。

### 主要问题

#### 1. 真正的学术位置仍然偏弱

当前论文的真实贡献更接近：

- 原始 NNS 思想在 ViT 上的系统化实现
- 面向特定计算图的结构微分分解
- 大规模数值正确性验证
- 两个固定模型上的描述性经验分析

它不是新的基础归因理论，也很难被认定为首次提出 Transformer 路径分解。论文在[第54至56行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:54)已经主动收紧了定位，这是正确的。但现有相关工作只有五个很短的小节，参考文献仅约十余项，无法证明作者掌握了这一领域的主要技术脉络。

尤其缺少与以下工作的直接比较：

- [GlobEnc](https://aclanthology.org/2022.naacl-main.19/)

- Transformer token contribution propagation
- Full-gradient 类方法
- saliency sanity check
- edge attribution 和 activation patching
- 计算图归因的参数化依赖问题

你们自己的 prior-art 审计已经把工作定位为“复现、统一实现和系统实证审计”，见[相关工作审计第26至28行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/docs/NNS_ViT_Endpoint_Scanner_EP0相关工作审计_20260918.md:26)。但正式论文没有充分展开这个判断。

**评审结论**

方法具有硕士论文级别的工作量，但目前的新颖性论证还不够。是否达到学位要求，将高度依赖你能否把“系统化实现和经验发现”论证为明确、不可被现有方法直接替代的贡献。

#### 2. 四个 RQ 的层级并不对称

RQ1 本质上是数学澄清。RQ2 是方法构造和正确性验证。RQ3 才是主要经验科学问题。RQ4 是效用和边界问题。

当前将四者并列，容易造成每个 RQ 都有同等研究深度的印象。实际上，RQ1 和 RQ2 很大程度上是链式法则及其实现验证，RQ4 又没有完成多幅度线性化实验。

更合适的论文主线应分为三个层次：

1. NNS 的数学身份
2. ViT 计算图上的结构化表示
3. 结构规律和有限干预中的有效范围

这样比把四项都包装成同级科学问题更稳健。

当前状态下，章节题名“一阶近似边界”仍然偏大。

### 2. “训练强化趋势”的表述带有未识别的因果含义

论文比较了一个训练 checkpoint 与三个随机初始化状态，并写出“训练后参数强化其幅度”，见[第307至309行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:307)。

这个设计只支持：

> 训练 checkpoint 与随机参数状态存在差异。

它不能单独识别训练过程造成了该差异。原因包括：

- 每个架构只有一个训练 checkpoint
- 没有同一初始化在训练前后的配对轨迹
- 随机状态与训练状态的输出尺度、置信度和梯度条件可能不同
- 只有三个随机种子，无法稳定估计初始化总体差异

建议将“训练强化”统一改成“训练参数状态下的幅度更大”。如果要保留训练效应，需要加入多个训练种子或训练前后 checkpoint。

### 3. 干预对象是人为构造的混合前向状态

实验只替换一个 head edge，其他 heads 和 identity 保持 clean。这是一个合法的计算图干预，但替换后的内部状态未必对应任何自然输入产生的完整前向状态。

因此，它识别的是：

> 规定替换算子下某条边的局部有限效应。

它不等于自然图像区域的因果贡献，也不等于该 head 在正常推理中的全部功能。当前稿对此总体上较克制，但答辩时必须能明确说明这一点。

## 三、方法学与统计推断

### 1. 命题 1 的理论贡献容易被认为是定义性结果

命题 1 从

\[
\mathcal L(x;x)=\operatorname{diag}(x)
\]

和 Jacobian 传播规则直接推出

\[
E_s(x)=x\odot\nabla_xs(x).
\]

推导本身正确，见[第68至91行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:68)。但它主要是链式法则的归纳结果，不应被当作强理论创新。

更严重的是，原 NNS 官方实现不可得。现有验证本质上是论文公式解释与自建实现之间的一致性验证，而不是对原作者实现的独立复现。因此，Table 2 的 5,000 次比较首先证明代码实现自洽，不能单独证明“原始 NNS 在全部适用条件下就是该定义”。

建议补充：

- 原 NNS 每类算子的逐式映射表
- 末端门控、池化并列和非光滑点的解释选择
- “paper-formula regression”与“官方实现复现”的明确区分
- 一个与当前实现独立编写的最小数值验证

### 2. 结构分解缺少唯一性与参数化讨论

合法计算切面定义和 residual 反例是目前理论部分最扎实的内容，见[第155至165行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:155)。

但还缺少一个关键问题：

> 同一个函数经过等价重参数化或不同切面选择后，Q/K/V、head 和 residual 路径图是否保持不变？

当前结果只能说明，在固定实现、固定图结构和固定切面下，各项能够闭合。闭合并不意味着分解唯一，也不意味着它具有实现不变性。

这是理论章节最需要补充的内容。至少应给出以下之一：

- 证明某类重参数化下的路径图不变
- 构造反例说明它依赖图表示
- 将方法正式定义为“相对于指定计算图与切面的分解”

### 3. 单元覆盖率太低，模型层面的语言仍偏宽

分层研究只覆盖 post-block token-channel 候选的 0.338% 和 0.677%，见[第212行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:212)。

## 四、结果解释与外推边界

### 最可信的结果

以下结果可信度较高：

- NNS 公式解释与当前实现之间的数值一致性
- 固定计算图上的 Q/K/V 与 residual 路径闭合
- 冻结样本中的空间扩展趋势
- 深层 Value-only 近似误差上升
- 区域替换中 regional Taylor 明显优于 Endpoint
- 随机基线修正后，Endpoint 对 random 没有稳定优势

其中最后两点很重要。它们使论文更接近严肃的边界研究，而不是方法宣传。

### 容易被过度解释的结果

1. **11/12 family 满足复合条件**

Table 3 的相关中位数约为 0.10 至 0.31，见[第327至344行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:327)。这是小到中等关联。不能仅凭“11/12”写成强行为预测能力。

2. **空间扩展不等于语义提升**

熵增加、locality 下降和距离增加只说明绝对局部质量变得更分散，见[第263至269行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:263)。它不能证明深层“理解了全局语义”。

3. **Feature 与 Endpoint 的相关性较弱**

正确配对 Spearman 为 0.2663 和 0.2811，见[第315至317行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:315)。它高于负控制，但仍远低于一致或等价。合理解释是两者有关联，但描述不同对象。

4. **像素分辨率可能主要来自 patch projection**

模型首先使用 $16\times16$ patch embedding。像素级纹理可能受到 patch projection 权重强烈影响。当前没有 patch 内置乱、patch 内均匀化或浅层权重匹配控制。这是“空间细粒度来自学习结构”之外的重要替代解释。

5. **跨模型绝对范数不可直接比较**

两个模型使用不同 normalization，见[第203至210行](/data01/home/yeziqi.831/nxtrec_wksp/testcode/vitnns_rebuild/papers/nns_vit_endpoint/publication_r2_20260920/zh/manuscript.md:203)。Endpoint 又依赖输入坐标原点。因此使用斜杠并列两个模型的 absolute mass 容易被读成可直接比较。建议分模型报告，主要比较模型内部的层深变化。
