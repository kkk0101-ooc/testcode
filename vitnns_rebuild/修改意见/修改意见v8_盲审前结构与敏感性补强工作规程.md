## 2. 冻结分析合同

### 2.1 实际 target--cut 图结构认证

对 model_registry.json 中两个标准 pre-LN、12-block、unfused ViT 后端分别展开有向无环图。节点覆盖 patch embedding、每层 norm1、逐 head Q/K/V、routing/value 合流、head-to-concat use、attention projection、两次 residual addition、norm2、MLP 和最终 norm/classifier。

对每个标量 target 与每个 block 的八类 cut，计算所有输入到 target 的路径可能穿过的 cut-edge 数集合：

- 仅为 {1} 时，认证为完整 target cut。
- 对 attention branch partition，若其完整截断输入到该 branch 的路径、且该 branch 位于 target 上游，则认证为 branch contribution partition，而不冒充完整 target cut。
- target 位于 cut 上游或声明 reconstruction object 不匹配时，记为不适用。

同一 producer 的不同 consumer、slot、invocation 保持独立 use identity。架构证明只适用于 registry 绑定的标准 pre-LN block，不外推到额外分支、fused backend 或其他架构。

### 2.2 三类 registry

新建只读派生 registry：

1. scalar_target_registry.json：仅包含标量 readout、位置、聚合规则和逐模型计数。
2. decomposition_registry.json：仅包含 native use、解析 differential partition、cut 与 reconstruction target。
3. intervention_registry.json：仅包含实际可替换变量、reference、finite effect 和区域任务合同。

原 457/385 是每图标量 readout 数，不是 decomposition 或 intervention 数，也不是穷举神经元数。必须由原始 target rows 重新计数，禁止手工改数。

### 2.3 空间熵质量敏感性

质量变量为每个 M3 unit map 在归一化输入坐标上的总 L1 absolute mass。阈值在每个 model--block 内由全部冻结图像和单元的 mass 分布确定，不读取 entropy 后选择。

报告每个 model--block 的 1%、5%、10%、25%、50%、75% mass 分位点；每图逐 block 的 Spearman(log1p(total mass), entropy) 再跨 12 blocks 算术平均；按 model--block mass 四分位分组后的每图 late-minus-early entropy；以及剔除每个 model--block 最低 1%、5%、10% mass 后的同一对比。

图内先汇总，图像是统计单位。所有原样本保留在审计表；剔除只定义敏感性估计量，不改变主分析样本或判断。区间为 10,000 次固定 namespace 的图像 bootstrap percentile median interval。

### 2.4 H4 匹配聚合敏感性

原 H4 保持：

M(j,b,h) = sum_i abs(L(j,b,h,i)); G_AG(j,b,h) = abs(inner(z(j,b,h), grad_z s_j)).

新增 matched-aggregation path score：M_sum(j,b,h) = abs(sum_i L(j,b,h,i))。

它与 G_AG 均为先在坐标内求和、再取绝对值。每个 block 在 heads 内分别计算 path score 与有限替换绝对效应的 Spearman，并减去 activation × gradient 对应相关；再对 blocks 0、3、7、11 算术平均。图像是统计单位，报告中位数、10,000 次 bootstrap 区间及正/负/平计数。该分析不替换原 H4，也不新增确认性检验。

### 2.5 随机区域基线

不重复模型实验。复核既有 S9：每次 random repeat 先取 absolute effect 并积分 AUC，再平均 20 次；报告 relative MC SE、5/10/20-repeat 重采样、split-half 与 leave-one-repeat-out。该项若来源和数值验证通过，状态记为 ALREADY_COMPLETE。
