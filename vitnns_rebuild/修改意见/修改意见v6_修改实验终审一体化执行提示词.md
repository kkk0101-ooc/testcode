### 6.1 建立三层闭合对象

正文必须分别定义以下对象。

#### 全局合法切面

对最终注册目标 $s$，若边集合 $C^{\mathrm{global}}$ 覆盖每条有效 input-to-target path 恰好一次，则

$$
\sum_{e\in C^{\mathrm{global}}}\mathcal L_{e,i}(s;x)
=x_i\frac{\partial s(x)}{\partial x_i}.
$$

在第一处 residual addition 上，下列才是完整目标切面：

- identity 加 attention branch；
- identity 加全部 heads；
- identity 加 Q、K、V induced terms；
- identity 加 routing-induced 与 value-induced terms。

#### 分支内部微分分组

设 attention branch 输出为 $a=f(u)$，其在 residual addition 处的下游 cotangent 为 $g_y$。定义 branch contribution

$$
\mathcal B_i^{\mathrm{attn}}(s;x)
=x_i\left[J_{a,x}(x)^{\mathsf T}g_y^{(s)}\right]_i.
$$

Q/K/V、heads 和 routing/value 的分支内关系应写为

$$
\mathcal B_i^{\mathrm{attn}}
=\mathcal B_i^{Q}+\mathcal B_i^{K}+\mathcal B_i^{V}
=\mathcal B_i^{\mathrm{routing}}+\mathcal B_i^{\mathrm{value}}.
$$

这些是 branch-internal differential partitions。它们单独不等于完整类别目标 G×I。

#### Residual 全局切面

$$
x_i\frac{\partial s}{\partial x_i}
=\mathcal L_{i}^{\mathrm{identity}}+\mathcal B_i^{\mathrm{attn}}
$$

或对第二处 residual 使用 carry 与 MLP branch。正文、图注、表格和验证器必须使用同一对象名。

### 6.2 建立四类对象词表

主文方法部分增加一张紧凑表。

| 类别 | 例子 | 是否原生前向张量或 use | 是否可直接替换 | 闭合对象 |
| --- | --- | --- | --- | --- |
| 原生计算图边 | residual add 的 identity/branch input、head 到 concat 的输入、Q/K/V projection slot | 是 | 视实现合同而定 | branch 或 full target |
| 解析微分分组 | Q-induced、K-induced、routing-induced、value-induced | 否，是微分项分组 | 否 | attention branch differential |
| 可干预前向变量 | attention probability $A$、value tensor $V$、head output、residual branch activation | 是 | 是 | 规定有限替换效应 |
| 汇总或排序分数 | map absolute mass、regional score、Taylor score | 否 | 不适用 | 统计 estimand |

禁止把解析微分分组称为 actual edge。`routing` 在微分段落中统一写为 `routing-induced differential`；在干预段落中统一写为 `attention-probability replacement`。`value` 分别写为 `value-induced differential` 和 `V-projection replacement`。

### 6.3 统一 Endpoint 术语

全文只使用以下术语。

- **Total Endpoint**：完整注册目标的 $x\odot\nabla_xs(x)$。

- **Branch contribution map**：一个 branch-internal partition 的加和。
- **Regional map score**：指定 map 在候选区域内的聚合分数。
- **Reference-aware Taylor score**：包含实际 activation displacement 的一阶估计。

### 7.1 实验 A：坐标参数化敏感性

目标是判断主要层深轨迹在三种输入表示下是否保持。

1. normalized-input Endpoint：现有主量。
2. raw-pixel gradient：

   $$
   G_i^{\mathrm{raw}}=\frac{\partial s}{\partial r_i}
   =\frac{1}{\sigma_i}\frac{\partial s}{\partial x_i}.
   $$

3. common-origin raw-pixel weighted gradient：

   $$
   E_i^{(r_0)}=(r_i-r_{0,i})\frac{\partial s}{\partial r_i}.
   $$

   主分析固定 $r_0=(0,0,0)$，RGB 范围为 $[0,1]$。该原点不依赖模型 normalization，也不得在查看结果后更换。

最低覆盖范围：

- 原 100 图/模型的固定 token-channel 单元，复算 entropy、locality 和 normalized distance；
- 原 400 图/模型的 Q/K/V path maps，复算 late-minus-early spatial entropy；
- 原 400 图/模型的 attention 与 MLP residual maps，复算 output–identity spatial TV。

统计单位继续为图像。不得把坐标方案当独立样本。结果按每个模型和对象分别报告方向、图像级中位差和 95% bootstrap 区间。该分析属于新前瞻稳健性检查，不改写旧确认性结论。

判定规则：

- 三种表示方向一致，只允许写“主要方向对这三种坐标表示保持”。
- 方向不一致或区间跨零，正文主结论必须限定为 normalized-input Endpoint 的性质。
- 不设必须为正的通过门，不因结果不利而更换 $r_0$。

### 7.2 实验 B：独立解析参考实现

目标是降低主扫描器、hook 和同一 autograd 图共同出错的风险。

实现一个独立的小型 CPU float64 测试模块。它不得导入 `endpoint_vit.py`、`endpoint_e3_closure.py` 或主扫描器的 component 构造函数。

最低模型：

- 一个小型单头或双头 attention block；
- 一个 pre-LN residual attention block；
- 一个共享 producer 到两个 consumer slots 的 fan-out toy graph；
- 固定非对称权重和非零输入，避免零项使 mutation 无法区分。

独立参考必须显式构造 affine Jacobian、softmax Jacobian $\operatorname{diag}(a)-aa^{\mathsf T}$、Q/K/V 微分、head concat/output projection 和 residual identity。逐元素比较：

- Q-induced map；
- K-induced map；
- V-induced map；
- routing-induced map；
- value-induced map；
- 每个 head map；
- identity map；
- branch map；
- branch reconstruction；
- with-bypass full reconstruction。

同时使用中心有限差分检查随机但冻结的输入方向。每个分量必须保存 max absolute error、relative L2 和 tolerance。

### 7.3 实验 C：新增结构 mutation

至少实现以下两类故障。

1. **Wrong-slot mutation**：把 multi-input consumer 的 cotangent 或 replacement 绑定到错误 input slot。正确验证器必须拒绝。
2. **Merged fan-out mutation**：将同一 producer 的两个 consumer uses 提前合并，丢失 use identity 或造成重复。正确验证器必须拒绝。

如独立 attention reference 还可低成本覆盖 detach mutation，可作为补充，但不得用它替代上述两项。

### 7.4 统计与阈值再审计

优先使用既有逐图数据进行 CPU-only 分析。

1. 建立分析身份总表，逐项标记 `confirmatory`、`prospective robustness`、`exploratory` 或 `post-hoc`。
2. 列出每个 multiplicity family、成员、冻结时间、校正方法和主张用途。不得事后把不同 family 合成一个新的确认性 family。
3. 解释 0.10 相关门槛和 0.05 区域增益门槛的来源。若无外部依据，明确它们是研究者设定的实际意义阈值。
4. 使用现有逐图值报告 0.05、0.10、0.15 三个相关阈值下的描述性结论变化。区域增益也给出预先固定的一组合理阈值敏感性。
5. 原 composite criterion 的公式、必要条件和与 `CI lower > 0.10` 的区别必须写清。原判定不得重算成新的主结论。
