# 1. Introduction

Vision Transformers (ViTs) divide an image into patches, project the patches into tokens, and repeatedly update the token sequence through multi-head self-attention and token-wise multilayer perceptrons (Dosovitskiy et al., 2021). This architecture provides several internal objects for inspection: a response may belong to a token, channel, head, branch, residual stream, or final class output. Activations and attention weights describe parts of this computation, but they do not directly answer where, in the original image, a specified response change relative to a reference originated.

Neuron and feature visualization offer complementary views of deep networks. Activation maximization searches for inputs preferred by a unit, saliency and attribution methods explain a given input, and attention visualization exposes routing between tokens. The Neural Network Scanner (NNS) of Dou et al. (2023) constructs a learning image for a neuron in an FCN or CNN, representing its response while retaining input location and allowing neuron images to be combined at the module level. A ViT extension requires more than enlarging a token grid. Attention weights depend on the input, residual additions combine bypass and branch responses, and a class output follows multiple stages of token mixing, final normalization, CLS selection, and classification.

We study three connected questions. First, how can a learning image be defined for an internal ViT response or class output while remaining numerically linked to the actual forward computation? Second, can the spatial ranking induced by such a map be evaluated through input interventions? Third, can a complete class attribution be accounted for by heads, attention, MLP, and residual components to describe allocation across depth? We construct learning images with integrated gradients along a straight input path and distinguish three objects. Module-own-response maps explain the output of patch embedding, attention, an MLP, or a residual addition. Fixed-clean-attention conditional Value-path maps explain a prespecified internal direction while cutting the variation of Q, K, and softmax attention along the integration path. Complete-cut class-component maps retain the downstream class derivative and assign one full-model IG map to internal components. This separation aligns each visualization with its target and admissible interpretation.

The main empirical evidence uses a frozen ViT-B/16 and an independent 500-image cohort. For a fixed block-0/head-9 internal target, the NNS ranking has a positive 4x4-cell fidelity difference from a target-matched patch-token baseline with uniform within-patch allocation on all 500 images; the median difference is 2.3082. The median falls to zero at the native patch scale, and three other prespecified coordinates have much smaller effects. In an independent 50-image class-explainer comparison, NNS scores below Grad-CAM, above rollout, and is not significantly different from full-model IG or raw CLS attention under the registered tests. A 100-image complete-cut analysis supports depth-dependent changes in attention and MLP branch shares in opposite directions.

This study makes four contributions:

1. It defines input-coordinate learning images for internal ViT scalars and class scalars and relates them to patch embedding, attention, the MLP, two residual additions, and the classifier path.
2. It verifies completeness and residual additivity on a frozen model, extending real module demonstrations from patch embedding to a complete class logit and contrasting the correct class, strongest competitor, decision margin, and a low-score output.
3. It evaluates the ranking of a specified internal target through 500-image fine-scale interventions and locates the empirical scope through scale, layer/head coordinates, prediction strata, and an independent explainer comparison.
4. It organizes a class attribution into complete internal cuts, reports their reconstruction and depth-wise branch allocation, and retains negative stability results, invalid endpoints, and post-hoc exploratory findings.

The remainder of the paper reviews NNS, input attribution, and ViT explanation; defines the method and protocols; and reports real-module computation, intervention results, sensitivity analyses, explainer comparisons, complete-cut accounting, and depth extensions before discussing the study's scope and limitations.
