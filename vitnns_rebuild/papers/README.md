# NNS-ViT papers

This directory contains two independent manuscript projects. Each paper owns its language drafts,
notes, quality-control records, references, scripts, and frozen figure manifest.

| Paper root | Scientific object | Primary reading copy | Figure package |
|---|---|---|---|
| `nns_vit_path/` | Path-integrated NNS-ViT learning images and complete-cut analyses | `nns_vit_path/zh/full_draft.md`, `nns_vit_path/en/full_draft.md` | `reports/nns_vit_unified_paper_figures_r10_r4_20260917/` |
| `nns_vit_endpoint/` | Endpoint $x\odot\nabla_xs(x)$ scanning, structured decomposition, and interventions | `nns_vit_endpoint/zh/full_draft.md`, `nns_vit_endpoint/en/full_draft.md` | `reports/nns_vit_endpoint_unified_paper_figures_r2_20260918/` |

Do not place paper-specific files directly under `papers/`. Shared repository-level experimental
evidence remains in `evidence/`, `reports/`, `manifests/`, and `docs/`.
