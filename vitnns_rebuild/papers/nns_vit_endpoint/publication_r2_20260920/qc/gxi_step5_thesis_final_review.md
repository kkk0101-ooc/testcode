# 第五步硕士毕业论文对抗式终审报告

## 总评与送审判断

终审对象是第五步同步重写后的中英文现役稿、补充材料、图表、related-work matrix、claim-to-evidence 表和第四步封存证据。按硕士毕业论文标准，当前研究问题明确，方法对象可形式化，关键数字可回链，阴性结果和外推边界均进入正文。论文达到内容送盲审条件。其方法价值来自目标条件化双索引局部微分对象及合法切面审计，不来自 Gradient × Input 公式本身。

当前结论为 `可送审`。这一判断针对学术内容，不替代学校模板、匿名规则、作者字段和最终归档检查。

## 1. 研究问题与科学价值

**问题。** 原稿入口容易让读者把贡献理解为 G×I 在 ViT 上的工程扩展。Conductance、DecompX/LRP、EAP/Vi-CD 与 Unpack 已覆盖内部归因、组件传播、边干预和命名路径的关键部分。

**证据位置。** 双语摘要、Sections 1、2.5、4.1–4.3，Table 1，Figures 1–2。

**影响。** 如果研究问题停留在生成内部热图，方法创新不足；如果问题落在同一 current-point local differential 的 $[e,i]$ 表示、合法切面和可检验经验用途，则形成可回答的研究问题。

**修改建议与判断。** 标题、摘要和贡献二已经直接定义 $\mathcal L_{e,i}(s;x)$。Related Work 明确最强近邻和失效条件。`NOV-JOINT-1` 只覆盖联合字段。研究问题和文献位置达到送审要求。

## 2. 研究设计与因果逻辑

**问题。** 结构闭合、局部路径尺度和有限替换属于不同证据层级。闭合不能替代因果干预，参数状态比较也不能识别训练过程。

**证据位置。** 命题 2，审计协议表，Sections 5.4、6.1、7、8.1–8.2。

**影响。** 混用这些证据会把实现正确性扩大为机制因果结论。

**修改建议与判断。** 结果按身份与正确性、背景规律、双索引机制、跨 checkpoint 复现和行为标定排序。结论明确把 closure 与 finite replacement 分开。E5 只写参数状态复现，不写训练导致。因果边界清楚。

## 3. 方法学与统计推断

**问题。** 需要核对统计单位、区间、多重比较、检查点选择和低覆盖率单元抽样。

**证据位置。** Section 5.1–5.4，Tables 3–10，`gxi_step4_numeric_recalculation.json`，`gxi_step4_e5_audit.json`。

**影响。** 把 head、pixel 或 tensor 项当独立样本会高估精度；四 checkpoint 若被写成独立训练种子会高估复现强度。

**修改建议与判断。** 推断先按图像聚合，bootstrap 使用 10,000 次重复，E5 在 checkpoint 内对四项假设执行 Holm 校正。E5 的 6,400 个图像级值从封存数组重算，最大差为 0。单元覆盖率和随机参数状态范围在方法与讨论中披露。结果方向可信，外推强度受到明确限制。

## 4. 结果解释与外推边界

**问题。** Attention Q 的方向具有模型依赖性，H4 在四 checkpoint 均反向，all-family 行为判据未获支持。只报告正向复现会构成选择性解释。

**证据位置。** Sections 6.4–6.6、7.1–7.2、8.2，Tables 5–10。

**影响。** 过度归纳会把冻结样本和规定任务写成所有 ViT 的一般规律。

**修改建议与判断。** Q 的相反趋势、H4 阴性、all-family 未获支持和“广泛但非普遍”均保留。适用范围固定为所列模型、检查点、图像、target、cut、reference 和 replacement。结果解释达到送审要求。

## 5. 学术写作与叙事结构

**问题。** 旧入口使用“结构化、可闭合、可审计”等属性词，但没有立即给出新增对象；讨论中的自我定位也略像预答辩。

**证据位置。** 双语标题、摘要、贡献、Related Work 结尾、Sections 8.1–8.2。

**影响。** 审稿人可能先形成“G×I 加 hooks”的印象。

**修改建议与判断。** 现标题直接写“双索引局部 Jacobian”。摘要和贡献二给出公式、自由索引和闭合对象。讨论使用正面技术陈述。防御性写作审计为 1/10，必要边界集中保留。叙事从对象、合同、正确性、机制到干预边界连续推进。

## 6. 改进路径

**问题。** 原稿需要区分提升论文层级的方法与证据修复，以及只改善表达和版式的发布性工作。

**证据位置。** 双语摘要与贡献、Table 1、Figure 1、Table 4、Sections 6.4–6.6 和 8.2。

**影响。** 如果优先处理措辞而不处理方法对象、近邻反例和证据错配，论文仍不能回答核心新颖性问题。

**修改建议与判断。** 已经完成三项高优先级修改。第一，重写双语入口，使方法增量可在摘要内独立理解。第二，用最强近邻逐字段反例约束 `NOV-JOINT-1`。第三，在结论中分开 closure 与 finite replacement，并绑定 attention/residual 的联合索引必要性结果。

送审前只剩发布性工作：填写或按匿名规则移除作者字段，补 repository/archive 元数据，按学校模板复核排版。这些工作不改变方法或结论。

## 最终裁定

`可送审`。维持该结论的最小条件是：

1. 不把基础 G×I、链式法则或单个组件重新包装为新颖性；
2. 不删除 H4、all-family 未获支持或模型依赖趋势；
3. 不把闭合、path norm 或四 checkpoint 复现改写为因果正确、贡献百分比或训练因果；
4. 投稿文件继续通过数字、引用、双语、公式和链接校验。

若任一条件被破坏，结论应降为 `重大修改后送审`。
