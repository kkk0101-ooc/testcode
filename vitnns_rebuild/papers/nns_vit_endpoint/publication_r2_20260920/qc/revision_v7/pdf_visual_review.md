## 构建期失败记录

1. 首次测试 PDF 因输出目录尚未创建而退出，未生成发布件。
2. 中文字体首次直连 GitHub 超时；通过工作区代理下载至临时目录，未安装系统依赖。
3. 首次完整构建因 Unicode 上标缺字失败；Markdown 改为数学模式后重建。
4. 第二次完整构建因英文补充的中文术语表缺 CJK 字形失败；双语均改用 XeLaTeX-compatible ctexart 类后重建。
5. 初版生成器出现可见交叉引用检查行、重复图片题注和双重章节编号；均在终版生成器中修复并重新连续双编译。

失败构建没有覆盖最终发布 PDF。最终构建报告状态为 PASS_TWO_CONSECUTIVE_CLEAN_BUILDS，发布验证状态为 PASS。
