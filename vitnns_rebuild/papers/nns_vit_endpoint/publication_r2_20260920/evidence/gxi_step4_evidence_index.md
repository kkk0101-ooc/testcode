## E5 同步决定

决定为 `SYNC_FOUR_CHECKPOINT_E5`。第四步专项校验逐字节核验 1,600 个 task JSON 与 1,600 个 NPZ，重新计算 6,400 个 image-level H1–H4 值，最大差为 0；再从图像级值重算 median、10,000 次 bootstrap CI、双侧符号检验和 checkpoint 内四项 Holm 决策。完整记录见 `gxi_step4_e5_audit.json` 和 `gxi_step4_numeric_recalculation.json`。
