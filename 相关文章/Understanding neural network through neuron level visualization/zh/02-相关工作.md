# 2. 相关工作

近年来，人们进行了许多尝试，以可视化、解释并理解神经网络的内部工作原理（Piano, 2020）。神经网络可解释性研究受到了广泛关注（Thiebes, Lins, & Sunyaev, 2021）。一种直观的方法是直接可视化神经网络中的数值。目前已经提出了多种方法来显示神经网络中神经元的激活值（Zhang, Tiňo, et al., 2021）。Yosinski、Clune、Nguyen、Fuchs 和 Lipson（2015）介绍了一种工具，用于可视化 CNN 中每个特征图产生的激活。激活值会随输入样本动态变化。Wang 等人（2020）提出了一种名为 CNN Explainer 的 CNN 可视化工具。CNN Explainer 集成了用于概括 CNN 架构的模型总览，并动态展示 CNN 各组件的运算过程。该工具帮助用户理解各层的作用以及相邻两层之间的相互影响。另有一种名为 3D Multilayer Neural Network Simulation 的仿真工具。[^1] 它可生成以三维形式表示的 FCN 可视化结果。这些工具简单且易于理解，但使用它们无法获得每个神经元所学到的信息。

为了更深入地解释神经网络，一些研究通过可视化展示模型的表征（Samek, Montavon, Lapuschkin, Anders, & Müller, 2021）。目前，以可视化方式解释神经网络的现有方法主要分为两类。一类是激活最大化（Simonyan, Vedaldi, & Zisserman, 2013），其目标是寻找能使被检查神经元达到最大激活的输入模式。该方法通过最大化某个输出神经元的激活来生成样本，这一生成样本反映了该神经元所关注的内容。借助反向传播，该样本得到迭代优化，最终获得使某个分类神经元激活值最大的样本。Nguyen、Dosovitskiy、Yosinski、Brox 和 Clune（2016）增加了图像生成网络，以合成接近原始图像的图像。为了避免高频噪声，Wang、Liu 和 Cheng（2018）采用图像模糊和去模糊来生成图像。另一类神经网络解释方法是显著图（Simonyan et al., 2013）。对于给定的输入样本，显著图试图为每个像素分配重要性分数。类激活映射方法生成一个映射，用以显示 CNN 中的关注区域。Zhou 等人（2016）提出类激活映射（CAM），在 CNN 中使用全局平均池化（GAP）取代全连接层。通过这种架构，输出层的权重被反向投影到卷积特征图上，从而识别图像中的重要区域。在 Zhou 等人（2016）的基本架构之上，Selvaraju 等人（2017）提出梯度加权类激活映射（Grad-CAM），用于突出显示图像中对概念预测至关重要的区域。Muhammad 和 Yeasin（2020）利用卷积层所学表征的主成分创建可视化解释。Zeiler 和 Fergus（2014）通过反卷积模型学到的特征来解释 CNN。由此可以看出，神经网络在低层主要学习简单的边缘特征，在高层则学习部分或完整的物体。Ren、Zhang、Wang、Hu 和 Zuo（2020）生成了视觉质量令人满意的图像，其中非盲反卷积并非必要选择。Zhang、Wang 等人（2021）提出通过提取图模型来解释 CNN。这些方法自动提取图像中的不同部分，以描述滤波器感兴趣的内容。

激活最大化方法关注神经元学到的视觉模式，不适合解释单个输入样本的结果。显著图方法显示输入样本中哪些区域在视觉上较为重要，但这类方法与固定的神经网络模型紧密相关，难以比较不同神经网络架构的工作机制，也难以分析模型不同组件的功能。本文所提方法将每个神经元视为一个单元，用来解释模型学到的信息。显著图显示的是模型感兴趣的区域，而所提方法显示的是模型从输入样本中学到的特征。该方法可以在统一框架下比较不同模型。

[^1]: 3D Multilayer Neural Network Simulation：<https://tutorials.retopall.com/index.php/2019/02/16/3d-multilayer-neural-network-simulation>。
